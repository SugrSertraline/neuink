## Workspace 与 Entry

- [ ] 选择或打开 Workspace 后可以创建 Entry，并在重启后恢复。
- [ ] Entry 标题、Field 和 Tag 更新后重新读取一致。
- [ ] 删除进入回收站；恢复后 PDF、笔记和元数据完整。
- [ ] 彻底删除只影响明确选择的回收站 Entry。
- [ ] 左右 pane、tab、焦点和分隔比例不会串到错误 Entry。

## PDF、Parser 与 Reflow

### 编辑生命周期（2026-09-06 新增，以下原生人工验收待完成）

- [ ] PDF、重排和片段记录的片段笔记/批注修改后，单页关闭、关闭其他页及关闭分屏均弹出保护；取消和 Escape 保留内容并恢复焦点。
- [ ] 批量保存任一项失败时所有待关闭页均保留；重试成功才关闭原目标集合，不误关后来打开的页。
- [ ] 保存期间继续输入或从另一分屏修改同一片段，新增文字仍为未保存状态，不被清空或忽略。
- [ ] 批注列表在保存未完成时刷新，不误清草稿；保存失败后仍可编辑和重试。
- [ ] 有未保存内容的跨分屏移动/交换被阻止，同分屏排序和已保存内容移动仍可用。
- [ ] 修改片段后隐藏阅读页超过五分钟，返回时草稿仍在；保存后无修改的隐藏阅读页才可回收。
- [ ] 切换资料库保存所有编辑类型；任一失败取消切换，新资料库不继承旧草稿/定位。
- [ ] 原生关闭按钮、Alt+F4 和页面刷新保护未保存内容；全部保存或明确放弃后能正常退出。不能用强制结束进程代替验收。
- [ ] 初次片段读取失败显示错误和重试；已有记录刷新失败不卸载编辑器、不清草稿，晚到的旧资料库响应不会串入当前页。
- [ ] 重复打开已有片段记录能更新定位和笔记/批注模式；跨页片段显示已有笔记，保存后重开不变空白。

### 常规阅读

- [ ] 导入 PDF 后状态按 queued、processing、succeeded/failed 更新并落盘。
- [ ] 解析失败可以复用原 PDF 重试，不生成第二个主 PDF。
- [ ] PDF 页面、Segment overlay、rail 和右侧内容定位一致。
- [ ] Reflow 的标题、段落、列表、公式、表格和视觉块顺序正确。
- [ ] 隐藏/恢复、列表项复制和 hover preview 不改变证据 Segment。
- [ ] 全文翻译支持暂停、继续、失败重试和导出。

## 论文内容导出（新增人工验收）

- [ ] PDF 与 Reflow 均可打开导出弹窗；窄窗与 125% 缩放下按钮、检查清单和格式选择可用。
- [ ] PDF 上传解析与 MinerU ZIP 创建的条目均能导出，隐藏图片/折叠内容后导出范围不变。
- [ ] 中文/双语稿仅有图中文字未核验时可正常导出，不额外勾选、不标草稿，输出仍保留核验范围说明与检查清单。
- [ ] 缺译、旧译文、缺图显示具体数量；点击“继续导出（含待核对内容）”后选择位置即可导出草稿，保留原文和检查说明。重新检查期间禁用按钮，旧结果不能授权新内容写入。
- [ ] 每项检查结果可点击“预览”，显示对应导出内容；大图适应窗口/放大、大表横纵滚动可用，缺图有提示，不加载文档中的未校验外部图片。
- [ ] 预览切换上一项/下一项时不显示迟到旧内容；关闭大图/大表只返回预览，Escape/返回清单保留导出弹窗及清单滚动位置。快照变化可重新检查，预览不写入或更改核验状态。
- [ ] Word/WPS 打开生成 DOCX，无中文缺字、遮挡或表格内容丢失，图片比例正确。
- [ ] 资料包移出 Workspace 后仍可读取图片；TXT 明确不含图片；未携带无关笔记或配置。
- [ ] 取消保存不写文件；目标重名、文件占用、只读位置和源内容变化均有可恢复错误。
- [ ] 重启桌面后端后新 IPC 可用；实际系统保存对话框和磁盘文件结果一致。
- [ ] 含 `text=Mermaid`、`markdown=null` 和 `asset_path` 的真实 Figure 默认只导出原图；切换源码、渲染图或原图附源码后，图注仍保留。
- [ ] Mermaid 源码模式不被重复代码围栏包裹；ZIP 的 `.mmd` 与解析源码一致。原图附源码将代码放到文末，而不是插在正文中间。
- [ ] 渲染图在原生 WebView2 中可生成；非法语法、外部资源或超限图片阻止写入，用户可选择原图/源码继续。
- [ ] Word 标题、图注、代码样式和三档图片宽度生效；逐段来源编号可选，长代码允许跨页，图片不超正文边界。

## 阅读成果导出（新增人工验收）

- [ ] 条目概览可多选文档笔记、片段记录、批注、已保存译文；默认不选，筛选不悄悄改变选择范围。
- [ ] 片段记录页可直接导出；有笔记/有批注/仅高亮只列出对应范围，空结果不变成全量，切换条目不复用旧范围。
- [ ] PDF/重排内当前片段笔记、批注和展开的译文均可就地导出；跨页片段可找到已保存记录，未保存草稿要求先保存。
- [ ] 翻译任务中可导出已保存译文；运行中/无译文禁用，导出弹窗关闭后焦点回到入口，父任务弹窗不关闭。
- [ ] 片段记录的文档定位图标与文字清楚；配对 PDF/重排跳转准确，未配对能打开 PDF，跟随控制在配对后可用，窄分屏按钮自动换行。
- [ ] 笔记文件菜单可导出当前笔记 DOCX/TXT；无 PDF 的条目、只读已保存笔记也可导出，既有 Markdown 另存为仍可用。
- [ ] 未保存笔记、版本冲突或片段草稿不被旧落盘版本代替；明确保存所选笔记不会保存未选笔记或接管编辑权。
- [ ] 合并文件和逐项 TXT/DOCX ZIP 均只包含勾选成果及关联引用；解压后索引、重名文件和中文名称可正常使用。
- [ ] 来源包含题名、物理页码、可用 DOI 和引用快照；未使用来源不展开，代码中的来源 token 保持原样。
- [ ] 旧译文、断链、孤立记录和缺图须确认后带提示导出；正文、图片或题名在检查后变化时不覆盖原目标。
- [ ] 原生 100%/125% 缩放、最窄分屏、长列表滚动及键盘勾选可用；底部取消/导出不被遮挡。
- [ ] Word/WPS 实际打开验证中文、表格、图片和多页内容；TXT 明确不含图片，Mermaid/公式保留源码。

## Markdown 与 Source Link

- [ ] 自动保存后重新打开正文一致。
- [ ] 表格增删行列、公式、图片和提示块可保存并恢复。
- [ ] 插入同一 Segment 时复用 Source Link，不产生重复 sidecar。
- [ ] Source Link 可展开、打开来源、复制引用和删除。
- [ ] 删除正文链接后，未引用 sidecar 记录被清理。
- [ ] 同 Entry 和跨 Entry 跳转都定位到正确 Segment。
- [ ] 导出 Markdown 生成可读 Sources 脚注。

## 搜索

- [ ] Entry、Tag、Field、Note、Page 和 Segment 结果能打开正确目标。
- [ ] Keyword、Semantic、Hybrid 返回模式和警告与实际执行一致。
- [ ] Embedding 模型缺失时明确不可用并安全回退。
- [ ] 启动应用不会自动构建向量索引，也不会出现embedding 相关的 CPU 峰值。
- [ ] 未构建向量索引时，Semantic/Hybrid 明确提示并回退 Keyword，不在搜索请求内联触发构建。
- [ ] 搜索面板「构建」按钮先弹出确认提示（CPU 占用与耗时），确认后才开始构建。
- [ ] 手动构建一次会同时覆盖全局与片段两个作用域，助手片段搜索可正常使用语义结果。
- [ ] 增量构建只补嵌新增或变更内容；未变化时点击「更新」接近瞬时完成。
- [ ] 重建索引后内存、磁盘状态和记录数量一致。
- [ ] 删除或修改 Entry 后旧结果不会长期残留。

## Assistant 与 Proposal

- [ ] `@` 读取对象、证据对象和编辑目标角色明确且不串位。
- [ ] 没有唯一写入目标时追问，不从久远 Pending Plan 猜测。
- [ ] TaskState 保存 taskId、目标、操作、授权和完成状态。
- [ ] 论文结论包含有效 Evidence；引用失败不能伪装成功。
- [ ] Verifier 阻断后不展示可 Apply 的正常 Proposal。
- [ ] Apply 只提交 taskId 和 proposalId。
- [ ] Apply 使用已验证的精确目标，不使用当前 UI 选择猜测。
- [ ] 基础正文变化时返回冲突，不覆盖用户新内容。
- [ ] 同一 Proposal 重复 Apply 不产生重复写入。
- [ ] Note 正文和 Source Link 写入中断后可以恢复或回滚。
- [ ] Apply/Reject/取消/新任务正确关闭旧 Task。
- [ ] Conversation、TaskState、AgentRun 和 Proposal 状态重启后可恢复。
