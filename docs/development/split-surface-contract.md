# NeuInk 分屏页面组合规范

> 状态：项目级实现规范  
> 适用范围：`apps/desktop` 工作区标签页、左右分屏和跨页面联动

## 1. 状态与职责

- `App` 是左右标签、活动窗格、外部跳转和分屏宽度的唯一状态所有者。
- `ReaderPane` 负责渲染当前左右页面，并执行由页面组合决定的联动。
- 单个阅读器或编辑器只管理自身滚动、选择和编辑会话，不重新创建工作区分屏状态。
- PDF 内嵌笔记与工作区右侧笔记互斥显示；存在工作区配对笔记时，以工作区笔记为唯一引用插入目标。

## 2. 页面类型

工作区只保留以下页面类型：

| 范围 | 页面 |
| --- | --- |
| 全局 | 资料库、设置、新建条目、MinerU 客户端教程、标签管理 |
| 条目 | 概览、PDF、重排视图、Markdown 笔记、片段记录、来源链接、条目回收站 |

片段笔记和批注共同属于“片段记录”页面，通过页面内部模式区分。不得重新增加独立 `annotations` 页面类型。

## 3. 组合关系

所有页面组合必须由 `resolveWorkspaceSurfacePair` 解析为以下一种关系；未列出的组合统一为 `independent`，不得在业务组件中追加孤立的页面类型判断。

| 关系 | 组合与约束 | 行为 |
| --- | --- | --- |
| `reader-sync` | 同一条目的 PDF + 重排视图 | 双向同步当前片段 |
| `record-sync` | 同一条目的 PDF/重排视图 + 片段记录 | 阅读器选择驱动记录；记录定位驱动阅读器；未保存编辑可阻止跟随 |
| `citation` | PDF/重排视图 + Markdown 笔记，可跨条目 | 阅读器向配对笔记插入来源链接；PDF 还可插入片段截图 |
| `backlink-navigation` | 来源链接 + Markdown 笔记 | 来源列表可以打开或聚焦对应笔记 |
| `source-navigation` | 同一条目的来源链接 + PDF/重排视图 | 来源列表可以让配对阅读器定位原文片段 |
| `independent` | 其他全部组合 | 两侧独立工作，只共享工作区数据更新 |

关系判定必须与左右顺序无关。涉及条目位置同步的关系必须校验 `entryId`；引用关系允许来源与笔记属于不同条目。

## 4. 焦点、编辑与命令目标

- 当前焦点窗格决定 `Ctrl/Cmd + W`、助手活动页面和默认新标签打开位置。
- 来源链接和图片只能插入当前可见的配对笔记，不发送给隐藏标签或被遮挡的 PDF 内嵌笔记。
- 同一 Markdown 笔记只能有一个编辑所有者；移动标签不得复制编辑会话。
- 切换对侧活动标签时必须立即重新计算组合关系，旧组合不得继续接收同步事件。
- 跨条目的阅读器不进行片段同步。

## 5. 布局与滚动

- 左右窗格各自拥有一个页面级纵向滚动所有者；表格、代码块和独立预览可以有明确边界的嵌套滚动。
- 标准空间充足时，阅读、资料库和设置等页面的目标最小宽度为 320px；Markdown 文档笔记为可响应式收敛的内容面板，目标最小宽度为 224px。
- 工作区不足当前组合的两侧目标最小宽度之和，或按目标宽度计算后的可调范围不足 96px 时，两侧按各自目标宽度的比例共同收敛，并为分隔条保留至少 96px 的有效拖动范围（工作区本身不足 96px 时使用全部可用范围）；不得锁死分隔条或将任一侧裁切出工作区。
- 标签栏和正文必须使用相同的分栏宽度变量。
- 分隔条支持指针拖动以及方向键、Home、End；取消、窗口失焦和卸载必须清理临时状态。

## 6. 测试要求

- 组合解析器必须遍历全部有方向页面组合，并验证左右交换后关系不变。
- 每一种非独立关系至少覆盖同条目、跨条目或反向布局中适用的边界。
- 分屏尺寸测试必须覆盖标准组合、Markdown 笔记在左侧和右侧，以及不足组合目标宽度的紧凑状态。
- 组件测试必须覆盖切换对侧标签、交换窗格、关闭窗格、脏编辑阻止跟随以及引用目标唯一性。
