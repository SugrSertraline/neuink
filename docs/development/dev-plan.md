## 1. 已形成闭环

- Entry 创建、编辑、标签/属性管理、回收站、恢复和彻底删除；
- PDF 导入、Parser 提交、轮询、状态持久化和失败重试；
- PDF.js 阅读、Segment overlay/rail、Segment Note、Annotation；
- Reflow 主要 MinerU 块、列表、公式、视觉块、隐藏、翻译展示和动态高度虚拟滚动；
- Markdown 编辑、表格、公式、Source Link、反向引用和导出脚注；
- Keyword/Semantic/Hybrid 搜索、持久化向量记录、RRF 和索引状态；
- 全文翻译、暂停/继续、失败重试，以及生成内部双语 Markdown 笔记；笔记支持另存本地 MD，不等于完整译稿 DOCX 导出；
- Conversation 历史与 AgentRun；
- Router、TaskState、Evidence Ledger、Verifier、Verified Proposal；
- Note Proposal 的后端校验、幂等和 journal recovery；
- Entry Meta、Tag、Segment Note 等受控 Proposal 基础能力；
- Agent Skills、内置 Subagent、权限审计和进程型 MCP 工具 MVP；
- 左右 Workspace Surface、tab、分屏和 Entry Overview。

“已形成闭环”不等于已完成发行质量，回归和性能债务仍按下文处理。

## 2. 当前优先级

### P0：日常可用与数据安全

1. **Workspace 生命周期**
   - 已支持严格识别、选择、新建、最近打开、切换和迁移真实 Workspace；
   - 继续移除对开发目录或隐式默认目录的依赖；
   - 明确 Workspace 不可用、迁移和损坏时的恢复 UI。

2. **关键写入回归**
   - 覆盖 Note/Source Link/Proposal Apply 的冲突、重复提交和异常恢复；
   - 覆盖 Entry 删除恢复、解析重试和 Conversation 恢复；
   - 把 [P0 回归清单](p0-regression-checklist.md) 中的人工项目逐步自动化。

3. **统一任务体验**
   - Parser、索引、向量化和翻译统一进入 Job 状态与任务面板；
   - 统一取消、失败原因、重试和历史清理语义；
   - 不用“状态文本”代替真实进度。

4. **构建与发行基线**
   - 在干净 Windows 环境验证安装包和资源；
   - 固化模型缺失、有模型、断网三种启动路径；
   - 建立最小 CI、构建产物和发布检查。

## 5. 阅读成果与研究探索：拟议路线

> 需求整合与首批实现：2026-09-06。产品定义见 [PRD 第 7 节](../product/01-prd.md#7-阅读探索与输出整合需求)。A1/A2 已落地部分能力，具体边界见 5.4；其余仍是拟议路线，不覆盖上文数据安全与发行基线。

### 5.1 当前基础与准确缺口

- PDF 上传解析与 MinerU ZIP 导入可复用归一化 Segment/资源路径，导出不应绑定某一种创建入口或仅绑定当前可见 Reflow 块。
- 当前全文翻译入口由 `useEntryTranslationTask` 调用 `runEntryTranslation`，进入 Rust `TranslationPipeline`。Rust 的 `should_translate_segment` 排除空内容与 Figure；不能用旧 TypeScript `translateEntrySegments` 的过滤逻辑判断现行任务跳过了哪些类型。
- 旧 `translationExport.ts` 仍只拼接成功片段，供 `App.tsx` 创建内部笔记使用；新文件导出另走 Rust `workspace::export`，检查缺失、原样保留内容与源版本。UI 区分“已译片段生成笔记”和保存到外部文件。
- `useMarkdownNoteFileActions` 的 MD 另存为保留。文档笔记 DOCX/TXT、阅读成果多选及分享 ZIP 已接入独立成果导出入口，见 5.6；系统级拖出尚未实施。
- Sciverse 已有证据检索、正文读取和资源客户端等基础能力；完整文献发现与研究图的端到端范围另行核对。本轮未验证账号权限、配额或联网可用性。
- [平行阅读方案](../../design-previews/parallel-reading-plan.md)已根据官方工具调研收敛首版范围。B1 标签队列、双篇对照、进度和删除恢复已实现并完成自动回归，原生桌面验收待补，详见 5.10。B2 本地综合笔记、跨篇来源及导出见 5.15；全局搜索/AI 写入目标适配和 B3 证据对比仍待开发。

建议先完成 A1/A2 的视觉验收及剩余输出范围，让已有阅读成果可靠带出软件。之后 B 与 C 可以独立切片推进；轻量证据对比可先从已选本地论文开始，不必等待完整图谱或所有镜头交互。D 复用已取得的证据，不另建一条自由生成的研究报告流程。

### 5.3 启动实现前的范围确认

- 默认中文 DOCX、可选逐段双语；简单结构优先，暂不复刻 PDF 原始版式。
- “全文”覆盖哪些保留项与尚未核对的图中英文，必须在导出前明确；解析覆盖率不能替代原 PDF 完整性核验。
- 批量导出默认仅包含选择的成果，是否附原 PDF 由用户选择；桌面拖出不阻塞普通导出交付。
- 研究方向图优先主题分支和代表文献，不先建设全库图谱；探索记录附着 Entry/Tag，不新增必填项目。
- UI 延续现有组件与语义 token；新组件确认状态、滚动和键盘/拖动所有者后再实施。
- 实现后的验证与限制见 5.4；未调用付费检索或翻译服务。

### 5.4 首批导出实现与验证

- PDF 和 Reflow 共用 `PaperExportDialog`。支持解析全文、中文译稿、中英对照，输出 DOCX、TXT 或包含 `paper.md`、图片与 `coverage.json` 的 ZIP；此 ZIP 明确标为 NeuInk 整理包，不冒充原始 MinerU ZIP。
- 新增 `shared/ipc/exportApi.ts` → `inspect_paper_export` / `export_paper` → `neuink-workspace::export` 调用链。读取与生成在 blocking worker 运行，不在 React 或 Tauri 主线程处理图像与压缩。
- 逐项核对非空译文、源文本及兼容现有翻译记录的源 hash；未译、失败、旧译文在草稿保留原文，不直接丢弃。图片内文字未核验或资源缺失时也须显式同意草稿；所有文件说明未逐页核对原 PDF。
- 导出范围读取完整归一化结果，不接收隐藏/折叠/虚拟列表参数。测试覆盖有无原 PDF、MinerU ZIP 写入后内容一致，以及 Markdown/HTML 图片引用重写不误改正文和代码。
- 资源仅从当前条目解析目录读取，校验路径/链接边界、图片解码与大小；不自动下载外部图片。只打包引用资源，不带原 PDF、笔记、会话或账号配置。目标不得写入资料库；写前重新核对快照，复用原子写，并保护已有同名备份。
- 依赖选择：Rust `docx-rs` 负责 DOCX；`pulldown-cmark`/`scraper` 读取 Markdown 与 MinerU HTML 表格；`image` 显式提供有界图片解码。既有 ZIP、原子写、Button/Dialog/Select/Switch 与 Toast 继续复用，未增加前端依赖。版本进入 Cargo.lock；库许可与打包需随发行材料维护，尚未测量新安装包体积。
- 自动验证：前端 119 文件 / 409 测试通过；Workspace 50 测试通过，含 13 项导出回归；另有 1 项手动触发的样本生成测试通过。TypeScript、`cargo check --workspace` 和前端生产构建通过；构建仍有 PDF.js 静态/动态导入及大 chunk 提示。
- 通过生产导出器生成三份 DOCX 样本并检查 OOXML 文本、表格、图片与字体。文档技能的 `render_docx.py` 因 Windows 环境缺少 `soffice.exe` 无法完成渲染，未通过 Word/WPS 版面验收，也未完成原生 Tauri 视觉、文件对话框与 125% 缩放验收。
- 首批限制：公式保留源表示而非可编辑 Word 公式；复杂/超宽表格以逐行文字回退并说明。笔记 Word 和批量片段 TXT 的后续实现见 5.6；仍无图中英文 OCR、桌面拖出、中文 PDF、PPTX 或研究图。新增 IPC 需要桌面后端重新编译并启动，单独刷新前端不能更新旧二进制。

### 5.5 Mermaid 与导出版式适配

- 已核对真实资料库：流程图通常是 Figure，`text` 含 Mermaid 围栏，`markdown` 为空，`asset_path` 指向原图；标题级别保存在 `mineru_metadata.level`，图注通过 `block_role=caption` 标识。不能仅依赖 Markdown 标题或把图片当普通源码。
- 共用导出弹窗新增四种方式：原图（默认）、Mermaid 渲染 PNG、可复制源码、原图加文末源码附录。普通图片不受流程图选项影响；源码相关 ZIP 附 `.mmd`。原图缺失保留源码并提示草稿，渲染失败不落盘，不擅自补画或修改源码。
- Word 统一标题层级、图注、正文强调、代码字体、图片居中及等比边界；图片最大宽度提供 60% / 85% / 100%，小图不强制放大。逐段来源编号默认关闭，核对时可以打开。保留解析内容的前提下做单栏排版，不承诺复刻 PDF。
- 继续使用现有 Dialog/Select/Switch、Mermaid、`docx-rs` 和图片库，无新增依赖。设置与任务状态归导出弹窗；正文设置/报告共用一个纵向滚动区，头尾固定，保存中阻止关闭及重复提交；无新增拖动行为。导出准备与 Word 文本样式拆成独立模块，避免持续膨胀单一导出文件。
- 自动验证：前端 120 文件 / 416 测试；Workspace 57 测试（20 项导出回归），另有 2 项手动 QA 测试默认跳过。真实论文的四种模式分别生成 DOCX/ZIP，手动 QA 测试通过；确认 29 个正文标题、10 个图注及图片/表格结构，源码模式替换流程图原图而不移除其他图片。
- 使用 Edge 无头浏览器调用实际导出渲染模块检查 3 份真实 Mermaid：2 份成功转换并检查 PNG，1 份因语法异常阻止导出。此结果不证明 Mermaid 识别语义正确。TypeScript、前端生产构建与工作区编译检查通过；既有大 chunk / PDF.js 混合导入提示仍存在。
- 文档技能渲染器再次因缺少 bundled `soffice.exe` 失败，未完成 Word/WPS 全文分页版面验收；未完成原生 Tauri 文件对话框、WebView2 渲染和 125% 视觉验收。桌面开发版已自动重编译运行，可继续人工测试。

### 5.6 笔记、片段与当前论文分享包

- 文档笔记文件菜单新增“导出 Word / TXT”，保留已有 Markdown 另存为。笔记入口仅查询当前已保存笔记；条目概览新增“导出阅读成果”，可按文档笔记、片段记录、批注、已保存成功译文筛选并多选。概览默认不勾选任何项目。
- 支持合并 DOCX、合并 TXT、逐项 TXT ZIP、逐项 DOCX ZIP。ZIP 按当前论文建安全命名的目录，带索引和待核对提示；此轮不是跨论文批量，也不带原 PDF、未选笔记、全量译文、聊天记录或配置。
- 复用 `docx-rs`、Markdown/HTML 处理、图片解码、原子写与目标保护，无新增依赖。新增共享 Checkbox 封装使用已安装的 Radix，复用 Dialog/Select/Switch/Button/Toast，未另建选择控件系统。现有大编辑器仅接入口，业务放在独立导出模块。
- 引用以题名、物理页码、可用 DOI 和文字快照携带，不输出仅本机可用的跳转。未使用 sidecar 来源和代码示例里的来源 token 不展开。旧译文保留对应旧原文并标明待核对；孤立片段记录与批注快照仍保留。图片无法读取或越界时不下载，显式确认后保留说明。笔记导出的公式与 Mermaid 为源码，不套用论文图像渲染选项。
- 保存与选择由当前弹窗持有；只使用已有保存所有者，不接管编辑权。未保存的所选笔记先由用户保存并刷新；片段/批注草稿提示回阅读器保存。生成前和写入前复核所选指纹，未选笔记的变化不阻止独立笔记导出。取消、关闭、重复提交和跨条目的迟到响应均有保护。
- 正文为唯一纵向滚动区，头尾固定，无新增拖动行为。Edge 无头浏览器使用实际组件/CSS、模拟 IPC 检查 1200/640/420 px 与 100%/125% 缩放：修复视口单位在 CSS zoom 下导致越界的问题；无横向溢出，单滚动区，键盘勾选、底部按钮与取消可用。已查看默认宽度和最窄样本截图；这不等于原生 WebView2/系统保存对话框验收。

### 5.8 重要缺陷检查与编辑安全修复（2026-09-06）
