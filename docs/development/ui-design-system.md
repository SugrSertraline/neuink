# NeuInk UI 设计与交互规范

### 重排阅读详略

阅读详略任务统一补齐源语言四层结果及对应中文译文：先保存原文详略，再沿用“整段翻译”来源逐层翻译并保存；两侧齐全后才计为完成。旧结果只补缺失或过期译文，不重算有效原文。任务列表显示“待补译／翻译中”，原文预览仍可查看；翻译失败保留已保存内容、显示本段错误并继续其他段落。选择、滚动和键盘沿用现有任务窗口契约，任务状态由共享队列持有。原有可视区域按需补译作为阅读时的补全路径保留。

顶部“阅读详略”仅提供原文、精简、要点、结论和主题五级，默认原文；原文指完整、未压缩内容，与语言无关。右侧独立提供“源语言：整段／逐句／隐藏”及“中文译文”开关，正文双语层同步使用源语言／中文译文标签。原文段落尚无详略结果时不重复显示缺失提示。逐句模式下详略入口显示“逐句模式”占位，仍可选择任意级别回到整段；组件与段落菜单也能双向切换，保留单段覆盖和已有缓存。打开条目时遵循已保存的逐句偏好，不把默认原文级别当作退出逐句的指令。

重排阅读面持有全局详略和单段覆盖，逐句模式暂停详略时保留单段选择，界面不提供独立关闭项。原文、精简、要点、结论和主题只作用于可验证的正文段落；标题、公式、图表、跨页续接或无法处理的片段保留原文。片段操作沿用现有位置、来源和键盘契约；压缩层不把生成文字或不连续的精简文字当作原文选区，原文依据可展开并回到真实来源。未生成、读取失败、部分失败与生成中分别提示，可按整篇或单段生成并停止；模型调用、数据持久化和任务状态不归 UI 组件。

新生成详略的段落至少包含 20 个非中日韩词，或 40 个中日韩文字；混排按每个词等于两个中日韩文字计算，标点和空白不计。整篇、单段、重试和自动生成均共用此门槛；短段落保留原文，已生成的历史结果仍可查看但不重新生成。门槛仅限制新的模型请求，不清理已有结果。

整段阅读时，片段信息栏将“跟随、原文、精简、要点、结论、主题”横向单选按钮固定在段落、页码和来源标识同一行，悬停片段或键盘聚焦时显示，预留位置避免正文跳动；当前选项高亮，不使用 Select 或二次展开菜单。Annotation 和 MinerU 等元信息靠右，不显示“AI 生成”标签。SegmentFoldControls 复用 ToggleGroup，不持有第二份粒度状态，原 FoldReader 持有段落覆盖，顶部全局控制保留。信息栏宽度不足时可横向滚动，键盘聚焦会跟随选中项；正文仍由原阅读容器纵向滚动。Tab／方向键移动，Enter／Space 激活，Escape 返回片段；操作不触发原文预览、片段导航或 Ctrl 拖动。触屏持续显示控件，减少动态效果时禁用淡入动画。缺少详略结果提示暂显示原文，不隐式生成；不适合折叠的段落只允许原文和跟随。目录轨道之外固定保留 24px 片段按钮、12px 正文偏移及至少 12px 目录间距，所有分栏宽度保持该下限；无新增依赖。

整段阅读且段落已有有效结果时，在段落正文上按住 Ctrl 滚动滚轮可调整本段详略：上滚更详细，下滚更简略；段落根节点聚焦后也可用 Ctrl + ↑／↓。顺序为原文、精简、要点、结论、主题，边界不循环，也不触发页面缩放。只更新 FoldReader 的本段覆盖，复用原有文字及高度动画，不调用生成任务；按钮提示中说明快捷操作。普通滚轮仍交给原阅读容器；输入框、链接、按钮、选字、拖动及右键菜单优先，保留 Ctrl 拖入引用和原有方向键行为。未生成、不适合折叠或处于逐句模式时不接管手势；段落移除时释放监听。触控板累积位移并限制切换频率，避免一次滚动跳过多个层级。

详略生成沿用翻译任务的共享 Dialog 和 Progress：点击顶部“阅读详略”按钮只打开任务窗口，不调用模型或切换阅读层级。窗口列出整篇符合条件的正文，初始不勾选；用户可逐项选择、全选或选择未生成内容，再点“开始生成”。普通生成跳过已有且原文匹配的结果，重新生成已有结果须明确确认。进度只统计本次需处理的段落，缓存单独计数；列表显示页码、正文摘要和未生成／待处理／生成中／保存中／已完成／失败／已取消／已缓存状态。局部任务结束后，整篇其他段落仍可选择。

任务窗口支持全部／待生成／处理中／已有结果／失败／已取消筛选，并可组合页码和正文搜索；状态数量按当前页码和搜索计算，段落编号不随筛选改变。筛选与选择由弹窗持有，切换条目时重置；“全选当前列表”和“选择未生成”只影响当前结果，保留筛选外已选项并明确显示数量，可单独清空选择。筛选不改变共享任务的执行和进度范围。小眼睛使用共享 HoverCard，悬停、键盘聚焦或点击可查看完整原文、安全错误及与当前原文匹配的已保存四层结果，不发起模型请求。单项取消和重试使用 TooltipIconButton；列表仍由 DialogBody 滚动，预览浮层独立限高滚动，沿用 Tab／Enter／Escape，不新增拖动或依赖。

片段信息栏不显示随详略层级变化的“作者原文”标签，避免 Ctrl 滚轮或键盘切换时横向挤动粒度按钮；原文的可访问标记保留，控件仍占用同一位置并复用原有展开／收缩动画。

段落尚无有效详略结果时，粒度标签及选中项使用正文前景色（浅色界面为黑色）与中性选中底色；已有结果沿用主题选中高亮。悬停或键盘聚焦标签区，用共享 Tooltip 说明当前显示原文并指引到顶部生成任务；不适合生成的段落单独说明保留原文。提示浮层不占据信息栏空间，选择仍归 FoldReader，正文仍由原阅读容器滚动，不改变生成或拖动行为；Escape 优先关闭气泡，再按一次返回段落。

顶部全局详略切换直接更新各段原文与中文译文，不播放文字或高度动画；跳过逐词位置测量及译文动画专用的字符对齐，并清理尚未结束的单段动画和重影。段落按钮、Ctrl 滚轮与 Ctrl 方向键调整本段时继续使用过渡动画。全局和单段状态仍由 FoldReader 持有，组件根据全局级别是否改变区分更新来源，不增加定时开关或持久化偏好；滚动、键盘与拖动契约不变。

重排工具栏按当前阅读面的实际可用宽度、按钮固有宽度和间距逐项决定显示范围，计入界面缩放和小数像素，不再用固定窗口阈值整组收起。先保留详略和语言控制，次要按钮按原顺序尽量平铺，只有放不下的进入菜单；更窄时详略也进入菜单。标题使用导航和外观按钮之外的剩余宽度，超长仍截断并保留完整标题气泡。布局状态归 useReflowToolbarLayout，菜单开关归 ReflowToolbar，业务状态仍归原组件；控件只挂载一份，隐藏测量项不接收焦点且不进入可访问树。设置浮层或阅读工具菜单打开时冻结布局，关闭后重新测量；收起当前聚焦按钮时移交菜单，菜单不再需要时移交可见操作。保持两行页眉及原正文滚动，菜单继续使用共享 Popover，键盘和拖动沿原契约，无新增依赖。

支持逐项及批量取消、重试，以及暂停、继续、停止全部；暂停立即停止派发，等待当前请求与写入结束后显示“已暂停”，继续处理原选择范围，不重复已完成项。暂停队列在当前应用会话内按资料库与条目共享，其他阅读面不能覆盖或隐式恢复它；后台任务投影同步暂停状态。停止中止未完成的模型请求并等待已开始的保存，已写入结果保留。未请求的取消项跳过，已发出请求的段落丢弃相应结果，保存中的项不能取消；暂停期间也可取消待处理项。任务结束后才能新建或重试，关闭窗口和 Escape 不停止任务。完成数量仅在成功写盘后更新。选择由弹窗持有，执行状态归共享任务；有界 Dialog 的 DialogBody 独占段落列表滚动，头部和底部操作固定，沿用 Tab／Space／Enter 和 Escape 契约，不新增拖动或依赖。

全局入口保留“生成详略”，任务运行或暂停时显示“查看进度”，移除“生成当前章节”；任务弹窗继续支持逐段选择与重试。生成调用共享 JSON 模型任务，每次请求最多等待 120 秒，复用系统助手模型的采样与最大输出设置；未配置输出上限时沿用共享适配器默认值，不再独立限制为 8192 Token。已配置的上下文长度用于估算输入容量，并在明确输出上限过大时为本次输入预留空间；估算不是模型分词器，不改变持久化设置。任务快照保留安全分类后的失败原因，在顶部和进度弹窗一致显示；区分上下文不足、超时、认证、额度、限流、空输出、截断、JSON／原文校验和读写失败，不显示服务端原始正文、凭据或私密路径，保留已完成的结果。

整篇、选中段落、重试及自动生成共用有界并发队列，每篇最多同时处理三个段落；每次模型请求仍只有一个待生成段落，互不共享输出额度，单段校验后立即原子保存。已保存且原文匹配的段落跳过，不重复生成。单段上下文不足、截断、空输出、格式／原文校验或内容过滤失败时，记录该段安全错误原因并继续后续段落；失败状态可查看该段原因，任务结束后只重试需要处理的段落。连接、认证、额度、限流、超时及读写等共享故障停止派发并中止未完成请求，等待已开始的写入结束，保留已保存结果和未处理队列。进度区逐项区分生成和保存：仅生成中的段落可取消，保存中的段落不可取消，完成数量只计入写盘成功的段落。

模型输入显式列出从零开始的句子编号，主题必须逐字来自结论的连续片段。提示词沿用 TextFold 原作者的段落规则与中英文长度约束，附带有界的文章标题、摘要、目录和当前章节背景；单段选择仍从完整重排文档获取背景，只生成所选段落，不生成章节摘要或导航图。模型仅改变大小写时，将其定位并还原为结论中的实际字面片段，再执行原有严格校验；不接受主题改写、不猜测证据编号，也不因生成失败降低原文校验。请求与提示词由生成层持有，任务状态、列表滚动及键盘／拖动契约沿用现有实现。

折叠与逐句对照在同一重排阅读面互斥；启用详略时暂以整段方式显示，选择逐句时退出详略，不改写原有偏好和译文。原文级别可复用匹配的原文译文，其他层级只显示与当前内容匹配的已保存中文译文；开启翻译且对应段落可见时按需补齐缺失译文，离开视口释放请求，失败提供手动重试，跨阅读面复用相同请求并全局最多并发三个。可用的不同层级中文译文切换时沿用词语与高度过渡，不用生成文字冒充原文选区。阅读设置中的自动生成默认关闭，仅在阅读面可见时补齐缺失详略结果，使用助手模型；同一资料库和条目共享进行中的任务。自动设置不重算已匹配结果，也不自动改变详略级别。

重排页眉固定分两行：第一行是限制宽度并截断的标题及右侧导航和外观按钮，鼠标悬停或键盘聚焦标题时使用共享 Tooltip 查看完整标题；第二行从阅读面左侧放置详略等工具，原文／翻译控制靠右。宽度不足时次要工具进入阅读工具菜单，更窄时详略控制也进入菜单；分屏紧凑工具栏沿用原有布局。重排虚拟列表仍是正文唯一纵向滚动所有者；全局与单段控制使用共享组件，交互沿用 Tab／方向键／Enter 与焦点契约，不新增拖动。单段切换详略前捕获可见词语位置，更新后让保留词移动、新增和删除词淡入淡出，并平滑调整段落高度；连续切换或卸载清理旧动画，减少动态效果时直接显示。动画清理不重建 PDF、笔记或用户选区；分屏联动继续使用原有片段导航。真实模型、原生 Tauri 和长文性能均须单独验收。

### 文件拖放导入遮罩

在主窗口拖入 PDF、MinerU 结果目录或 ZIP/RAR 时，显示覆盖整个窗口的半透明遮罩、内侧虚线边界与居中提示，明确支持的文件类型；资料库未打开时提示先打开资料库。遮罩不接收指针事件，不改变原有拖放命中区域、文件分流和导入队列；离开窗口或放下文件后立即消失。拖放状态仍由 `usePdfDropImport` 持有，窗口没有额外滚动区或键盘操作。

### PDF 内容重复提醒

新建条目选择 PDF、拖入 PDF 批量创建、创建新版 PDF、给已有条目附加 PDF 及从 MinerU 结果新建时，先按原 PDF 字节的 BLAKE3 哈希核对当前资料库；文件名和条目标题不参与判断。命中已有条目或回收站时，在右下角显示不自动消失的通知及“查看详情”按钮。详情列出待添加和已有论文的标题、PDF 文件名与已有位置，让用户取消或“仍要添加”；通知关闭等同取消。Zotero 和 MinerU 列表导入、研究导入及在线获取 PDF 也沿用确认流程。拖入批量导入逐项处理，取消一项后继续下一项，并汇总成功、重复和失败数量；不自动覆盖或清理用户文件。

预检状态归创建入口或导入队列持有，确认状态由根应用通知与对话框持有；工作区写入层在真正保存 PDF 时再次核对，并只接受与当前文件内容哈希一致的确认。通知和对话框使用现有按钮与键盘契约；文件选择、拖入和表单键盘契约沿用现有实现；不新增滚动区、拖动手势或 UI 依赖。哈希读取失败明确报错，成功、取消与失败反馈须区分；无 PDF 的空条目不执行核对。

### 标签管理树图

条目库页眉的“标签管理”使用共享标签图标。编辑页按标签父子关系绘制 SVG 连线，标签节点保持真实的 HTML 按钮；单击选中，双击或键盘激活打开条目，节点箭头独立展开／折叠。顶部提供展开全部、收起全部及按路径新建，右侧对选中标签执行打开、添加子标签、重命名和移入回收站。窄窗口时编辑区移至树图下方。

展开状态、选中项、编辑草稿和提交状态由 TagEditorPage 持有；树图区域独占横向及纵向滚动，编辑区仅在内容超出时滚动，页眉固定。树图尺寸小于视口时居中，较大时从起点显示；左键拖动空白画布或中键拖动平移视图，“视图居中”复位。节点按钮不启动平移，触屏保留原生滚动；指针取消或 Escape 取消本次拖动。节点右键菜单复用共享 ContextMenu，提供打开、展开／折叠、添加子标签、重命名和移入回收站，菜单沿用键盘与焦点契约。连线不接收指针事件，节点使用现有 Button、Input、Dialog 和语义色；没有新依赖。空标签、提交中、保存错误和删除确认须有明确反馈，失败后保留草稿供重试。

树图缩放和平移由 useTagEditorViewport 统一持有，仅保存在当前页面会话中。顶部提供缩小、百分比／恢复 100%、放大、适应画布和视图居中；范围为 10%–200%，按钮每次调整 10 个百分点。Ctrl／Command＋滚轮围绕指针缩放，普通滚轮及方向键沿用原生滚动；画布聚焦时 +／− 缩放、0 恢复，输入框及节点键盘激活不被抢占。缩放同步改变画布尺寸、节点和连线，按应用 CSS 缩放换算坐标，保留当前位置；适应画布和居中可找回移出视口的内容。平移经过 4px 阈值，取消、捕获丢失、失焦和卸载清理手势。

空白画布右键提供新建标签、缩放、适应、居中和展开／收起全部；节点菜单只作用于被右击的标签，不能同时打开画布菜单。触发区域与菜单显式标记允许应用右键，避免被主窗口的默认右键拦截。菜单关闭恢复节点或画布焦点，新建菜单将焦点交给路径输入框；保存中禁用标签修改和展开动作，视图调整仍可用。继续复用 Button、ContextMenu 和现有删除确认，无新增 UI 依赖。

### 条目库顶部布局

条目库“选择模式”由 useLibrarySelection 持有临时多选集合，与 App 的单项详情预览分开。列表和书架显示共享 Checkbox，单击或 Enter／Space 勾选，Shift 连选、Ctrl/Cmd+A 全选当前结果、Escape 退出；编辑框、菜单、对话框和进行中的列宽调整继续拥有原键盘行为。筛选改变清空选择，切换资料库、标签或浏览范围退出模式；列表与书架互切保留选择。模式内禁用条目拖动和双击打开，普通模式契约保持原样。表格预留 42px 勾选列，固定标题列相应右移，不改写原列宽偏好；滚动仍归原表格或书架。

批量操作在固定工具区显示选中数量，支持追加本地标签、隐藏／恢复来源条目及将本地条目移入回收站。LibrarySelectionActions 持有操作快照、确认弹窗和进度；确认前列出本次实际目标，混选按来源保护拆分操作范围。失败项保留供重试，已成功项不再次执行；切换上下文停止后续调度。空选择、来源读取中或失败时禁用不适用操作，来源条目仍由工作区再次核验删除保护。弹窗列表由 DialogBody 滚动，复用已有组件、语义色及焦点契约，无新增依赖。

带 Zotero 或 MinerU 来源记录的条目只允许隐藏／恢复，行内菜单、右键菜单、书架和详情侧栏统一使用来源隐藏操作；删除原论文引导至来源端。工作区在移入回收站及彻底删除前重新核验来源记录，损坏的来源记录阻止删除。旧回收站中的来源条目只能恢复，批量清空跳过它们及其下属记录。来源隐藏按本地条目 ID 原子保存，兼容原 Zotero 隐藏记录并允许恢复；目录扫描不会撤销隐藏。本地笔记、标签等阅读增强继续按本地副本规则保存，来源数据的明确写回沿既有逐次确认流程。

“已隐藏”在条目库顶部提供直接入口，选中论文后在详情侧栏头部继续提供入口；Zotero／MinerU 条目详情提供隐藏／恢复操作，隐藏列表的操作列提供直接恢复。进入隐藏列表清空标签与搜索等遗留筛选并返回资料库导航，避免已隐藏论文被其他条件遮住。来源启用偏好与扫描目录配置分离：目录未配置只停止扫描，不撤销本地副本的管理能力；显式关闭来源仍隐藏其列表内容。隐藏状态由工作区持久化，catalog 丢弃会覆盖新操作的旧读取结果；读取失败明确显示重试。沿用原列表滚动、单击预览、双击打开和右键菜单契约，无新增滚动区或依赖。

论文行单击选中并在左侧“条目详情”显示对应内容，不打开工作区页签；双击或 Enter 打开正文，右键菜单和行内按钮不触发行打开。选择归 App／Workspace，详情复用 EntryContentSidebar，表格和书架保留原滚动及拖拽契约。

条目库标题列最小宽度为 160px，默认宽度仍为 420px；拖动与键盘调整沿用列宽 hook，保留已有列宽偏好。单行标题继续截断，悬停或键盘聚焦标题时通过共享 Tooltip 展示可换行的完整标题，避免与浏览器原生 title 提示重复；Escape 和滚动沿用共享气泡的关闭规则。气泡状态归 Tooltip，表格仍拥有滚动，标题预览不改变条目选择、单击／双击或行键盘激活契约。

条目库操作列直接平铺图标按钮，不设“操作”下拉入口；查看详情、解析／重试、回收站或来源导入／隐藏／恢复按条目状态显示，失败条目不重复显示重试与重新解析。行内按钮复用 TooltipIconButton、共享 Button／Tooltip 和现有 Lucide 图标，悬停或键盘聚焦显示文字气泡，按钮保留可访问名称；禁用项通过外层触发区域显示提示，提交／解析中使用旋转图标并尊重减少动态效果设置。操作列采用紧凑默认宽度，保留用户已有列宽；空间不足时换行，所有操作仍可见。按钮与右键菜单复用 LibraryPaperMenuItems，来源导入按钮复用 SourceLocalCopyButtons 和原 Provider；表格、右键菜单及书架均移除“在右侧打开”。右键菜单打开或执行管理动作时将对应条目设为当前选中项，同步左侧详情并保持整行高亮；行内操作不冒泡触发行打开、拖动或双击。来源条目继续只提供隐藏／恢复与导入本地，本地条目沿用回收站确认。选中项仍归 App／Workspace，提交状态和确认仍归原解析、来源与条目操作组件；表格／书架继续拥有滚动，按钮沿用 Tab、Enter／Space，菜单保留方向键及 Escape 契约，无新增依赖或滚动区。

宽窗口将浏览路径、条目数和操作合并到同一行；标签管理、关系图、来源检查、阅读统计使用一致的次要操作样式，创建条目保留主按钮及文字。筛选行按窄搜索、单选滑动来源切换（全部／本地／Zotero／MinerU）、标签页范围、排序与显示设置分组；根列表不重复展示“全部论文／未分类”。Zotero 和 MinerU 在设置中分别启停；关闭后保留已复制的本地数据和映射，但停止扫描，并隐藏该来源的筛选选项、来源条目和相关统计。分屏时搜索独占一行，键盘顺序与视觉顺序保持一致，长标签路径截断并保留完整提示。标签场景在空间不足时将路径独占一行、数量与操作并排，避免独立空行。

状态仍归 EntryLibraryView 和原设置 hook，表格／标签笔记列表保留原滚动所有权；复用 Button、SearchInput、Select、ToggleGroup、DropdownMenu 与语义色，无新依赖。控件的 Tab、Enter、方向键、菜单关闭和表格拖放契约沿用现有实现；页面头部不新增滚动区，加载／错误时保留范围切换和清除筛选，标签管理沿用禁用状态。

### 翻译来源配置

翻译分为单词释义、选中文字、单片段、段落逐句对照、整篇与批量五类。默认来源用于选择“跟随默认来源”的行为，各场景可单独指定且不受默认变更影响。所有类型均可选择小牛翻译、DeepL、Azure、Qwen-MT 或已有模型连接；旧默认翻译模型迁移为对应的已保存连接。单词的本地词库优先可关闭；旧选区服务和各场景选择迁移时保留原含义。来源失效明确提示，不能擅自替换；已保存译文和暂停任务不因配置变化自动重译。

翻译页面上方为“翻译模型与服务”，下方为“翻译行为”，随后是自动翻译开关与范围。小牛、DeepL、Azure、Qwen-MT 各占一条默认收起的独立配置行，点击或键盘激活名称展开表单；可以同时展开多项。行尾显示未配置、已配置、未保存、处理中、操作失败或恢复草稿状态。“大模型连接”作为列表最后一个独立折叠项，标题下提示复用系统连接，展开显示已有连接名称、模型和配置入口，下方说明到“翻译行为”选择使用。连接数据仍由 SettingsPanel 持有，默认模型选择归下方行为区，不建立另一份配置或密钥。服务加载失败不隐藏大模型入口；模型未就绪、未配置和已配置数量分别呈现。

来源草稿归 TranslationSourcesSettings，复用 useSettingsAutosave 串行保存和关闭保护；服务读取归 SelectionTranslationSettings，每个 TranslationServiceForm 独立持有配置、密钥草稿、验证状态和关闭保护。折叠复用 SettingsDisclosure 的原生 details/summary，正文保持挂载，收起不保存、不丢弃、不测试连接；未保存内容定位和待恢复草稿会展开对应表单。复用 SettingsGroup、SettingSelect、Input、Button 与语义色，无新依赖。settings-viewport 独占纵向滚动；折叠标题可通过 Tab 到达、Enter/Space 激活，收起后的字段不进入键盘导航，表单和浮层沿用原键盘契约，无新增拖动。

服务字段预填官方地址，API Key 为密码输入，旧密钥只显示已配置标记。测试只提交固定示例；“验证并保存”成功验证后才保存配置，失败保留输入。地址变化清空正在输入的密钥，避免误发至另一地址；切页保留草稿，关闭时保护未保存修改，迟到响应不得恢复已放弃的输入。保存的服务配置互不覆盖，密钥仍按服务和地址保存到本机凭据库，读取不回传。翻译目标为简体中文，费用以各服务账户为准。

专用服务直接翻译文本，不调用大模型生成背景或结构化提示词。全文任务复用现有逐片段保存、进度、暂停、继续和取消；暂停任务通过非敏感配置指纹固定原服务，配置改变时要求恢复或新建任务。公式、代码和链接等非正文结构在本地保留，长文本有界拆分，普通正文按原 segment 整体提交，仅超长内容按安全边界分块；逐句展示复用保存的整段译文并在本地对齐。阅读详略的中文译文沿用段落来源，取消订阅中止专用服务请求；详略内容生成仍使用助手模型。

### 解析论文标题核对

标题核对状态由 EntryTitleConsistency 持有，并在概览及 PDF 标题右侧复用：检查中显示可感知的旋转状态；明确匹配或已确认时不占位；不一致、无法确认、读取或模型失败时保留警示与详情入口。弹窗内显示当前名称、可核实的模型建议或失败原因，分别提供修改与“确认当前名称无误”；“稍后处理”不撤销提醒。确认结果归工作区持久化，按当前标题、PDF 显示名称及解析版本核对，变更后重新检查；多视图确认后同步更新。标题栏不新增滚动，弹窗使用共享有界布局，键盘、焦点和关闭行为沿用 Dialog。

### 研究构思工作区

研究构思入口固定在左侧功能栏底部、设置上方，复用 ActivityButton 的选中、焦点和键盘操作。侧栏和页签状态仍由 App 持有，导航不新增滚动或拖动；上方六个常用入口的滑块不包含研究构思。

论文卡片库接入与其他工具相同的可折叠侧栏；独立构思页签持有画布和卡片详情，二者通过同一工作区状态共享数据。侧栏独立滚动并在切换工具或折叠时保留生成任务和未确认草稿；画布不显示滚动条，空白处拖动平移，按钮缩放与复位。点击导航打开页签与侧栏，重复点击收起侧栏；助手沿用现有侧栏和对话状态。

后台默认按已解析论文串行生成本地草稿，可暂停、重试，失败只保存脱敏分类；已有用户卡片和成功草稿不会被覆盖。新草稿分开背景、纯问题、方法组件和约束，论文关系与模式匹配标记为 AI 归纳；仅将有本次提供正文片段来源的关系保存。长文抽样而非仅取开头，部分正文明确展示。草稿可逐张编辑核对，也可直接加入画布并标记为待核对；手动重新整理是独立预览，确认前不覆盖原草稿。仅接受输入正文中、属于该论文的来源标记，原文摘录和定位供用户核对，未关联来源明确显示，不能声称结论已核实。查看来源先校验片段与摘录，失效保留快照并提示，不跳至猜测位置。界面说明在线模型会接收解析正文。

侧栏顶部用共享 DropdownMenu 的标题菜单切换构思列表／卡片库，旁边的加号随当前面板创建构思或卡片，未确认草稿在切换后保留。左侧使用共享 Card 展示可直接拖动的用户、论文草稿和科研模式卡片；搜索只过滤当前候选卡片，不再混放独立论文检索入口。空画布可自行创建纯研究问题，或从已有问题开始。

选中节点在节点旁弹出共享 Popover 气泡，展示按类型定义的下一步分支；选定后收起气泡，画布只展开当前一个待填空位，卡片底部“下一步”可重新打开。左侧不再重复展示“选择下一步”说明。空白点击／平移保留选中，再次点击同一节点或 Escape 取消；气泡随画布平移和缩放定位，铅笔按钮再打开编辑器。问题可以探索方向、尝试方法、拆分子问题或补充约束；其他节点沿各自规则继续扩展。虚线位置为临时建议，不保存为空节点；选择位置后侧栏严格过滤可接收类型并清除过时筛选，拖入或点击填入一次性添加节点及有向关系，不匹配类型原位提示。推荐仅表达结构兼容性，不声称论文语义相关或方法有效。临时选择归 IdeationContext，衔接规则归 ideationBranches，布局状态归 useIdeationLayout，坐标与路径计算归 ideationLayout／ideationRouting，画布仍独占平移／缩放／拖动，侧栏及详情分别滚动。复用现有按钮、菜单、焦点与按下反馈；高频选卡不引入装饰动画。自动聚焦分支保留可读缩放，选空位时移动视野使其可见；显式适应画布可缩小查看整体。异步草稿沿提交时的构思和目标落位，错误保留内容；切换或删除构思清除临时选择。

选择构思只切换当前画布，保留构思侧栏，不打开助手、不写入输入框、不自动附带构思摘要。当前撤下“与助手讨论”及助手回复送入卡片的入口。后续按“可引用的构思对象”设计：像论文一样由用户显式引用，以稳定 ID／版本标识一条构思，发送时取得该构思的节点局部内容、关系和论文证据快照，保留来源与用户假设的区分。此引用流程尚未实现，不以展示系统提示词作为产品交互。

真实节点的已保存坐标保持稳定：打开构思只修复重叠，点击“自动排列”才重新布局整张图；添加节点、填入空位、编辑关系和选择分支不会整体重排。待填空位与正式卡片等大，优先靠近当前节点横向衔接；右侧已占用或画布逻辑宽度小于 624px 时优先放在相邻空行。类型选项共用最近可用位置，一次只呈现一个空位及一条虚线。填入时采用原坐标，同时保留原节点及视野；空位消失，气泡可以重新请求同类型分支。布局状态与画布宽度归 useIdeationLayout，候选避让归 ideationSlots；Canvas 的 ResizeObserver 仅报告可用宽度，尺寸变化不重排真实节点。默认打开及聚焦保持至少 90% 的可读比例，空间允许时纳入直接相连的节点，只有用户主动“适应画布”才缩小查看全部。计数归上方工具栏，画布去掉重复的浮动操作条。只持久化真实节点位置；显式排列继续用 @dagrejs/dagre 3.1.3 处理带环、多个父节点和独立节点，图中箭头保持语义方向，固定节点不移动，连线沿空隙绕行。现有共享 UI 与 3D 力导图库不能提供此有向卡片分层布局，因此保留 Dagre，渲染仍用共享组件和语义 token。

侧栏卡片复用 usePointerItemDrag／createPointerDropSession，标题和正文都可拖动，内嵌操作按钮保持点击行为；使用 PointerPreview 而非原生 HTML5 拖放，以兼容 Tauri。拖动归当前工作区与构思，Escape、失焦、取消和面板切换均终止手势；拖放只在松开时提交，之后抑制误触点击，拖动期间暂隐气泡。按 CSS 缩放与画布缩放换算坐标；落在虚线空位时严格校验类型并使用原位坐标。键盘仍可选择空位并通过“填入空位”完成同一操作，无新增依赖。

卡片和位置沿既有存储自动保存。ResearchStudio-Idea 模式含 15 类和 31 个原始子模式，标明上游来源、版本和许可，不视为论文结论。画布卡片可拖动、用方向键移动或移除，所有拖放都有按钮／键盘替代；复制分支创建可独立编辑的节点与替代关系。用户通过卡片的“连接”动作选择目标，可编辑关系类型；AI 关系保留片段并标明归纳状态，连线、位置和卡片一起保存；移除卡片时清理关联连线，旧空位数据仍可见。自动保存与关闭保护复用工作区写入及编辑保护，失败保留本次修改；旧卡片无片段来源时明确说明。

### Zotero 本地导入

来源目录刷新只更新来源目录信息，本地独立条目保持独立。Zotero 目录索引遇到相同 PDF 时仍创建来源行，只保留文件内容哈希，不重复复制 PDF 字节；来源对照同时按原始关系和 PDF 内容哈希寻找本地条目，来源列提示“本地已存在”。明确导入时默认打开已有本地条目，“另建一份”才创建另一份；来源 PDF 有新版时，仅用户主动另建副本才读取新 PDF，已有本地内容保留。源文件与已保存 PDF 字节一致时复用本地解析和阅读增强，避免重新解析；原始来源数据从本机目录只读获取，不要求 Zotero 进程运行。

已有本地条目的 Zotero 来源行在菜单、侧栏和概览提供“导入 Zotero 笔记”。ZoteroNoteImportDialog 持有目标、勾选、读取和提交状态，默认勾选尚未导入的笔记版本；可核对文本、切换关联的本地目标和重新读取。导入前保存目标草稿，后端重新读取来源并校验所选内容哈希。同一来源笔记同一版本跳过，来源新版本新增本地笔记快照，不覆盖改稿；导入记录保留原始 HTML，图片暂在 Zotero 查看。记录和笔记正文、条目目录通过工作区导入 journal 一起发布，启动恢复未完成操作；发现外部修改则保留恢复记录并停止覆盖。此记录只表示出处，不创建来源自动更新或写回绑定。DialogBody 负责笔记列表滚动，使用共享 Select、Checkbox 和 Dialog 的键盘与焦点契约，无新增依赖和拖动。

保存弹窗将来源原文读取问题与保存错误分开持有。Zotero 无法连接或读取失败时，以非阻断状态明确“不影响保存到本地”，技术详情默认收起；没有可写来源版本时突出本地保存操作。读取请求不能阻塞本地保存，完成后忽略迟到结果；本地保存成功给出明确通知。真实本地写入失败继续显示错误并保留对话框；先保存本地、再写回 Zotero 失败时，明确分别报告两者结果，避免误报本地保存失败。沿用原有滚动、键盘和确认契约。

来源条目的“导入到本地”创建独立条目：重新分配条目、笔记、引用和批注标识，复制 PDF、已保存笔记及图片、解析资源、译文和本地标签关联；不复制阅读时长、来源绑定、笔记写回关联和回收站内容。来源扫描继续管理原镜像，不影响独立副本。工作区将来源及内容指纹保存在 `local-copy-origin.json`，完整校验后原子发布目录；解析中、内容缺失或复制期间源内容变化均不留下半成品。重复导入默认打开现有有效副本，只有“另建一份”创建新副本；移入回收站的副本不阻止重新导入。

独立复制是用户明确要求的重复内容，不重复触发 PDF 去重确认。成功后再询问“是否隐藏来源条目”，关闭或保留显示不修改隐藏状态；隐藏失败保留副本并允许只重试隐藏。来源列显示“已导入本地”，本地条目标识“独立副本”，侧栏和概览可打开对应条目。根应用的 SourceLocalCopyProvider 持有复制、完成与隐藏状态；复制前保存对应条目的笔记和片段编辑，保存失败则中止。对话框复用 Dialog 焦点、Escape 与键盘契约，不新增页面滚动区、拖动手势或依赖；复制中禁用重复入口，切换资料库忽略迟到结果。

左侧 Zotero 分类与标签默认仅显示前 2 个分类和前 3 个标签，长名称截断并可查看完整提示；其余数量与“在条目详情查看全部”一起显示，点击打开对应条目的概览页签，完整编辑沿用条目编辑页。可见项保留快捷添加；“选择其他来源分类或标签添加”通过共享 Select 选择任意收起项后核对本地路径。完整列表继续由概览／编辑页的外层负责滚动，侧栏不增加嵌套滚动区。

Zotero 分类和标签只作为来源信息，保存在来源 sidecar，不自动创建、匹配或覆盖 NeuInk 标签。扫描刷新只读分类与标签，旧记录在扫描时补齐；已有本地标签保留。条目概览、左侧详情和编辑页复用 ZoteroOrganizationInfo，提供显式“添加到我的标签”：先核对目标路径，可改名或复用本地路径；来源标签中的斜杠默认转为全角，分类路径则明确作为层级预览。概览和侧栏复用原追加标签接口，不覆盖其他元数据；编辑页只追加到草稿并随条目保存。来源更新弹窗不再提供追加来源标签。来源数据归工作区扫描／catalog，复制对话框持有短暂草稿及错误；外层页面继续独占滚动，按钮、输入框及 Dialog 沿用键盘与焦点契约，无新增拖动或依赖。

来源笔记保留导入原文、上次确认写回的来源内容和对应的本地正文／标题基线；本地改稿与来源更新独立。重新启动仅有本地修改时不报来源更新；确认写回只更新该笔记的已知版本，之后 Zotero 再次改动才提示。旧导入记录从保留的原始 HTML 判断本地改稿，不能用现有本地正文冒充导入基线。笔记编辑页显示来源及本地改稿状态，左侧条目详情的笔记行显示“Zotero · 本地副本”；保存和版本冲突继续沿用原有确认、草稿和比较流程。

条目库共用现有论文列表和本地标签树；配置 Zotero 数据目录或 MinerU 结果目录后，启动、设置变化及重新检查时将新论文复制为本地条目并记录来源对应关系。根列表不再重复显示“全部论文／未分类”切换；全部／本地／Zotero／MinerU 单选来源切换与标签、搜索及解析筛选组合使用。来源归属从条目 sidecar 读取并显示在独立“来源”列，未配置目录时不创建条目。同步进度显示在列表工具栏附近，列表正文继续独占滚动；已有副本的来源内容变化、已消失的来源项和未完成的同步在每次启动检查后由有界详情弹窗逐篇提示，不在列表上方重复显示警告。可逐项采用来源标题、字段及 PDF 显示名称，PDF 内容、解析结果和笔记不自动覆盖。NeuInk 的普通编辑只修改本地副本；只有来源笔记经用户逐次确认后才写回 Zotero。Zotero 行内“隐藏”只记录在 NeuInk 工作区，左侧“已隐藏”视图可恢复；本地副本及 Zotero 源数据均不删除。来源筛选、隐藏和恢复沿用标准控件的 Tab／Enter／Space 契约，无新增拖动或 UI 依赖。

来源更新按来源条目及内容指纹记录“已核对”，同一版本不再反复提示；再次变化时重新提示。操作列将解析主操作与统一的“操作”菜单并排，隐藏、打开、重新解析和回收站操作复用右键菜单语义；旧列偏好首次升级时展示新增的“来源”列。来源笔记在 NeuInk 自动保存为本地草稿；手动保存直接打开差异弹窗，自动并排展示 Zotero 原文、本地拟写入内容及逐行增删，无“先比较”的中间按钮。优先展示上次保留的来源原文并明确标注，后台读取当前 Zotero 原文；未连接、读取中及失败时仍可取消或保存本地，仅当前版本读取成功后可确认替换。写回要求 Zotero 10+ 运行且允许本机访问；确认后按既有 API 授权、备份和对象版本条件写入，不直接修改 Zotero 数据库。来源读取有短超时，迟到响应不能覆盖新一轮预览；本地内容变动、保存失败或来源冲突均阻止写回并保留草稿。差异与读取／保存状态由 ZoteroNoteSaveDialog 持有，原文基线归工作区笔记同步记录；笔记编辑器的滚动区、Ctrl/Cmd+S 和文件操作保持原契约，弹窗复用有界 Dialog 与 DialogBody，不增加拖动或依赖。

设置“导入与解析”配置 Zotero 数据目录，导入入口仅在条目库。没有配置时自动查找本机资料库；发现多个时由用户选择。打开导入窗口及目录变化后自动读取列表，仍提供刷新和失败重试。普通附件从数据目录读取；相对路径链接附件需要基础目录，仅在无法解析时展示选择入口，并优先读取 Zotero 配置。持久设置归原 AppSettings、导入关联归条目 sidecar；窗口持有筛选、选择、分页与导入进度，DialogBody 独占纵向滚动并复用共享滚动条样式，沿用原生键盘操作，无新增拖动。目录变化清除旧结果，迟到读取不得恢复旧列表；保存失败保留原目录和选择。

复用共享 Dialog、Table、SearchInput、Select、Checkbox 和 Button，所有颜色使用语义 token。DialogBody 是唯一纵向滚动所有者，头部和底部操作固定；每页 50 行、长标题和附件名截断但保留完整 title。分类包含子分类；全选作用于当前筛选结果，跨筛选保留选择并明确提示。键盘沿原控件 Tab／Enter／Space 操作，不增加拖动手势。写入期间禁止关闭／改目录／改选择，停止会完成当前论文再退出，关闭页签沿现有未保存保护；失败项保留选择供重试，已完成条目不重复执行。

导入是只读读取源库、显式复制到 NeuInk，加载、无文献、无匹配、已在本地、附件缺失和错误分别展示。不得把目录发现或读取成功宣称为已导入；附件未下载时明确“仅导入信息”，不自动取云端附件或启动解析。不以网页示例检查替代原生 Tauri 视觉验收。

### PDF 图片与表格放大查看


当前 PDF 页持有临时打开状态，Dialog 管理焦点和关闭，useImageViewport 独占图内滚轮缩放／主指针拖动，不创建图片滚动条、不透传 PDF 缩放。首次完整适应窗口，支持按钮及 +／−、方向键和 0；Escape 拖动时取消拖动，否则关闭，点击窗口外空白关闭，焦点回到阅读页且不改变阅读位置。图像优先解析原图，失败回退原 PDF 裁剪；表格优先裁剪以保留原版式。仅渲染目标区域，最长边 2560px、最多 400 万像素，关闭或切换取消渲染并忽略迟到结果；加载、失败和重试原位显示。只读可用，不新增依赖、写盘或模型调用。

### 阅读分屏联动模式

同一论文的 PDF／PDF、重排／重排及 PDF／重排可见分屏共用页签栏锁链按钮，点击在“同步滚动”和“点击联动”之间切换。同步滚动双向跟随阅读锚点；点击联动只响应片段、目录及显式导航，普通滚轮、拖动滚动条和空格平移各自独立。状态归 App 的 ReaderPreferences，保存为本机偏好，缺省为同步滚动；切换只改变规则，不立即对齐两侧。不同论文不联动；笔记引用和片段记录继续沿用各自的显式定位，不声称支持连续滚动同步。

ReadingViewSession 按资料库和论文识别可见阅读面，ReadingNavigation 统一区分主动滚动、点击目标和被动定位，PDF／重排适配器负责页码、片段与页内／段内偏移；PDF 留白映射到片段边界，不能按空白比例跨过无关段落。各阅读器仍独占正文滚动、缩放与历史；不共享缩放或横向滚动。被动定位不抢键盘焦点、不回传广播，隐藏页不接收；来源引用的定点跳转仍只作用于指定副本。切换模式、用户主动操作或卸载取消过时校正和待发帧，不重建文档或丢失阅读位置。

按钮复用 Button、Tooltip 和 Link2，文字区分两种模式，aria-pressed 表示连续同步是否开启；Tab、Enter、Space 沿用共享按钮行为，不触发页签选择／拖动。原有分屏分隔条继续拥有调整宽度的手势。没有新增依赖、后台轮询或论文写盘。

### 阅读固钉

PDF 解析片段右键菜单提供“固定”；图片、表格、公式、段落和列表项复用原解析内容，列表仍先明确操作范围。固钉由当前阅读面的 ReaderPinnedSegments 持有，按片段去重，多块可独立移动和关闭；重复固定聚焦已有窗口。固钉属于本次阅读会话，不写入笔记／批注或工作区文件，切换论文、资料库或 PDF 文档时清理，不跨分栏共享。

固钉通过 Portal 挂在阅读容器中、与 PDF 滚动节点并列，滚动／翻页／PDF 缩放不改变其位置和尺寸。PDF 继续拥有正文滚动，固钉正文单独限高滚动、overscroll-contain；内部 Ctrl 滚轮不透传改变 PDF／应用缩放。图像优先用解析资源，缺失或读取失败时复用原 PDF 对应区域的截图缓存，显示加载、失败及重试，迟到结果不能恢复已关闭内容；其他类型复用 SourceSnapshotPreview。只读阅读可用，无模型或持久化写入。

移动只从标题把手开始，右下角调整大小，复用 usePointerItemDrag 的主指针捕获、阈值、Escape／取消／失焦／切换／卸载清理；固定面板关闭自动滚动，几何按帧更新，不重绘文档。界面缩放只换算一次坐标，窗口收缩时限制在阅读区，隐藏零尺寸不覆盖位置。方向键移动／调整 5px，Shift 为 20px；拖动中 Escape 回滚，面板聚焦且未拖动时 Escape 取消固定。按钮和正文选字不触发拖动；关闭后返回另一固钉或阅读区，定位原文复用已有阅读导航及返回历史。没有新增 UI 依赖。

### PDF 解析筛选与提问提醒

左侧“解析”分组、条目范围菜单及页眉共用短文案“全部、未解析、已解析、解析中、解析失败、无 PDF”，顶部菜单分组标题为“解析状态”；筛选、计数及高亮状态保持同一来源。“全部条目”仍表示包含无 PDF 条目的整个文库。

解析分组中的“全部”仅筛选带 PDF 的条目并保留标签／搜索条件，沿用原 `libraryView` 状态与持久化。条目行最右侧复用 `PdfParseButton`，提交状态由按钮持有，排队／解析状态以资料库和原生解析队列为准；同一按钮提交中禁止重复请求，失败通知并可重试。未配置服务时进入现有解析设置，不自动提交；解析中的条目不可重复启动。行内按钮的指针和点击不触发条目打开或拖动，Tab／Enter／Space 沿用 Button；表格继续独占滚动，操作列最小宽度容纳文字按钮与回收站。

助手输入区的提醒由已解析的阅读上下文派生，跟随固定对象或当前 PDF，笔记、不关联内容、缺少 PDF 及解析成功时不显示。未开始／取消、排队、运行和失败有对应提示，说明解析不足会影响提问效果，并复用同一解析动作；不拦截发送，不清除问题草稿，不自动解析。消息区仍为原滚动所有者，提醒不创建嵌套滚动、浮层或新依赖。

### 设置页资料库流程的状态边界

`useWorkspaceSelection` 随设置页挂载，持有目录检查、待确认对象和执行中状态；`WorkspaceSelectionDialog` 复用共享 Dialog，仅显示检查结果与触发确认／取消。选择目录、打开最近资料库均先检查，确认后先执行未保存内容保护，再切换或创建。失败保留待确认对象以便重试，处理中禁用确认／取消并忽略 Esc 关闭请求。设置页原有 `settings-viewport` 保持唯一页面滚动所有者，弹窗沿用共享组件的焦点与键盘行为，没有新增拖动或嵌套页面滚动。

### Research 组件安装入口

深度研究归入“检索与工具 → 可选服务”，与 Tavily、Sciverse 复用 `SettingsServiceSection` 的标题、状态和分隔样式，不单独占据页首分组。安装与进程状态由原生 Research 控制器持有；设置页复用研究状态 hook，仅在“检索与工具”激活时观察。安装不会因切页或关闭设置而取消。`settings-viewport` 是唯一滚动所有者，标准 Button 的键盘、禁用与焦点契约不变，无新增拖动、嵌套滚动或依赖。

“深度研究 · Research”显示未安装、准备中、实际阶段百分比、验证中、已安装和错误；验证阶段没有百分比时不虚构进度。无资料库、其他研究任务进行中、报告尚未保存或任务属于另一资料库时限制对应操作。聊天未安装时仅提供“前往设置安装”，安装中提供“查看安装进度”，通过设置目录项 `tools-deep-research` 定位；导航和重新渲染均不得提交安装。

### 推荐标签的一次性阅读入口

PDF 顶部推荐标签浮层右对齐，视口边缘保留至少 16px 安全距离，内部使用 16px 留白，列表预留滚动条空间；只有列表滚动，底部确认操作固定。接受或拒绝由共享条目推荐状态持有并缓存，只有保存成功才标为已接受；关闭浮层不是拒绝，保存失败保留选择与重试。已处理入口从标准／紧凑阅读工具栏消失，跨分屏和重开保持一致；重新生成入口保留在条目详情，不重新激活已处理的顶部入口。复用 Popover、Button 和语义颜色，沿用 Escape／Tab 契约；入口移除后焦点返回可用的阅读工具按钮，无新增拖动。

### 模型翻译诊断交互

连接测试提供“打开错误日志”，只打开应用确定的本地日志目录。打开失败在原弹窗内显示简短错误，不泄露文件系统路径。沿用当前弹窗的请求状态、焦点与正文滚动归属；未新增自动测试、设置开关或拖动行为。

模型连接测试复用 Dialog／Button，展示选中文字和片段／批量两条真实翻译检查。SettingsPanel 持有不可变配置快照及已保存配置结果；弹窗持有请求、取消、重试和复制状态。只有正文滚动，页头与操作栏固定；Escape／关闭／卸载取消并忽略迟到结果，沿用焦点返回及 Tab 行为，无新增拖动或依赖。草稿测试不保存、不修改已保存配置状态；保存修改后清除旧结果。加载、成功、失败、超时与取消使用文字及语义色，复制只导出脱敏诊断。

> 适用范围：`apps/desktop` 中所有新增界面、界面重构和交互修改  
> 说明：本文定义后续实现标准，不代表当前所有历史界面已经符合标准。旧界面在被修改时应逐步收敛，不要求脱离具体任务一次性重写。

## 1. 产品体验目标

### 新手聚焦引导

解析引导先推荐 MinerU 客户端导出 ZIP 并导入，再介绍可选的自建解析服务。设置“导入与解析”将客户端方式置顶，提供打开已有图文教程的按钮；教程说明新建条目与向已有 PDF 条目导入的不同 ZIP 要求。用户在引导步骤中点击该按钮时，进度跟随到教程步骤，避免引导遮罩停在已离开的设置页。
导入普通 PDF 后自动提交解析在首次使用时默认关闭；只有用户明确开启并配置 MinerU 服务才会自动提交。已保存的开关选择继续生效，客户端 ZIP 导入直接使用结果。

新手引导仅在首次打开空资料库时自动显示；已有数据的用户从设置“入门与教程 → 新手引导”继续或回放。教程拥有任务、步骤、已完成／已跳过状态和自己的唯一纵向滚动区，本机进度不改变论文与笔记数据。普通说明由用户确认，操作步骤检查页面状态或明确的操作事件，不把打开编辑器当成保存成功、不把发送当成回答成功。解析或模型未配置时允许跳过，不能虚构完成。
真实翻译、写笔记、发送消息等练习不得成为“继续”的强制条件；直接继续仅完成教学说明，不代替业务操作。后续步骤不得假设可选练习已经执行：分屏、笔记等演示目标需独立准备，缺少实际资源时说明原因并允许跳过。业务 Dialog 或由高亮区域打开的浮层应可正常操作，关闭后回到同一步；隐藏浮层不能算作已打开，编辑中不能算作保存成功。新增或调整步骤时逐步验证这条契约。

聚焦遮罩使用共享 ViewportOverlay、语义表面与 `--guide-backdrop`，按 CSS 缩放后的实际坐标定位，并裁切到真实滚动容器和隐藏祖先；高亮不等于全部可操作，权限由步骤元数据明确区分观察、图文阅读和实际练习。观察步骤允许悬停但禁止页面点击、选字、滚轮、拖放和业务快捷键，临时锁定目标内部及其祖先的原生滚动容器，保留滚动位置与纵向滚动条占位，退出时还原样式；只读预览可滚动、选字复制，但不可通过按钮跳转。MinerU 图文教程只高亮自己的阅读容器，不包含标签栏，允许滚动截图、选择文字和复制链接；实际练习保留明确需要的操作，工具栏和分屏复制步骤禁止滚轮穿透，复制练习只开放当前标签的右键及菜单中的复制动作。遮暗区域禁止悬停、点击、右键、触摸、滚轮、拖放及键盘激活。透明的实体命中遮罩从视口减去高亮窗口的并集，阻止鼠标穿透和背景 CSS hover；Window 捕获阶段同时拦截业务事件及全局快捷键，不仅绘制变暗效果，背景焦点回到教程控件。目标未加载／未高亮时不授予交互权限。由当前目标实际打开的关联菜单、下拉框、悬停预览和选字工具条增补高亮，并沿用步骤权限，不因 PDF 步骤无条件放行浮层；每一步切换清理旧的悬停内容与浮层许可。交互许可与视觉聚焦共用可见目标选择。教程不夺取模态焦点；真实 Dialog 打开时隐藏遮罩并释放定位监听，在 Dialog 内保留不抢焦点的“教程仍在进行”提示，关闭后重新测量并恢复。Esc 先归真实弹窗、菜单和选择器；只有没有子浮层消费时才暂停教程。几何更新按帧合并，只在可见时注册监听及观察器，暂停／卸载时清理，不建立永久动画循环。任务切换重置教程滚动，不重置阅读位置。

欢迎页按从上到下的顺序介绍条目库、条目详情、搜索、助手、标签阅读五个入口，不展示教程内部路由规则、教学对象状态或切换教学 PDF 的按钮。打开教程时自动准备独立的 Attention Is All You Need（演示版）：有同一演示标识的条目则复用，没有时从本地资源一次性加入 PDF、已保存的 MinerU 解析结果与图片、文档笔记及来源、片段记录、批注和摘要示例译文；不改变用户原有同名论文，不复制凭据、服务地址、任务或阅读历史。重复打开不覆盖演示中的编辑。准备是后台状态，不占教程步骤；准备完成后留在当前步骤，只有用户继续才前进，第二步直接介绍 PDF，不闪过自动跳转的准备页面。准备中可暂停，迟到结果不得导航；缺资源时提供明确错误和重试，不能联网补下载或留下半成品。

原文与解析二进制由用户当前资料库提供，按其要求供本机开发演示使用，不纳入 Git，也不作为本项目开源许可覆盖的素材。公开发行前仍需确认论文及解析素材的分发许可；本机 Tauri 和便携包读取相同 `resources/onboarding` 目录。构建时素材齐全则自动携带，缺失或基础格式检查失败时跳过整套演示素材，不阻止主体和 embedding 打包；每次构建记录演示资源包含状态，旧构建副本不能代替本次资源。每次进入、恢复或回放演示都重新校验包含状态、实际资源与已有演示条目，缺少时提示“缺少演示数据，无法演示”，不覆盖用户编辑、不联网补下载。不自动提交解析、翻译或助手请求；仅摘要有预置译文，不能将它宣称为全篇翻译或实时模型输出。开发检查页使用单独进度键和内存数据，不用于证明原生阅读或真实模型链路已验收。

复用只按独立演示标识判断，不因标题相同把用户论文改成演示版；后端检查演示 PDF，新导入验证 PDF 内容 hash、片段身份与资源路径，通过同盘暂存目录完成后一次性发布。任务目录与操作说明使用不同层级，目录展示编号、当前步骤与完成／跳过状态，不引入第二个纵向滚动区。暂停控件同时提供图标和文字；暂停后复用右下角通知说明精确恢复路径，并提供直达设置入口。

进入、前进、后退及目录选步自动路由到对应教学页面，并绑定教学论文，不使用当前活跃的其他论文替代已绑定对象。遮罩只为当前步骤的目标留透明窗口：欢迎页展示导航整列；逐项介绍入口时，同时展示对应按钮与相邻内容面板，设置入口则对应完整设置页。两个区域分别定位，并按步骤契约授予权限，观察导航时不能误点击切页或收起侧栏，说明面板避让二者；其他步骤遮暗导航，不常驻显示整列。教程正文仍为唯一滚动所有者。路由按步骤去重，普通重渲染不反复切换、抢焦点或清空阅读位置；模态仍沿原契约让位。暂停后的迟到准备结果可保存进度，但不得跳转页面。

步骤说明须在路由完成、目标可见且连续两帧几何稳定后显示，PDF 页面还须完成位图绘制；不同步骤不复用旧定位。同一目标已显示后的滚动、缩放和截图加载采用逐帧更新，不重新进入加载状态或卸载演示，相关提示离开实际阅读容器后隐藏，不能画到旁边的界面上。等待期间仅呈现固定位置的加载提示、暂停及可用的跳过操作，不先将新说明显示在默认角落。说明高度在绘制前测量，避免用加载提示的高度定位正文；定位帧及观察器在暂停、模态让位和卸载时释放。

教程说明面板受视口高度限制，面板本身裁切溢出，正文作为唯一可滚动区域；任务目录再长也不能挤出固定的暂停、跳过和继续按钮。窄视口及放大状态下验证底部操作可见、可点击。

教程面板优先置于聚焦目标及其关联浮层之外的遮暗区域；按左右、上下的实际空间选择位置，侧边较窄时允许收窄面板，上下空间有限时限制面板高度并保留正文滚动。定位使用正文未裁切的自然高度，不能把上一次位置裁切后的高度反馈为新的内容高度，避免说明面板在侧边与底部反复跳动、使按钮点击落空。仅当视口几乎被聚焦目标占满、没有可用暗区时，才采用遮挡面积最小的视口内位置，操作按钮仍须可见。

解析块教学在演示论文的真实可见 PDF 块上一次性描边，同一步固定示例块，不因布局调整换成另一个段落；悬停步骤使用阅读器自己的预览，并允许预览内阅读和复制。这些观察步骤不要求用户制造鼠标事件才能继续。选字教学必须等 PDF 文字层有可选文字才展示，使用不写入真实选区的视觉演示；拖选效果之后自动显示与阅读器共用的选区操作控件、对应文字及“演示 · 不执行操作”标记，不使用一行文字替代操作框。演示控件禁用且不注册业务回调，不自动提交翻译、提问、复制或批注；本步只观察，后面的批注练习才允许实际拖选。操作框按实际可见 PDF 区域避让边缘，并持有独立选区优先权防止悬停遮挡；减少动态效果时立即呈现。演示标记和优先权随步骤退出清理，布局变化后按真实块的可见位置更新，不持续占用动画帧。

每个教程步骤在说明区同时给出当前要做的操作和可观察的结果，不把演示效果冒充已执行的写入或模型调用。具体控件使用不截获指针的短标签与描边，标签随目标滚动和布局变化定位；当一步介绍多个概念时，说明项的悬停或键盘焦点与真实界面位置一一对应。操作提示只能要求点击当前高亮且允许交互的区域；需要右键片段时，高亮和交互许可必须覆盖 PDF 片段层，而非只覆盖其兄弟节点中的画布。

NeuInk 是面向长期阅读、研究和知识整理的 Windows 桌面工作台。界面应当像可靠的生产力软件，而不是营销页、AI 演示面板或卡片展示站。

所有界面遵循以下原则，按优先级排序：

1. **信息和任务优先**：用户首先看到当前对象、状态和下一步操作。
2. **行为可预测**：点击、拖动、保存、关闭和切换在不同模块中使用同一套语义。
3. **高信息密度**：通过层级、对齐和留白建立秩序，不用大卡片和大图标制造稀疏感。
4. **状态可信**：加载中、未保存、保存中、已保存、失败和只读必须准确且互斥。
5. **渐进呈现**：常用操作直接可见，低频操作进入菜单；详情可以悬停预览，但不能只靠悬停访问。
6. **复用优先**：优先使用仓库已有组件、库、工具和交互模型。
7. **桌面优先**：以键鼠、分屏、可调整区域、长列表和长时间连续使用为主要场景。
8. **概念收敛**：优先给已有内容增加可撤销的状态或操作，不为相同内容新增一套对象、编辑器和分类。跨入口展示复用原内容。

## 2. 实现来源与复用顺序

实现 UI 前，按以下顺序检查，不得跳过已有能力直接创建新组件或引入新依赖：

1. `apps/desktop/src/components/ui/` 中的共享组件；
2. 已有业务共享组件和 hooks；
3. 已安装库提供的能力；
4. 在共享层扩展已有组件；
5. 仅当以上均不适用时创建新的业务组件；
6. 仅当现有依赖无法可靠完成任务时引入新依赖。

当前前端基础设施：

| 需求 | 首选能力 | 使用要求 |
| --- | --- | --- |
| 基础控件 | `components/ui` 中的 shadcn 风格封装 | 业务组件不要重复实现 Button、Dialog、Menu、Input、Table 等基础控件 |
| 无障碍交互原语 | `radix-ui` | 如果已有本地封装，必须使用本地封装，不直接使用 primitive |
| 样式与布局 | Tailwind CSS、`cn`、现有 CSS 变量 | 不在业务组件中建立第二套颜色、圆角或阴影系统 |
| 变体管理 | `class-variance-authority` | 多处使用的尺寸或状态必须收敛为变体 |
| 图标 | `lucide-react` | 不混用其他线性图标库，不用图标代替无法理解的概念 |
| 富文本与 Markdown | Tiptap 及现有 extensions | 先扩展现有编辑器能力，避免并行引入另一套编辑器 |
| 长列表 | `@tanstack/react-virtual` | 先测量性能；达到实际瓶颈后复用现有虚拟化能力 |
| Toast | 现有 `useToast` / Sonner 基础设施 | 同一动作不得同时弹多个重复通知 |

新增依赖必须在改动说明中回答：

- 当前仓库为什么无法完成；
- 新依赖替代了什么，而不是重复了什么；
- 体积、维护、许可证和 Tauri WebView2 兼容性；
- 是否提供了行为测试和回退策略。

## 3. 视觉基础

### 3.1 颜色与表面层级

颜色来源以 `apps/desktop/src/styles/theme.css` 为准。组件应使用语义类，不直接复制当前十六进制值。

| 层级 | 语义 | 推荐实现 |
| --- | --- | --- |
| 应用背景 | 工作区之外的底色 | `bg-background` |
| 主内容面板 | 用户实际阅读、编辑和浏览的区域 | `bg-card` 或 `bg-white` |
| 次级区域 | 工具条、筛选条、表头、分组背景 | `bg-muted` |
| 悬停 | 可交互行的轻量反馈 | `hover:bg-muted` 或 `hover:bg-accent` |
| 选中 | 当前对象或活动视图 | `bg-accent`，配合文字或边框，不只依赖颜色 |
| 浮层 | 菜单、Popover、HoverCard、Dialog | `bg-popover` |

强制规则：

- 主内容区域应与应用背景有清晰层级；默认使用白色内容面板和浅灰应用背景。
- 固定表头、粘性工具条和滚动覆盖层必须使用**不透明背景**。
- 不在承载正文、列表或表格的区域使用玻璃拟态、背景模糊或半透明渐变。
- `primary` 只表示品牌、主要动作、焦点和选中状态，不用于大面积装饰。
- 成功、警告、错误和信息状态使用 `success`、`warning`、`destructive`、`info` 语义变量，不随主题色改变含义。
- 除数据可视化外，不新增随意颜色；数据颜色必须有图例或直接标签。

### 可选材质扩展

每日看板的拟物图表复用原 SVG 绘图及阅读数据：柱形／K 线使用正面、顶面和侧面呈现厚度，折线使用高光线材与立体节点，热力格用凸起色块和凹入空格区分有无阅读。正面高度、节点中心和 K 线高低点仍使用原比例，不旋转坐标轴、不改变统计数值；侧面厚度受数据高度与列间距限制，零值不生成柱体，下降 K 线继续保留空心语义。统一暖铜／铜绿数据色、固定左上光源及纸面刻度，图表框和气泡沿用 theme.css 的材质变量；只在 `data-appearance="atelier"` 生效。

图表材质由 ReadingChartMaterial 和 atelier-charts.css 提供，无 WebGL、动画循环或新增依赖。状态仍归 ReadingTrendChart／原缩放与互换 hooks，主图仅在 Ctrl + 滚轮时调整范围并拦截浏览器缩放，普通滚轮交由看板内容区滚动；悬停气泡说明两种操作，滚动时收起且不接收指针。键盘日期检视保留，小图仍独立预览与切换，看板继续独占页面滚动；装饰 SVG 不接受指针，不改变点击区域。主题切换保留图形、日期、各自范围及焦点；高对比模式隐藏额外立体侧面，原有减少动态效果偏好继续约束互换动画。


用户明确开启的“拟物”是独立材质扩展：`AppearanceProvider` 在 `html[data-appearance="atelier"]` 上应用 `theme.css` 的专用语义变量及 `styles/atelier.css`、`styles/atelier-controls.css` 的限定样式。原有 `data-theme` 配色预设及偏好不被替换；关闭后移除材质层。新增物件图标仅用于主导航等识别位置，小型操作保持 Lucide。此模式按用户确认的设计允许木质书架、织物、高光与实体按钮；普通模式继续遵循以上密度与表面规范。不得让未限定的拟物规则影响原模式、PDF 画布或正文选择层。

标题栏 Logo 必须沿用本地“书页＋钢笔尖”标识。普通主题使用原版蓝色 SVG；书房主题使用基于本地 Logo 生成的暖棕色平面与黄铜细边版本，颜色呼应纸张、亚麻和木质书架。不使用字母替身或额外底板。两者共用原 Logo 的尺寸与拖动区域，生成来源和提示词记录于 `shared/assets/atelier/generation-spec.json`。

`shared/assets/appearance.ts` 统一维护标题栏、原生窗口和导航图标来源；助手导航通过 AppearanceIcon 使用纸张／皮革对话图标，普通主题仍显示原线框图标。原生任务栏图标由 AppearanceProvider 的主题状态驱动，经 useWindowIcon 串行同步、取消过时加载并释放 native Image；浏览器预览跳过原生 API。只授予主窗口 `core:window:allow-set-icon`，不增加图片解码依赖。Windows 快捷方式可使用从同一暖棕 Logo 转换的多尺寸 ICO；其固定图标独立于运行中窗口的主题同步。

书架复用条目库的筛选、阅读状态、选择与动作回调，默认单击或 Enter 打开详情，提供明确分屏按钮及共用右键菜单。页眉与数据范围不随展示切换改变；原表格保持挂载以保留列宽与滚动。书架独占纵向滚动，大集合按行虚拟化；方向键、Home/End 可访问未挂载行。切换外观或书架/列表同样必须取消未完成拖动。不得使用独立的演示数据或编辑会话驱动正式书架。

用户确认的三维书本扩展复用 BookCover：标题、标签和条目 ID 来自原集合，封面不伪造出版信息。书架静止、悬停和聚焦必须保持同一 DOM 封面，禁止切换为另一套纹理排版；书封由原正面、封底、书脊、纸页和上下边缘组成连续六面体，厚度与过渡时长使用主题 token。悬停或键盘聚焦默认转到横向 −22°／纵向 6°，指针将横向限制在 −36° 至 −8°、纵向限制在 −2° 至 14°；260ms 平滑过渡，增加随角度变化的反光和接触阴影，不叠加上浮或缩放。指针更新合并到下一帧，退出、拖动和辅助偏好变化复位，尺寸与命中区域保持不变。仅书房概览可见时按需加载 Three.js，普通／玻璃模式不加载。Three.js 0.186.0（MIT）用于现有 CSS 无法提供的真实厚度、遮挡及方向光照，不替代共享控件、PDF.js 或编辑器；独立延迟模块约 522 kB／gzip 131 kB，开发类型包不进入运行产物。WebGL2 不可用、丢失上下文、减少动态效果或高对比模式保留 CSS 封面。每窗口最多三个场景，DPR 上限 2，静止不循环渲染；不可见、拖动、失焦、关闭及退出主题释放几何、纹理和上下文。Canvas 为纯视觉层、指针穿透，不截获点击、焦点、键盘或拖动。原生 WebView2 GPU 验收必须单独记录。

条目概览保留完整标题一次，将主要阅读入口并入摘要；统计使用紧凑行，标签、属性和文件信息用细分隔线组织，不重复展示条目状态。书房概览的小书封在内容宽度低于 480px 时收起；原滚动区与操作回调不变。PDF 选中文字浮层用 `reader-popover` 接入两套材质，格式工具条用 `editor-toolbar`，引用快照用 `source-paper`；格式状态通过 aria-pressed 表达，来源正文与 PDF 文字保持清晰。

条目管理入口集中于概览：页眉“编辑条目”在原页签内进入编辑页，侧栏不重复提供元数据编辑；“创建新版 PDF”和客户端解析结果导入位于“文件与时间”。无 PDF 的条目仍可直接上传。编辑页复用标题、描述、标签快速选择及属性控件，ReaderSurfaceBody 持有内容滚动，草稿归概览 surface，接入现有未保存注册与关闭保护；Ctrl/Cmd+S 保存，返回、Esc 和关闭遇到未保存内容时可保存或放弃，失败保留草稿，返回后恢复编辑按钮焦点。解析进度变化不重置草稿，其他位置更新元数据时阻止覆盖。原有页签拖动与分屏契约不变。

无 PDF 的本地条目在“文件与时间”并列提供“获取 PDF”和“上传 PDF”。获取状态由按资料库／条目去重的请求及原任务列表承载；按钮仅在缺少 PDF 时显示，进行中禁用重复获取与本地上传，失败就地解释并保留重试，成功刷新原条目并显示阅读入口。下载只补充原文件及来源，不自动解析或创建另一条目；远程全文笔记仍保留，开放版本不能被描述为期刊原版。保存前复核条目版本，已有 PDF、删除和并发编辑不被覆盖。ReaderSurfaceBody 继续独占正文滚动，普通按钮沿用 Tab／Enter／Space，无新增拖动、浮窗或 UI 依赖。

推荐标签在打开已解析论文且助手模型配置完整时默认自动生成，恢复但未激活的 PDF 页签先等待激活；已有标签不阻止生成。结果按资料库和条目缓存在本机，概览和 PDF 共用请求及结果；分屏、StrictMode 和重开不得重复请求，空结果同样视为已生成。失败保留旧结果，当前会话不自动反复重试；“重新生成”或重试成功后才替换缓存。推荐列表只显示尚未关联的路径，兼容旧缓存；添加成功后从待选结果移除并同步所有视图，失败保留选择，丢弃仍保留完成标记以避免重开后自动恢复。实际标签归属来自资料库，不由缓存推断。PDF 阅读工具栏直接展示推荐入口、生成状态及数量，浮层可选择添加、重试和重新生成，普通与并行阅读保持一致；不自动弹窗或写入标签。状态归共享推荐 store 和原设置，浮层正文独占限高滚动、动作固定，PDF 滚动与拖动保持原归属；复用 Popover／Button 的键盘与焦点契约，无新依赖。

材质控件采用 2px 小圆角矩形、平面底色、上沿／左沿的 1–2px 白色高光和下沿细暗边，不使用控件外投影或明暗渐变形成凸起。此模式的基础 `--radius` 同为 2px，卡片、条目行及状态徽标也遵循方正边角；侧栏分组标题采用与侧栏齐平的直角金属底和上下细边。开关保留原尺寸与滑动距离，轨道及滑块分别使用 2px/1px 圆角；选中以位置和轨道颜色同时表达。弹出浮层和书本物件保留用于区分层次的投影。材质细边必须与原焦点环组合，错误、禁用和只读状态仍遵循共享组件语义。Button、Toggle、ToggleGroupItem 的材质定位使用稳定的 `data-ui`，避免 Tooltip/Dialog 的 `asChild` 替换 `data-slot` 后样式失效；切换按钮同时以 `aria-pressed` / `aria-checked` 识别选中，不能依赖可能被提示层覆盖的 `data-state`。此层不改变左右分屏、控件高度或滚动所有者。

机械反馈统一由 `atelier-controls.css` 和主题动效变量管理：悬停 140ms 提亮边缘，按下 70ms，折叠／开关 180ms，使用无回弹缓动。plain/ghost 与完整按钮均按实际点击区域响应；展开标题和独立动作保持各自命中范围。选中使用压入细边，列表使用窄黄铜索引边，不让整行随 hover 位移。输入错误优先于材质边框，焦点环与材质阴影组合；表格固定列保留原投影和不透明底色。

侧栏、标签导航、快速选择与标签编辑复用 `DisclosureIcon`：外框光源固定，只有箭头旋转。展开状态仍归原组件，SidebarPanel 内容保持挂载并保留独立滚动，仅对展开内容淡入，不动画 flex 高度。SidebarPanelGroup 的手势所有者标记调整过程，取消／结束后清理；调整中关闭材质动效。Workspace tab 拖动也禁止装饰过渡。`prefers-reduced-motion` 归零材质时长并取消按钮位移与书本抬升，普通主题不受影响。

书房侧栏表面统一使用语义标记：`sidebar-toolbar` 为不透明金属底，`sidebar-canvas` 和 `sidebar-empty` 透出侧栏织物底；禁止直接借用弹窗底色作为整个搜索侧栏背景。对话消息使用纸色，通过 `data-message-role` 区分双方；搜索选中项复用暖色选中底和黄铜细边。样式只定位这些表面，不覆盖内嵌错误、警告、禁用和拖入提示。搜索状态／结果滚动仍归 SearchPanel／CommandList，对话状态／消息滚动仍归 AssistantPanel，标签状态／面板滚动与高度仍归原导航及 SidebarPanelGroup。

### 书页阅读与批注材质

PDF 可显式切换连续滚动与书页阅读，旧偏好默认连续。书页模式沿用单／双页选择，阅读区低于 860px 时临时使用单页；它不改变左右工作区分屏。PdfReaderDocumentPane 的 usePdfBookNavigation 拥有当前书页，原容器拥有滚动，现有阅读记录拥有持久化页码。页码、查找和来源跳转经容器范围的 page-reveal 适配后复用原定位函数；隐藏页组件保持挂载以保留选区草稿，仅当前与相邻书页渲染。正文拖动继续选字，纸张左右两侧的翻页按钮支持点击或向内拖动，预留侧边操作空间，阅读区聚焦后的 PageUp／PageDown 翻页；输入与正文选区不接管按键。减少动态效果／高对比直接换页。

书页翻动是 460ms 的临时 CSS 三维纸面，截取已渲染 PDF 位图与高亮，不复制成另一套文字排版，不变换真实 PDF／文字命中层。每次只保留一个动画，限制在阅读区内，结束、取消、尺寸变化、后台或卸载释放临时画布和待执行帧，无额外依赖。书房材料使用 reader-paper.css 与 theme.css token：纸边层叠、书脊暗边、织物底、胶贴和便签折角；标准／玻璃主题不获得便签纸色。annotation-paper 共用于已保存批注、悬停、页码旁批注菜单和选区／片段编辑，颜色沿用高亮数据。页边入口打开原批注编辑器及对应批注，不创建第二套批注数据。阅读书签来自打开条目时已保存的位置，沿用阅读记录；不代表多书签收藏功能。

翻页动画期间统一隐藏原纸面的文字、高亮与纸边，动画下方预先放置目标页的位图及高亮，并通过随卷曲位置和抬起高度变化的阴影区分纸张；双页纸背显示对应目标内容，真正的目标页及页码在动画完成后同步提交；双页的另一侧保留原内容至提交，避免提前换页产生局部静止的错觉。同目标的重复操作不重启动画，保留最新定位回调；取消后恢复原纸面，不执行过时跳转。

### 可选玻璃扩展

用户要求的玻璃材质优先呈现背景透色和轮廓透射，使用低覆盖率底色、克制的背景模糊、细反射边与边缘折射。窗口以中性底色分层，环境光只绘制在外壳一次；禁止在工作区和阅读器内重复铺蓝紫渐变或把文字、分隔线整体染蓝。不能叠加白色面渐变、四面凸边或按键投影，把玻璃做成实体塑料；悬浮阴影只用于外壳和浮层。此模式允许胶囊按钮、圆形图标按钮、圆润浮层和侧栏轮廓；复用原尺寸与命中区域，不让按下或悬停移动控件。主按钮使用高对比度蓝底及白字，开关的选中轨道保留明确强调色。只在控件和导航使用材质，PDF、笔记、表格及固定表头仍清晰实色。

用户通过相同隐藏搜索菜单可选择原有风格、拟物或玻璃。玻璃以 `html[data-appearance="liquid-glass"]` 限定，token 归 theme.css，外壳与浮层材质归 liquid-glass.css，共享控件归 liquid-glass-controls.css。它是对上方普通模式规则的显式扩展：导航外壳、输入、共享控件和独立浮层可使用半透明背景；正文、表格及固定表头仍用实色。同一工具栏或浮层共用一次背景取样，内部按钮不重复模糊或创建折射资源；分段选择器共用底色和选中片。useGlassMaterial 提供鼠标高光，glassOptics 提供浮层及独立悬停控件的背景边缘折射；不复制正文像素，不移动命中区域，不新增滚动或拖动所有者。用网格与真实滚动内容验证透光，同时检查深色背景下的文字，不能只凭浅底上的阴影判断材质。沿用本地 Logo，错误和焦点优先于材质。

用户明确要求的概览与 PDF 适配复用 ReaderSurfaceFrame：仅玻璃模式允许概览信息区半透明、阅读工具栏悬浮；PDF 画布、文字、选区和笔记正文仍清晰实色。框架只拥有工具栏测量及本区域滚动材质状态，原正文保留唯一滚动所有权；滚动时提高覆盖率与细反射边，停止后恢复，工具栏不位移或隐藏。首屏、片段导航、右侧笔记及 PDF 定位须避让实测高度；支持窄分屏与 CSS 缩放，保留键盘、拖动及编辑器实例。普通／书房模式仍采用原网格流式工具栏。

降低透明度是独立可持久化偏好；界面明确说明它会关闭半透明、模糊和折射，theme 菜单提供“恢复通透效果”。只在玻璃模式挂载 `data-glass-transparency="reduced"`；切回其他外观移除标记。系统减少透明度／高对比度偏好在浏览器支持时优先；不支持模糊时回退实色。减少动态效果关闭动态光影与光学资源；拖动时取消指针光影，侧栏宽度拖动暂停外壳模糊。光影只在指针事件后合并到下一帧，无持续渲染循环；光学贴图只随几何尺寸改变，限制分辨率和缓存。SVG 背景折射仅面向 Chromium/WebView2，并不等同于 Apple 原生光学渲染。设计依据与范围见 [液态玻璃方案](../design/liquid-glass-theme.md)。

### 3.2 字体与字号

使用 `theme.css` 定义的 Geist / Segoe UI / Microsoft YaHei UI 字体栈。

| 内容 | 建议字号 | 约束 |
| --- | --- | --- |
| 页面或对象主标题 | 16px | 单行优先，过长截断并提供完整信息 |
| 区域标题 | 13–14px | 使用字重建立层级，不重复加背景卡片 |
| 正文和表格内容 | 13px | 默认密度基线 |
| 次要信息 | 11–12px | 保证对比度，不低于 10px |
| 状态栏极简信息 | 10–11px | 只用于非关键、短文本 |

不要通过同时增大字号、加粗、加色和加背景来表达同一层级。通常选择其中一到两项即可。

### 3.3 间距、尺寸与圆角

- 优先使用 4、8、12、16、24px 的间距节奏。
- 紧凑列表行高为 32–40px；多行信息行高通常不超过 48–56px。
- 默认按钮使用现有 `Button` 尺寸：`xs`、`sm`、`default`；不要在业务组件重复写相近尺寸。
- 条目库／详情、搜索、助手和标签阅读的顶栏共用 `.side-head`，保持 36px 高及统一字号、字重、边距和主题背景；顶层名称统一中文，筛选和路径放在标题栏下方。
- 页面内容内边距通常为 12–16px；同级区域保持一致。阅读/编辑工作区外层不叠加灰色边距，内容表面铺满可用区域，页面内部自行安排信息间距。
- 使用现有 `--radius` 和组件圆角。只有 Badge、状态点和明确的胶囊筛选项使用完全圆角。
- 普通内容区域优先用边框分层；阴影只用于菜单、Dialog、拖动预览和真正悬浮的面板。

### 4.1 信息架构

页面从上到下最多包含：

1. 一个页面/对象标题区；
2. 一个主操作或筛选工具条；
3. 一个承担主要任务的内容区；
4. 必要时存在的状态栏或详情面板。

同一页面不要重复出现多个含义相近的标题、模式切换和操作栏。主任务开始前的固定区域原则上不超过两行。

集合页面的主标题反映当前浏览对象或分类，不统一使用模块名。标签名称作为主标题，路径、筛选范围和数量作为次要信息；长名称截断并提供完整值。侧栏与正文的分类名称复用同一份定义，加载/失败时不把临时空数组显示成最终数量。

### 4.2 表格和资源管理器式列表

- 高密度对象集合优先使用明细列表或表格，不为每个对象创建独立大卡片。
- 层级结构采用“当前目录的直接子项”语义；默认文件夹优先，再显示文件或条目。
- 标签导航使用表格上方的紧凑导航区，只显示直接下级标签；标签不占用论文数据列。默认最多两行，更多标签可展开为限高的独立导航区，不挤占整个论文区域。标签数量按当前资料库范围内含下级的论文去重统计，不受论文搜索或“未分类”筛选影响。
- 条目库所有表头居中，正文标题仍左对齐，数字、状态和操作内容按统一规则对齐。数据列表头复用 Button，点击或 Enter／Space 按该列排序，再次激活反转升降序；以箭头及 aria-sort 表达状态，与工具栏排序和方向共享 EntryLibraryView 的同一状态。操作列和全选框不参与排序，列宽手柄与排序按钮分开命中，拖动、双击复位和方向键调宽不得触发排序。最近阅读范围允许主动改序，缺失字段始终置后，排序不清空当前多选或改写条目数据，原表格仍独占滚动。
- 操作列保留左右 16px 内边距，默认 272px、最小 184px、手动最大 480px，以容纳平铺的文字操作；窄列和来源条目的额外按钮按需换行，不能向左溢出、裁掉或收进菜单。保留已有手动列宽，旧过窄列宽按现有规则校正，无新依赖。
- 长标题截断，但必须通过原生 `title`、Tooltip、HoverCard 或详情面板提供完整值。
- 表头固定时必须不透明，并有明确底边线。
- 横向滚动只能属于内容表格区域；一个区域只允许一个横向滚动容器。
- 滚动条应在该内容区域底部可达，不得制造页面级和表格级双滚动条。
- 首尾列需要固定时，复用 `TableHead` / `TableCell` 的 `pin="left" | "right"`，表头和正文保持一致；行背景必须不透明，固定单元格继承同一悬停/选中背景。表头层级高于固定正文列，表格内隔离层叠；使用独立单元格边框，避免合并边框随滚动消失。
- 论文列表使用实际滚动容器的可用宽度（扣除纵向滚动条）计算列宽。全部可见列能放下时，以现有列宽比例分配剩余空间，允许自动展示宽度超过手动调整上限，不保留空白占位列；此时取消两侧固定列的定位、阴影与竖向分隔。空间不足时恢复按用户偏好固定及横向滚动。自动放大不写回列宽或固定偏好，拖动和键盘调整须将展示尺寸换算回基础列宽，并保留缩放、取消与恢复默认行为。
- 最后一行仍需保留底部边界，空白区域不伪装成额外记录。

### 4.3 关系浏览

关系浏览由条目库页眉的“关系图”按钮打开独立工作区页签，不占用左侧主导航。再次点击切换到已有页签，不重复创建，也不改变左侧工具及其高亮。复用 Button、SearchInput、DropdownMenu、PointerPreview、Popover 与语义颜色。关系由当前标签、条目和 WorkspaceNotesProvider 的目录派生，不另存图数据，不把共同标签或父标签累计数量转换为额外关系。已删除笔记不显示，失效来源保留关系与快照并禁用原文定位。

页面将查询、关系类型与选中对象作为同一导航位置，后退／前进一并恢复，历史最多 80 项；搜索输入合并连续键入，选中对象后退出搜索范围，避免漏掉该对象的关联。单击已展开直接关系，不再叠加独立“只看关联”筛选。“全部关系”同时清除选中与筛选，“返回总览”退出展开，“适应当前画面”只调整镜头。三维适配器拥有布局坐标、镜头和 GPU 资源。画布铺满内容区，无滚动条；三维浏览时左键拖动旋转、右键拖动平移、滚轮缩放。根据相机与节点云中心的相对深度，后半部节点保留 24% 不透明度，连线同步减弱，后侧文字收起且不参与鼠标拾取；旋转到前侧后恢复。方向键旋转、加减号缩放、Home 适应当前视图，仅画布自身获焦时接管按键。标签／条目／笔记分别用球体、薄方块和八面体及文字图例区分；大图限制文字标签并避让重叠，“查找对象”提供完整列表、名称／路径搜索及 Enter、方向键、Home／End 操作。

悬停显示摘要并突出相邻关系，以不参与拾取的细外圈、材质及关联线高亮反馈，不改变节点尺寸或点击范围；非邻居减弱颜色。文字指针／键盘焦点与画布拾取分别管理，画布失去命中不能清除仍停留在文字上的悬停。位置和尺寸仅由展示帧更新。单击或 Enter 经 220ms 过渡将选中对象及其直接关系展开到朝向相机的二维平面，其他对象淡出。入向关系（上级标签、所属标签／条目）位于左侧，出向关系（下级标签、直接条目、拥有笔记、引用来源）位于右侧，相邻对象同时显示关系含义；同一对象有多种关系时均保留。二维仅平移和缩放，禁止意外旋转；“返回总览”还原进入时的镜头、目标和视角。每侧最多显示宽区 6 个／窄区 3 个，较矮面板按文字实际可用空间继续减少，并明确显示已展开／总数；完整关系仍在分组详情列表中，不能删改业务关系来适配画布。快速选择从当前画面继续过渡，后台暂停、卸载取消，减少动态效果直接切换。

展开完成后显示详情气泡，复用 Popover 的边界避让和缩放校正。宽区为右侧气泡预留空间，窄区为底部紧凑气泡预留空间；高度受画布剩余空间限制，不遮住顶部工具及返回入口。“详情”按钮独立收起／展开，“收起详情”保留二维关系。详情按上级／下级标签、直接条目、笔记归属和引用来源分组，优先显示关系，再显示补充元数据；标签说明只统计直接归属，不把子标签继承关系画成已保存归属。只有气泡正文及对象菜单拥有纵向滚动，滚动详情不缩放画布。Escape 优先关闭气泡，再次按下返回总览；关联行继续查看另一对象，返回／前进及 Alt＋左右方向键恢复导航位置。从原页面返回复用仍挂载的关系页签，保留查询、选中与镜头。

三维适配器按需加载，不自动旋转，交互停止后暂停渲染；页签隐藏、窗口失焦或拖动取消时释放指针状态，卸载清理帧、计时器、监听器和 GPU 资源。WebGL 初始化／上下文失败时保留搜索、对象列表和详情，并提供重试；减少动态效果关闭气泡入场动画。布局使用可变副本，不把力导向坐标写回业务数据。

采用 MIT 许可的 [3d-force-graph](https://github.com/vasturiano/3d-force-graph) 1.80.0 替换固定分列 SVG；现有 Three.js 负责渲染，新库补齐力导向布局、节点拾取和轨道镜头，不新增第二套控件库。Three.js 复用已安装版本。当前图模块的延迟 chunk 约 823 kB（gzip 234 kB），共享 Three.js chunk 约 578 kB（gzip 144 kB）；仅打开关系图时加载图模块并创建场景。已验证 Chromium 浏览器的 WebGL 渲染与失败恢复测试；依赖 WebGL2 的原生 WebView2 窗口视觉验收尚未完成，不能以浏览器结果替代。

### 4.4 卡片

Card 用于以下场景：

- 聚合一组独立指标；
- 显示可单独理解的摘要；
- 表达有明确边界的设置组或空状态。

Card 不用于：

- 可以用紧凑行表达的文件、笔记、标签或文献列表；
- 给每个小控件额外套一层视觉容器；
- 仅为了“看起来丰富”而增加图标、阴影和大留白。

## 5. 组件使用规范

### 5.1 按钮与图标

- 一个区域只有一个主要动作使用默认主按钮。
- 次要动作使用 `outline` 或 `ghost`；破坏性动作使用 `destructive`。
- 纯图标按钮必须同时提供准确的 `title` 和 `aria-label`。
- 图标只用于帮助识别动作或对象类型。无法改善识别速度的装饰图标应删除。
- 同一动作在不同页面使用同一个 Lucide 图标。
- 不用颜色和图标替代清晰动词，例如优先“保存”“移到回收站”，不只显示图形。

### 5.2 工具栏

- 常用、与当前选择直接相关的动作保留在工具栏。
- 低频文件操作、显示设置和高级格式进入 DropdownMenu 或 Popover。
- 工具栏尽量保持单行；空间不足时允许横向收敛或进入“更多”，不要无限换行压缩正文。
- 工具按钮应在不可用、只读、保存中状态下统一禁用，不能只禁用正文输入。
- 相同功能不应在同一视图的多个工具栏重复出现。
- 嵌入式阅读器由外层阅读框架持有标题、论文角色和模式切换，内部只显示阅读工具；不要重复渲染单篇页面的完整页眉。窄屏切换主读/对照时，状态操作必须清楚指向当前对象，不允许误标隐藏论文。
- 单篇 PDF 顶部采用两层分组：论文标题、解析与翻译状态靠左，文档操作靠右；下层显示工具、页码导航、文内搜索依次分布于左、中、右。按阅读区容器宽度收起按钮文字和低频动作，窄窗按组换行，不让整组操作撑开标题或产生横向滚动条。长标题省略并保留完整提示；图标按钮保留名称和提示，搜索无结果状态时不预留空白计数栏。状态仍归阅读会话及原业务 hook，正文滚动与拖动归原阅读容器，布局不新增状态或手势。
- 同排输入框、下拉框和动作按钮保持等高，优先使用已有尺寸组合：32px 工具栏使用 `Button` / `SelectTrigger` 的 `default` 尺寸，28px 紧凑工具栏使用 `sm`。不为单个入口另造近似尺寸，也不全局放大阅读器中的紧凑控件。
- Select 收起状态使用与 outline 按钮一致的语义底色、细边框及圆角；默认 13px 字号，紧凑尺寸沿用 12.8px，业务工具栏可统一覆盖字号。值与 14px 箭头保持 8px 间隔，长值单行省略但箭头不被挤压；展开、键盘聚焦、禁用、占位及错误状态必须可辨。主题材质继续由现有拟物／玻璃样式覆盖，不在选择框内另建材质层。

### 5.3 菜单、悬停详情与提示

- Tooltip 用于解释图标按钮或被截断的短标签。
- HoverCard 用于补充对象详情，但核心操作和关键信息必须可点击访问。
- ContextMenu 用于对象级动作；在正文编辑区域不得覆盖系统复制、粘贴和拼写菜单。
- DropdownMenu 用于低频命令，Popover 用于需要短暂填写或选择的内容。
- 浮层必须使用 Portal、正确层级变量和完整键盘交互，不自行硬编码极大 `z-index`。
- 对 CSS UI 缩放下的阅读工具浮层，复用 `PopoverContent` / `DropdownMenuContent` 的可选 `viewportAligned`；底层共享 `ViewportOverlay` 提供缩放坐标容器，嵌套浮层继承设置，未启用的既有页面保持原状。验证边缘定位、外部点击穿透、Escape、返回焦点及嵌套菜单，不能只检查工具栏本身不溢出。
- `HoverCard`、`Tooltip` 默认使用 `ViewportOverlay`。层级由公共组件负责：阅读预览 200、普通详情 400、Dialog 内详情 550、Tooltip 600；业务页面不要再覆写 `z-index`，Dialog 通过 React 上下文传递层级。
- 悬停详情、阅读预览和 Tooltip 即时打开，不增加防误触等待、关闭后的冷却或必须移出再进入的锁定。仅可移入交互的详情保留 150ms 离开宽限，供鼠标跨越触发器与浮层的间隙；时序统一在 `components/ui/hover-interactions.ts`。
- 预览打开状态由 HoverCard/Tooltip 的 Root 持有，受控入口仍由调用者持有；共用文档监听处理按下、拖拽、外部滚动、窗口失焦、缩放及 `neuink:reader-surface-change`。关闭后下一次正常鼠标移动即可恢复，正在按住鼠标、拖动或选字时不弹出遮挡。Esc 先关闭预览，不能连带关闭底层 Dialog。普通 PDF 悬停不暂停后台渲染队列。
- 正文原生选区与可见选区工具条优先于所有 hover：松开鼠标后仍有 PDF／重排正文选区时继续抑制预览；选区工具条由自身生命周期持有独立优先权，聚焦批注输入框导致原生选区消失也不释放，隐藏／卸载仅释放自己的优先权。共享 `hover-interactions` 关闭已有预览并阻止重开，原预览内选字复制不受影响，无延迟或冷却。选区工具条通过 Portal 使用 `--z-reader-selection`（450），高于阅读预览和普通详情、低于系统 Dialog；原选区和滚动所有者不变，切换阅读面关闭重排选区浮层。
- 正文焦点下的 Escape 与选区工具条关闭按钮均结束本阅读区的选区，不清除另一分栏文字；固定工具条也可用 Escape 退出，拖动中的 Escape 优先取消拖动。新拖选开始即撤下旧工具并取消旧捕获，松手后读取最终选区；失焦、手势取消、切换阅读面和卸载不得让已排队的捕获重新打开旧浮层。工具条输入与内部滚动保留选区摘录，其他分栏滚动不关闭它；正文滚动仍归原阅读容器。阅读交互检查可用 `reader-showcase.html?interactions`，其 PDF、解析区域及批注均为隔离示例。
- 详情浮层自己负责长文本滚动，内部选择文字、滚动和点击不能触发外部关闭。内容组件不要再叠加一层限高滚动容器；PDF 列表预览同样只保留浮层滚动。明确的“查看更多”按钮可使用 `HoverCardTrigger openOnClick`；需要编辑或完整键盘操作的内容继续使用 Popover、Dialog 或详情页，不能把 HoverCard 当作编辑器。
- PDF/Reflow 的命中检测仍属于阅读器，鼠标坐标预览共用 `PointerPreview` 和 `useReaderPreviewVisible`。视口容器处理缩放，按实测高度避让边缘；指针移动经动画帧更新位置，不重新渲染整篇文档。普通原文快速预览让指针穿透，PDF 列表预览允许移入滚动和项目定位。
- 已使用 Tooltip 的触发器不要再重复添加原生 `title`；保留可访问名称。未包裹 Tooltip 的静态截断文字仍可使用原生 `title`。
- 开发检查页为 `http://127.0.0.1:1420/hover-showcase.html`，启动命令 `npm --workspace apps/desktop run dev:frontend`。它复用真实 UI 组件和样式，仅使用示例数据，不进入生产导航或生产构建。

### 5.4 Dialog 与危险操作

- Dialog 只用于需要用户做出决定或完成集中输入的任务。
- 长表单和导出清单复用 `DialogContent layout="bounded"` 与 `DialogBody`：弹窗尺寸以可视区域为上限，不随加载、检查结果或详情展开重新居中；头尾固定，正文是唯一纵向滚动区，并预留滚动条位置。缩放下的高度约束使用容器百分比，不直接叠加 `vh` 和 CSS zoom。
- 缩放下的导出下拉框使用 `SelectContent viewportAligned`，以 Popper 定位并只让选项视口滚动；复用 `ViewportOverlay` 的 `dialog-popover` 层级，避免菜单落到弹窗后面或出现两个滚动所有者。
- 删除优先使用回收站；不可恢复或会覆盖内容的动作必须说明后果。
- 按钮顺序保持一致：取消、破坏性/替代动作、主要确认动作。
- 不用 Dialog 展示普通成功消息；成功使用内联状态或短 Toast。

### 5.5 表单和状态

- Label 描述字段含义，placeholder 只提供示例，不能替代 Label。
- 错误显示在对应字段附近；页面级错误才放在页面状态区。
- 加载、空状态、失败、只读和无权限使用不同文案和视觉。
- 同一个异步动作只能有一个可信状态来源，避免按钮、Badge 和 Toast 相互矛盾。

共享 Input、Textarea 的普通状态使用 muted 实底区分周围内容，聚焦时使用 card 底色与克制的焦点环；错误、禁用及材质主题仍保留原语义。助手输入区不设置常驻标签／提示行，正文直接从顶部开始；仅空白时在输入起点显示 placeholder，聚焦不隐藏，只有引用时也不增加输入提示。无障碍名称保留“输入问题”，提示不写进草稿。编辑状态、引用、光标与撤销归现有 Tiptap，草稿快照归 AssistantPanel；长问题只在编辑区内限高滚动，发送操作保持可见，消息列表仍独立滚动。Enter 发送、Shift+Enter 换行及输入法组合键契约不变。

## 6. 交互规范

### 同内容多视图与译文对照

PDF 译文模式在原始位图上方使用整页不透明遮罩，仅按原始解析坐标为表格、图片、公式和算法保留原图窗口；段落框间隙及解析遗漏的原文字迹一并遮住。遮罩位于文字命中、译文、加载和错误反馈下方，不改变滚动、选择及导航所有权，不复制 PDF 位图或增加渲染循环；无解析区域的页面保留原始 PDF。

PDF 悬停预览正文统一采用主题无衬线字体及用户选择的字号，长段落不自动缩字或切成多栏；浮层独占限高纵向滚动，原文、译文、笔记使用相同正文基准，代码与公式保留专用字体。所有片段预览均可移入、选字和滚动，正文到浮层沿用共享离开宽限，浮层内事件不触发正文片段选择；正文选区优先与 Escape 关闭不变。译文覆盖层使用随页面缩放的紧凑基准字号，不放大短段落；长段落按实际渲染尺寸缩小适配分配区域，不增加段内滚动条。悬停预览保留完整可读译文，整页仍由阅读器滚动。

解析公式的兼容修复仅作用于 SourceSnapshotPreview 显示层，原文与译文复用同一流程，不改写用户文件。矩阵列格式遭 OCR 损坏时，仅在各行列数一致、对齐意图明确且 KaTeX 校验成功后修复；保留上下标、左右定界符和编号，不猜测缺失单元格或复杂嵌套矩阵。带编号的公式使用行间数学块，公式横向滚动仍由原预览区域负责；代码与关闭 OCR 规范化的笔记审阅不受影响。状态、选择、键盘与拖动仍由原阅读器持有。

PDF 可交互预览必须避开当前原文 block 的完整矩形；上下空间不足时可收窄移至侧边或限高滚动，不能为挤入视口覆盖可选文字。没有可读空间时不显示自动预览，右键片段菜单仍可用。块命中与选区高亮统一使用实际 PDF 内容矩形，不包含纸张装饰边框；重叠块按固定优先级与面积选择，不沿用上次悬停块。文字层负责修正紧邻字行边缘空隙的原生选区端点，依据真实字形位置，不用解析文字替换原文；拖动、跨行／跨页选择与自动滚动仍由浏览器拥有，双击选词、组合键和远处空白不吸附。取消、失焦、切换与卸载释放临时手势。

PDF 的原文／译文入口并入原有阅读操作栏，不在页签下方增加独立顶栏；悬停译文是两种显示状态都可用的预览交互，不占互斥模式按钮。同论文分屏通过页签栏锁链按钮切换同步滚动／点击联动，PDF 工具栏不重复提供开关。显示状态仍归 ReadingViewSession，正文滚动与拖动契约不变。连续／书页切换只在拟物主题显示，其他主题保持连续阅读并隐藏入口，不清除书页偏好。重新解析属于条目详情“文件与时间”，确认覆盖后加入原解析队列；PDF 工具栏及更多菜单不重复提供重新解析，未解析和失败时仍保留开始／重试入口。

PDF、重排、文档笔记和片段记录的标签右键提供“复制到另一分栏”。复制的是带独立 viewId 的阅读视图，不复制条目、PDF 或笔记文件；关闭、移动、固定仍按视图身份处理，删除底层内容则影响所有视图。复制沿用现有 ContextMenu 键盘与工作区拖动契约，不自动提交未保存内容。

ReadingViewSession 持有每个阅读标签的原文／译文显示模式；悬停预览独立于该模式，正文滚动仍归原阅读器。相同资料库、条目的可见 PDF／重排视图按全局阅读偏好切换同步滚动／点击联动，保留各自缩放，不向隐藏视图发送定位，不将被动滚动再次广播。译文使用原 PDF 的覆盖层，不改写源文件；仅同页同栏、无遮挡、已翻译的相邻正文段落可重新分配高度，不跨越标题、图注、图表、公式或未翻译区域。未翻译文字段落覆盖显示“缺少翻译”，图表与公式仍保留；译文按渲染尺寸缩放适配，不增加段内滚动条。源片段标识保持不变，文字级原文高亮不转换为猜测的译文选区。

同一窗口内的文档笔记共用按资料库／归属／笔记隔离的 SharedNoteSession。文档内容、标题、溯源数据与保存队列共享，编辑器光标及撤销栈独立；增量事务同步，不以整篇 Markdown 替换每次输入。保存沿用后端 revision 校验；保存期间的新输入仍是未保存草稿，外部版本冲突要求明确处理。程序排队插入的来源和图片按共享会话去重。每个视图继续接入关闭保护，释放编辑器时移除订阅，最后一个干净视图关闭后释放共享会话；此机制不宣称支持跨窗口或跨设备协同。

### 6.1 点击、选择与打开

列表的编号、项目符号与参考文献共用单项操作范围：PDF 命中坐标、重排列表项、悬停、点击／键盘选择、Ctrl 拖动、复制、笔记、批注及助手引用使用同一个列表项身份；跨页项使用自己的页码与范围。整块引用仍可解析，右键提供明确的“添加整个列表到助手”。缺少单项坐标的旧解析不猜测鼠标目标，点击或 Ctrl 手势打开列表项选择，再执行所选项操作；只有显式操作整个列表才扩大范围。重排复制使用独立按钮，不占用行点击。解析父块继续保留，单项身份由共同的前后端来源解析器恢复，不把临时预览身份写成无法回跳的来源。状态归原阅读／菜单及助手草稿，PDF 与重排各自拥有正文滚动；普通选字优先，跨项选区保留实际选中文字，拖动沿用捕获、Escape、失焦与卸载取消，不自动发送。

- 左侧“条目库”与“条目／笔记详情”是独立工具，由 App 的 sidePanel 持有选择；打开条目、搜索命中、助手来源及切换阅读页只更新阅读目标，不改变侧栏选择或强制展开。条目库不再因聚焦 PDF 自动变成详情；详情仅在用户主动选择后跟随聚焦对象，无目标时保留空状态。原搜索查询、助手会话、标签阅读范围和侧栏滚动所有者不变，不新增拖动契约。默认内容继续由“阅读与批注 / 打开条目”的 PDF 优先偏好控制，无 PDF 回退概览；明确的笔记、原文定位和查看概览不被默认偏好覆盖。

- 单击选择或打开必须在同类对象中保持一致。
- 行内按钮不得同时触发行点击；事件边界必须明确。
- 双击只用于用户已有桌面心智模型的场景，并同时提供单击可发现入口。
- 当前选中、键盘焦点和悬停是三种不同状态，不得共用同一视觉表达。
- 侧栏树形行的箭头、标题和数量共享一层悬停/选中背景，内部按钮保持透明；仅展开不产生常驻背景。背景只属于当前行，不能因悬停子节点连带高亮祖先。展开和选择仍是独立动作。
- 标签名称在侧栏和标签浏览列表中单击进入条目库的对应标签；整行与名称使用同一动作，不额外提供“详情 / 浏览”两套入口。侧栏逐级目录箭头只浏览子标签，树形箭头只展开/收起，侧栏目录位置仍独立持有。条目库标题整合面包屑、标签名称和紧凑描述，描述点击后展开编辑；“论文 / 标签笔记”切换内容，“标签导航”只控制上方导航区域的显隐，“仅当前 / 含子标签”独立控制论文范围。切换栏目或导航显隐保留搜索与描述草稿；切换标签、资料库范围或关闭页面接入统一未保存保护。浏览方式、密度和数量显示作为本机偏好保存，树形展开状态独立保存。
- 论文标签的“只显示最具体的标签”是按每篇论文、每个分支计算的展示规则：仅隐藏已关联子标签的重复祖先，不删除真实归属，不移除导航中的父标签；编辑仍使用全部标签，同名末级标签用完整路径区分。
- 标签浏览行不使用悬浮详情卡；名称可用键盘激活，完整路径通过可访问名称与原生提示提供。描述编辑支持保存、取消和 Ctrl/Cmd+S，收起后焦点回到入口；Escape 只在没有未保存修改时收起。
- 普通条目库与标签范围共用 `LibraryHeading` 和 `LibraryEntryTitle`。页头面包屑始终显示“显示全部”、当前条目范围（包括 PDF 解析状态）和标签管理入口，标签路径接在范围之后；解析状态不得只放进可截断的数量摘要。范围菜单复用侧栏的状态定义，保留当前标签和搜索，进入回收站时清除标签；“全部标签”只清除标签，“显示全部”通过 App 的未保存保护后统一清除范围、标签、搜索与排序，并回到论文栏目。状态仍由 App 与条目库页面持有，不增加第二套筛选状态。加载、失败和空列表仍可返回全部，标签管理在资料未就绪时禁用。阅读统计和创建入口固定在同一页头区域，搜索与筛选共用下一行；标签导航开关与表头设置放在表格工具栏；不另加“论文列表”标题栏。标签数量、描述入口与内容切换融入页头的信息行，描述仅在编辑时展开；页头不提供平行阅读入口。窄面板允许路径换行并收起上级标签和次要按钮文字，保留“显示全部”、完整范围名称、标签管理和完整路径菜单；菜单沿用共享组件的方向键、Enter、Space、Escape 与关闭回焦契约。页头固定在正文滚动区域之外，不改变表格或标签导航的滚动、拖动所有者。论文标题与次要信息各占一行，所有范围的论文共用字号、行高及选中反馈。
- 条目库使用同一个 `LibraryPaperTable` 和 `LibraryPaperToolbar`。“标签导航”复用共享 `Toggle`（aria-pressed）与 Tooltip，开启时高亮，按 Space/Enter 切换并保留焦点，只控制 `LibraryTagNavigation` 是否显示，不重新挂载表格或改变论文集合、排序、搜索、列偏好及滚动位置。根目录的“全部论文 / 未分类”和标签内的“仅当前 / 含子标签”是显式范围筛选；未分类指没有关联任何标签，进入标签、切换资料库范围或重置筛选时退出未分类筛选。论文行采用 48px 行高、轻水平分隔线，文本左对齐、日期与时长右对齐，固定列保留边界。文件采用紧凑文本，标签复用 `EntryTagBadges` 的 `Badge` 样式，按列宽显示名称及剩余数量；单个标签使用完整可用列宽。鼠标悬停或键盘聚焦通过共享 `HoverCard` 显示完整路径，长名称换行，保留点击访问；浮层只读并独占预览滚动，不嵌套设置菜单。
- 条目库页面持有筛选、选择和 `showTagNavigation` 布尔状态；导航显隐保存为本机偏好，读取时兼容原列表/标签浏览设置。没有下级标签时不占据空白区域，也不覆盖显隐偏好。表格持有列宽并作为论文区域唯一横纵滚动容器。导航只持有展开状态，展开很多标签时自行限高滚动。论文拖动统一使用 `useLibraryEntryDrag`，Escape、失焦、取消、切换上下文和卸载均清理，鼠标释放只提交一次；拖动预览复用 `PointerPreview` 的缩放坐标与层级。
- 标签范围的“论文 / 标签笔记”切换与阅读统计位于页眉同一操作行。切换时页眉、描述、统计和标签操作保持挂载与位置；主要创建入口占同一位置，分别显示“创建条目 / 新建笔记”。笔记搜索与论文搜索共用 `SearchInput` 的尺寸、图标及清除入口，各栏目保持独立搜索和滚动状态；笔记列表不常驻刷新按钮，目录加载失败时才显示重试。创建入口复用 `CreateTagNoteButton` 与已有创建对话框，异步操作使用所属页面的 `/create` 子作用域，参与统一关闭保护；不引入新的数据或拖动所有者。
- 关键动作必须支持键盘访问，并显示 `focus-visible`。
- 条目库左侧的快速视图、解析、全部标签共用 SidebarPanelGroup / SidebarPanel；三组标题的颜色、折叠反馈及动作区域统一，默认高度权重为 1 / 1.25 / 2。各组独立滚动，外层不滚动，分隔条复用标签阅读的拖动、方向键和取消契约。折叠偏好沿用原存储，高度比例在本次侧栏会话内保存。全部标签的搜索、编辑与显示设置保留在标题右侧；搜索输入和当前目录路径在本组正文内，收起再展开保留查询，搜索可展开本组。标签导航和拖放逻辑仍归 TagNavigation，拖动边缘滚动只作用于标签面板的 viewport，不滚动快速视图或解析组。
- “平行阅读”复用普通工作区左右分屏。同标签侧栏复用条目库 TagNavigation，并使用三个独立可折叠的 SidebarPanel：标签选择、论文、标签笔记。路径与搜索固定在顶部，三组标题始终保留；每组正文独占自己的 ScrollArea，外层不再滚动。展开区块由 SidebarPanelGroup 按剩余空间分配高度，论文默认权重为 2，标签与笔记为 1。相邻展开区之间提供横向分隔线，可拖动调整两组高度，折叠组不参与调整；高度比例由面板组在本次侧栏会话内持有，窗口尺寸变化时按比例适配。分隔线支持上下方向键微调、Shift 加速；拖动支持最小高度限制、缩放坐标换算、Esc/取消/失焦回退与卸载清理，不自动滚动列表；收起只保留标题并释放高度，不卸载笔记会话、搜索或正文滚动容器，重新展开恢复滚动位置。各区块共用侧栏标题样式，支持 Enter/Space 切换及左右方向键收起/展开，aria-controls 关联正文。定位论文时只展开论文区并滚动该区，不改变另外两组折叠状态。输入搜索时自动展开匹配标签；搜索同时筛选完整标签路径与当前范围论文标题/PDF。根目录展示全部论文，无标签条目也可直接打开。标签单击更新范围，目录双击/箭头进入下级，树形双击展开；复用既有模式和显示偏好。搜索右侧 Toggle 控制含子标签。浏览范围独立于活跃 Tab：首次显示且资料加载完成时按有效来源标签、论文标签初始化；此后切换论文、分屏焦点、来源或配对标签笔记仅更新当前论文高亮，保留标签范围、搜索、含子标签、折叠和滚动。主动选择标签更新范围；从条目库重新进入平行阅读显式初始化范围并清空搜索。搜索右侧“定位当前论文”只在用户点击时定位：搜索隐藏论文时清除搜索，论文不在范围内时选择仍包含它的来源标签或有效自身标签，无标签则进入全部论文；程序滚动仅作用于侧栏，不抢焦点。已删除标签保留不可用提示，已删除论文移出列表并禁用定位；资料库切换重置会话范围。来源说明放入路径提示。论文采用约 42px 紧凑行：标题单行截断，下一行只显示短进度条及百分比/阅读状态。完整标题、文件名、页码、时长、笔记数量和标签路径通过共享 HoverCard 在悬停或键盘聚焦时查看，Escape 关闭；查看详情按钮仍可直接访问完整条目。预览仅绑定论文主按钮，不改变打开、分屏、筛选或滚动状态。操作按钮根据实际 Surface 切换图标、高亮与 Tooltip，不使用临时点击状态。所有左侧面板共用 App 的 sidebarWidth 和一个本机宽度偏好，切换面板不改变宽度；侧栏共享 ScrollArea 固定预留纵向滚动条宽度，原生滚动区使用稳定滚动槽，滚动条显隐不挤压或覆盖内容；不引入第二套阅读器或编辑所有者。
- 主导航使用“标签阅读”名称，打开标签笔记不自动切换左侧工具。标签阅读保持三组面板、浏览范围、搜索、折叠、滚动及高度；只更新当前笔记高亮，定位所属标签属于显式范围变化。详情工具随当前聚焦对象显示条目详情或标签笔记详情，不能因标签笔记缺少 EntryId 而回退到条目库，也不能随意将一篇来源论文作为笔记归属。标签笔记详情显示标题、归属标签、按论文去重的来源与同标签笔记；来源和同标签笔记各自使用可调高度的 SidebarPanel，复用共享目录与 SidebarPaperRow，不创建第二个编辑器。删除来源保留状态和引用快照说明；无来源、目录错误、笔记删除和标签失效分别显示明确状态。搜索及助手工具保持原面板。
- 标签阅读中的论文箭头独立展开内部内容，论文标题保留快捷阅读。目录列出 PDF、重排、片段记录、引用及按标题区分的文档笔记；无 PDF 仍可打开笔记，重排不可用时说明解析状态。SameTagSidebar 持有论文和笔记组的展开状态，原论文面板独占滚动；切换内容、搜索及侧栏工具保留目录状态。子项默认在当前侧打开，已存在的内容优先聚焦原页签；分屏按钮及右键菜单可明确选择另一侧，复用原工作区路由及编辑保护。打开详情也保留标签阅读侧栏。当前内容高亮与“左侧／右侧已打开”分别表达焦点和页签位置。箭头支持左右方向键，菜单复用 Radix 键盘行为、ViewportOverlay 缩放定位及门户化子菜单；长菜单限高滚动，关闭恢复焦点，不增加拖动动作或悬停等待。
- 论文内部目录按“论文 → 内容／文档笔记组 → 具体笔记”逐级缩进，连接线在最后一个直属子项处结束，不贯穿到下一篇论文。论文保留标题与阅读进度，子项使用 SidebarContentRow 紧凑单行，重复类型信息保留在可访问名称与完整提示中；已打开侧别及不可用原因仍可见。文档笔记组使用 SidebarSectionHeader 的 branch 变体，不绘制独立面板底板，数量与箭头都属于同一折叠按钮。展开时只高亮当前子项；收起笔记组显示“当前”，收起论文显示当前内容名称。已展开的箭头按右键进入首个可用子项；子项按左键返回直接上级，已收起的笔记组再按左键返回论文；这里的左右键指键盘方向键。Tab/Enter/Space 与菜单沿用原契约。展开即时更新布局，仅使用短淡入与箭头转向；调整面板高度或减少动态效果时关闭装饰动效。
- 同标签侧栏的标签笔记作为第三个 SidebarPanel 独立折叠与滚动，标题不会被上方长列表挤出可视区域。复用 SidebarSectionHeader、SidebarContentRow、创建对话框和笔记目录；当前标签与含子标签开关同时控制论文和标签笔记，笔记搜索独立且按需展开。切换论文不改变笔记范围、搜索和折叠。单击笔记优先聚焦已有编辑页，否则在当前活跃区域直接打开，不自动分屏；新建后同样直接打开。行末独立“分屏打开”按钮才请求放到论文另一侧（无论文时为当前区域另一侧），移动已有编辑器沿用保存保护，不创建第二个编辑所有者。标题右侧提供搜索和新建，行内菜单提供移到回收站，不常驻刷新或删除按钮。已删除笔记和无效标签归属不进入正常列表；资料加载、失败、标签失效时禁用创建。创建对话框保持原归属，标签删除后必须重新选择，不能静默回退。
- 打开论文后的笔记导航统一放在左侧「条目详情」，按阅读内容、文档笔记、标签笔记和回收站分组；概览/PDF/Reflow 顶部不重复放置标签笔记选择器、列表或复选框。文档笔记与标签笔记均可折叠，共用 SidebarContentRow 的行高、排版、焦点和操作区，使用文档/标签图标区分。标签笔记默认平铺本论文标签及祖先标签的笔记、进入论文时的标签上下文笔记，以及引用本论文的笔记；标题旁的筛选入口按需展开搜索和标签/引用范围，筛选生效时显示可清除的提示，不常驻模式切换、选择器、刷新或回收站工具条。已删除笔记只在统一回收站展示与恢复。标签笔记单击直接打开，独立行末按钮用于分屏打开；已有分屏中聚焦笔记时保留配对论文的侧栏；选择和范围由侧栏持有，笔记目录由 App 中的 WorkspaceNotesProvider 共享，侧栏 ScrollArea 是唯一纵向滚动所有者，笔记行不引入拖动或第二个编辑所有者。

### 6.2 拖动与调整大小

PDF 缩放以扣除导航轨道后的可见阅读区域中心为锚点，按钮与 Ctrl＋滚轮共用 PdfLayoutAnchor，在页面几何更新前捕获纸面坐标、更新后绘制前恢复；页眉、间隙、边框不随正文比例缩放，界面缩放只换算一次。连续缩放保留同一纸面锚点，避免逐次取整累积漂移；ResizeObserver 在后续页面尺寸变化时继续恢复该位置，期间关闭浏览器自动滚动锚定。普通滚轮、指针操作、导航按键、外部滚动、窗口变化、失焦、切换文档和卸载释放锚点及监听，下一次缩放重新取点。单页、双页及书页模式不得因缩放额外重置横向位置或排队延迟回跳；到达文档边界时服从实际可滚动范围。纸面容器需保留左右留白的滚动空间，避免刚超出阅读区时中心偏移。分屏宽度变化仍保留原页内阅读位置。

PDF 阅读区按住空格后可用主指针左键拖动查看，松开空格或鼠标即停止；原阅读容器独占横纵滚动，缩放及持久化仍归 usePdfReaderZoom。手势经过 4px 阈值、捕获 pointerId 并按界面缩放换算移动距离，逐帧合并滚动；Escape、取消、捕获丢失、失焦、切换阅读面、布局变化和卸载回滚并清理。输入、通过键盘聚焦的按钮及浮层保留键盘操作；鼠标点击普通按钮后移回 PDF 正文，空格转交阅读区并阻止按钮重复触发。普通正文拖动继续选字，Ctrl 拖动仍用于引用；空格拖动抑制选字、片段点击和悬停。它直接移动视口，不采用数据拖放的落点或边缘自动滚动。只读 PDF 可浏览，加载、失败及无文档时不开启手势。缩放按钮按 1% 微调，Ctrl＋滚轮按距离及同向事件间隔动态加速：普通 100px 滚轮事件约 5 个百分点，快速滚动单次最多 18 个百分点；小幅触控板输入累计后按 1% 提交，同帧事件合并为一次更新，停顿或反向后重置加速。范围保持 10%–300%；中间百分比按钮恢复 100%（沿用适应阅读区宽度的基准），并取消待处理的滚轮更新。普通与分屏工具栏复用 PdfZoomControls，无新增依赖。

选中文字浮层支持固定在当前阅读视图内：PDF 各页向同一个 ReadingSelectionToolbarProvider 发布选区，重排沿用单一选区工具栏，跨页及重新选字不重建已固定的窗口。临时取消选区时保留上一份译文，依赖实时选区的操作禁用；新选区到达后原位更新并拒绝旧请求结果。固定位置归视图会话，不写入论文或全局偏好，关闭／切换阅读面后释放。固定状态才显示顶部拖动柄，支持主指针、4px 阈值、Pointer Capture、方向键微调及 Shift 加速；Escape、pointercancel、捕获丢失或失焦回滚手势，窗口缩放和尺寸变化将位置限制在可见视口内。定位以视口像素记录，按 CSS 缩放换算一次；原阅读器、浮层和译文保持既有滚动所有者。

PDF 选中文字的译文完成后，在结果内提供“添加到高亮批注”，复用原选区位置、颜色与批注保存入口。相同选区已有内容时追加译文并保留重要性，末尾已有相同译文时不重复追加。浮层持有本次保存状态，进行中阻止重复提交，失败保留译文及选区以便重试；空译文、翻译中／失败、无写入能力或固定浮层失去实时选区时不可写入。选择身份包含页码、正文及矩形，迟到保存不能关闭后来的选区。操作复用 Button 的 Tab／Enter／Space 行为，结果正文沿用原限高滚动，固定浮层的拖动与阅读器滚动所有者不变，无新增依赖。

所有拖动实现必须满足以下完整契约：

1. 只允许主指针从明确拖动柄开始；PDF 整段拖入聊天采用用户确认的 Ctrl + 正文拖动，按下时锁定手势，普通拖动保持选字；
2. 至少移动 4px 后才进入拖动，单击不得触发拖动；
3. 使用 Pointer Capture 或等价机制，并校验 `pointerId`；
4. 拖动时禁用文本选择，光标和预览保持一致；
5. `Escape` 和 `pointercancel` 必须回滚，不得提交；
6. `pointerup` 只在有效目标上提交一次；
7. 长内容在上下边缘提供自动滚动；
8. 命中计算使用稳定布局坐标，不使用已被动画 transform 改写后的坐标反复计算；
9. 移动数据节点本身，不通过替换整篇文档或整份集合模拟移动；
10. 拖动结束、组件卸载和窗口失焦都必须清理监听器、光标、选择和临时样式；
11. 拖动期间关闭高成本 HoverCard、预览和动画；
12. 提供明确的放置线/目标高亮，以及可撤销或可预测的结果。

拖动必须至少测试：未超过阈值、有效移动、无效目标、跨区域、Escape、pointercancel、长内容自动滚动和卸载清理。

- 工作区标签的落点以各分栏为定位参照；标签栏必须成为标签的 offset parent，稳定槽位转换到视口时只计算一次分栏偏移和界面缩放。右栏与 125% 缩放需覆盖独立回归，不能使用拖动动画后的标签边界代替槽位。
- 条目库与每日看板各自在全工作区最多有一个页签，均可关闭、固定、排序及移动分栏；重复点击入口激活已有页签。关闭其他／右侧标签只保留显式固定项，不特殊保留条目库。清空任一分栏时收拢剩余分栏，保留原视图身份、活跃项、滚动及固定状态，不自动补回条目库。全部关闭后使用没有 tab 的空工作区，提供打开每日看板／条目库按钮；批量关闭按稳定页签 key 查找当前归属，不沿用收拢前的旧分栏位置。恢复会话保留主动关闭后的空状态，首次打开或无有效旧会话时沿用条目库默认页。

- 左侧每日看板／条目库／详情／搜索／助手／标签阅读六个入口使用同一套样式、颜色和间距，共用一个滑动高亮块，最多选中一个。选中状态从 App 的侧栏展开状态和聚焦页面派生，不维护第二套点击记忆：有打开的侧栏时选中该入口（阅读 PDF 时条目库侧栏也属于条目库入口）；侧栏收起时，仅在看板／条目库页面回落到对应入口，其他页面隐藏滑块。点击看板入口打开内容 tab 及今日智能建议侧栏，切换工具后可返回智能建议；点击条目库入口聚焦已有条目库并显示其导航侧栏；打开成功后再改变侧栏，沿用未保存保护。右键在右栏打开采用相同规则。页面入口的 `aria-current="true"` 表示当前导航项，工具沿用 `aria-pressed`；再次点击当前已展开的工具或页面侧栏入口收起侧栏，不关闭内容页签、不切换当前阅读页面；侧栏收起后可再次点击入口打开。不设置顶部开关。展开时保留侧栏边界原有点状拖动手柄；收起后在最左导航栏与页面的分界线中部显示向右箭头，点击恢复上次侧栏及其宽度，不触发内容页导航。收起后焦点交给边界箭头，恢复后交回拖动手柄。实际聚焦页面由工作区 tab 标识。六入口组内无分组标题、分隔线或额外的页面高亮，遵循减少动态效果设置；状态归 App，正文滚动、键盘、拖动所有者不变。今日智能建议侧栏与其他工具互斥展示，始终只有一个导航高亮。
- 统计入口保留在条目库页眉，点击打开每日看板，不再展示受标签／解析筛选影响的统计浮层。看板按全资料库现有阅读记录展示所选日期、近七天时长与当日论文；日期由 App 级每日控制器持有，中央看板和每日记录共用，智能侧栏始终分析实际今天；阅读活跃时长仍归原阅读器，关闭看板不改写历史。日期栏固定，正文独占纵向滚动；日期、趋势日期及继续阅读支持键盘，按钮不抢占 PDF 空格拖动。看板和空工作区是中性页面，不隐式关联后台论文、选区或笔记。读取中／失败不显示伪零值，空日期和空资料库分别说明，失败提供重试；没有新增 UI 依赖或拖动手势。

### 6.3 滚动

- 后台重型阅读面闲置释放时，活跃页签仅保留轻量阅读快照，不保留 PDF、DOM 或适配器回调。每页签最多缓存 8 个嵌入阅读对象、每对象最多 80 条导航历史；关闭页签或切换资料库后释放。PDF 保留页内偏移、横向位置和缩放，重排以实测段落和段内比例恢复；滚动后等待虚拟列表提交再采样，不在卸载后的失效 DOM 上采样。恢复因异步内容加载而中断时需继续，旧跳转不得重放，新跳转／主动滚动优先。校准帧数有界，隐藏和卸载清理帧、监听器与观察器，正文仍由原阅读容器独占滚动。

- 工作区页签按稳定 surfaceKey 归属于同一渲染列表，左右侧仅决定 CSS 网格位置，不能以所在 pane 作为阅读器／编辑器的挂载身份。列表 DOM 顺序也保持稳定，避免移动原节点时浏览器清空内部滚动；拖入目标仅标记可见页面。配对笔记的加载、关闭只改变稳定 Provider 的值，不替换阅读器外层结构。分屏、交换与移回保留原滚动、导航历史和草稿，真正关闭与闲置释放仍沿原契约。连续 PDF 宽度变化前记录当前页与页内比例，布局后还原；显式缩放和书页导航保留自己的锚点。重排宽度变化按原虚拟行片段及段内比例还原，不用全文滚动百分比，用户主动滚动优先，隐藏与卸载清理待执行帧。滚动所有者仍归原阅读器，没有第二层滚动容器或新拖动手势。

- 每个方向只能有一个主要滚动所有者。
- 固定头部和底部操作区不参与正文滚动。
- “条目库”与“条目详情”由主导航分别进入；详情侧栏标题不提供返回条目库按钮。下方详情、阅读入口和笔记共用原 ScrollArea，固定标题栏不进入滚动视口或覆盖正文。
- 嵌套滚动只用于有明确边界的预览、代码块、表格或独立面板。
- `overscroll-behavior` 用于阻止嵌套区域意外带动父页面。
- 程序定位内容时不得无条件抢夺键盘焦点。

### 6.4 动效

- 常规状态过渡为 100–180ms；拖动回位或面板展开不超过 220ms。
- 动效用于说明状态变化和空间关系，不用于持续吸引注意力。
- 避免大面积缩放、弹跳、发光和循环动画；持续动画仅用于真实进行中的任务。
- 尊重 `prefers-reduced-motion`，新增复杂动效时必须提供降级。

## 7. 编辑器与笔记专项标准

### 7.1 术语

- `Note` / “文档笔记”：独立 Markdown 文档，可作为标签页或分屏打开。
- `Segment Note` / “片段记录”：绑定原文片段的短笔记。
- `Annotation` / “批注”：绑定片段或文本选择的结构化记录。

界面不能把三者都缩写为没有上下文的“笔记”。

### 7.2 编辑会话

- 同一笔记同时只能有一个编辑所有者。
- 只读视图必须禁用正文、标题、格式、插入、拖动和程序化修改命令。
- 编辑权接管必须原子转移正文草稿、标题草稿、dirty 状态和保存处理器。
- `Ctrl/Cmd + S` 只作用于当前聚焦编辑器，不得广播给隐藏标签页。
- 标题和正文属于同一个保存快照，不能分别从不同版本写盘。
- 保存期间不应冻结正文输入；保存完成后必须比较版本，保留保存期间产生的新修改。
- 加载失败时编辑器默认保持只读，避免用空白内容覆盖原文件。

### 7.3 保存反馈

- 退出保护由 App 持有待处理列表和导航，编辑器继续持有正文状态；复用 dirty/close registry，不新增平行 dirty 状态。关闭时定位实际标签页和具体编辑区，列表提供“去处理”“保存并退出”“保留草稿并退出”。后者需检查所有待处理项的最新备份和保存中状态；备份失败及忙碌操作保持窗口打开。恢复覆盖正文、元数据、创建表单、标签、待办及设置；记录通过标题栏入口查看，显式应用到原编辑器。恢复后的文档笔记暂停自动保存并审查版本冲突；自动保存设置需要“应用恢复设置”，模型和服务配置按原保存契约确认，不因恢复触发网络测试。模型弹窗的 X/Escape 走关闭保护，明确取消放弃当前编辑。设置与各页面的原滚动所有者、键盘与拖动契约保持不变；有恢复记录待处理时输入只读，恢复失败保留记录并提供重试。记录位于文献库 `.neuink-recovery`，密钥仅写入独立系统凭据库，磁盘记录使用版本引用，预览不显示密钥；解锁时核对引用版本和资料库归属，失败不退回明文保存，不写正文／密钥日志。
- 退出／恢复窗口复用有界 Dialog 和 DialogBody，列表归 DialogBody 滚动，只读内容预览可独立滚动以便复制；操作栏固定。Esc／取消回到具体编辑页，处理期间禁用关闭和重复提交；不新增键盘快捷键或拖动行为。备份采用 250ms 有界合并队列与退出时强制刷新，保留保存期间的新修改；操作系统强制结束仅承诺最后一次成功写盘的版本。

长文本编辑器推荐使用约 1000ms 的防抖自动保存，同时保留 `Ctrl/Cmd + S` 立即保存。若某个阶段仍使用手动保存，必须提供：

- 持续可见且准确的“未保存”状态；
- 切换、关闭和工作区变更保护；
- 保存失败后的明确重试入口；
- 不依赖进程内内存的恢复草稿，或明确说明恢复范围。

状态文案统一为：`未保存`、`保存中…`、`已保存`、`保存失败，重试`、`只读`。

### 7.4 编辑器界面

- 图片设置由所选 Tiptap 图片节点持有，宽度／对齐仍写入原图片属性，正文滚动继续归原笔记容器。控件复用 Button、Input 和 ViewportOverlay，独立于图片宽度，通过 Portal 放在当前笔记可见区域；调节和输入聚焦期间固定控件的视口位置，不重建滑块，不用滚动正文补偿位置。拖动／按键期间临时保留原文档高度并关闭滚动锚定，避免缩小文末图片触发滚动范围收缩；松手、按键结束、取消、捕获丢失、失焦、只读切换和卸载恢复样式。普通滚动及分屏／界面缩放变化重新定位，图片离开可见区域时收起控件。保留原生范围输入的捕获、方向键与 Home/End，百分比限制 10%–100%，只读不显示编辑控件；不新增依赖或滚动容器。

- 文档笔记目录固定在当前笔记视图最左侧，不属于全局侧栏，也不占用格式工具栏。默认收起为 36px 窄入口，可显式展开／收起；宽视图使用 180px 紧凑左栏，笔记视图不宽于 760px 时以 180px 浮层在当前笔记内部左侧展开，布局仍仅占 36px，不挤压正文或超出当前分栏；长标题截断并保留完整提示。目录从当前 Tiptap 文档派生 H1–H6 层级，可搜索并切换查看表格、图片、公式、代码、流程图、列表和来源等元素。复用 Input 和 Button，目录列表独占滚动，正文仍归原笔记容器；点击仅滚动所属视图，不关闭目录、不写入 ID、不改变光标或触发保存。展开状态、查询、范围和目录滚动由各笔记视图独立持有，收起再打开及切换标签页保留，不重新挂载编辑器。只读可定位，加载／读取失败禁用并收起；展开期间订阅文档更新，关闭／卸载解绑。方向键及 Home/End 导航目录，Escape 仅在目录内关闭并返回入口，不接管正文键盘；没有新拖动行为。格式栏的窄屏适配按目录之外剩余正文宽度决定。
- 笔记溯源优先定位当前活跃的同论文 PDF／重排，其次另一可见来源、已经打开的来源页签；均没有时在笔记另一侧打开 PDF。复用视图身份及原阅读模式，不重复创建同一来源；点击笔记导致焦点变化时仍复用另一栏的可见来源。请求按 surfaceKey 定点，只定位选中的视图，不广播到其他副本；之后用户手动滚动仍沿用正常联动。阅读器持有定位及返回历史，App 持有布局，笔记不丢失编辑焦点；缺失来源保留摘录预览，不跳到无关论文。

- 助手的 Mermaid 流程图／思维导图复用 MermaidDiagramPreview 与共享串行渲染器，回复完成后显示图形，流式期间只显示生成状态，源码通过原生 details 按需展开；普通代码块不改变。图表是只读正文元素，大图和源码分别限高内部滚动，不新增编辑、拖动或写入权限，原消息列表与完整回复页签继续持有外部滚动。来源说明放在图旁正文，引用仍使用既有可点击溯源组件，不把链接组件注入 Mermaid 语法。渲染失败保留错误及源码；无关父级更新不重建图表。

- AI 文档笔记修改使用独立只读审阅页签，不把尚未确认的内容灌入编辑器。已有笔记标题区显示紧凑待审阅入口，助手提案提供“在笔记中查看修改”，审阅页提供“返回对话提案”和“打开当前笔记”；新提案不自动抢占阅读焦点。正文采用渲染后的完整内容块对比：红色 − 修改前、绿色 + 修改后，新增／删除保留文字标识，修改以旧／新内容成对显示，保留总增删行数。图表、表格、公式、列表不按源码行截断；普通代码块仍作为内容显示。复用共享预览但跳过 OCR 文本修复，不能压缩笔记缩进、修改数学定界符或截断长内容；复杂跨块引用保留完整版本。预览失败给出明确错误，不回退到整段源码。修改默认展开，可收起；长的未修改上下文可折叠但必须能完整展开。上一处／下一处只滚动审阅区域，并按 UI 缩放换算定位。审阅页拥有选择／展开／滚动状态，窗口级 NoteReviewProvider 是会话提案的导航投影，Conversation 与 Verified Proposal 保持唯一写入依据；切换资料库清空投影。审阅页固定确认／忽略栏委托已加载且空闲的原对话处理，按整条提案提交，不提供未经验证的逐行部分应用。与左侧卡片共享决定锁，处理中禁用重复提交和其他提案决定；已应用／忽略后移除按钮。其他对话的历史快照须先返回原对话再明确确认。应用中切换对话不抢回视图，结果与保存仍归原对话。未保存草稿阻止应用，原版本检查与来源组件不变。返回旧对话必须加载并展开目标消息、聚焦具体提案，并暂停自动滚到底部，后续流式更新不得覆盖主动定位。缺少原文快照或补丁不匹配时明确报错并禁用审阅页确认，不猜测对比；片段记录沿用原审阅入口。无新拖动手势，页签拖动、键盘关闭和原编辑器草稿保护继续复用工作区契约。

- 助手消息按容器宽度适配：不以整窗宽度判断窄侧栏。220px 下收起独立头像列，保留角色文字与左右气泡区分；提案标题和状态分行、长字符串可换行、查看修改按钮允许换行、确认按钮组可折行。消息列表保留原滚动所有者，不能用裁切隐藏溢出的关键操作。

- 标题与保存状态放在同一紧凑标题栏。
- 常用文字格式保持一行；颜色、高级组件和文件操作进入菜单。
- 正文是页面主要区域，不允许工具栏因换行长期占据大面积高度。
- 正文右键默认保留系统菜单；插入组件使用 `/`、明确的“插入”入口或块级菜单。
- 块拖动遵循第 6.2 节；嵌套列表只能拖动真实列表项，不能让用户误以为移动单项却移动整组。

## 8. 文案与信息表达

- 面向用户的中文应简短、具体、可执行；代码领域术语保持工程规范定义。
- 按钮优先使用动词：保存、打开、定位、重试、移到回收站。
- 状态描述事实，不使用“似乎”“可能已经”等模糊措辞。
- 错误信息包含发生了什么以及用户下一步能做什么。
- 标题默认不重复父级上下文；需要说明所属条目时用次要文本展示。
- 日期、时长、页码和数量在同一模块采用统一格式。

## 9. 可访问性

- 交互控件必须可通过键盘到达，语义元素优先于 `div` 模拟控件。
- 图标按钮提供 `aria-label`；状态变化使用适度的 `aria-live`。
- 不只依赖颜色表达状态，至少同时使用文本、形状或图标之一。
- HoverCard 不能是访问完整信息的唯一方式。
- 表格使用正确的 header/row/cell 语义；可交互行必须有键盘等价操作。
- 文本和关键边界应满足常规对比度；`muted-foreground` 不用于关键操作或错误。

### 阅读定位与文内预览

- 条目库标题与条目数量位于同一行，数量使用次要文本；没有描述或范围动作时不得预留第二行。搜索右侧的按钮、排序选择器和范围切换使用同一高度、字号、边框与圆角，主题材质由现有主题层覆盖。
- 每个重排片段均区分原图、解析后内容和翻译三个独立显示层，可同时开启；原图指资产图片或 PDF 区域截图，解析后内容指可选取文字、表格、公式或流程图，不能将文字原文称作原图。原图与解析开关不改变翻译选择。类型开关、各层默认值和大小由全局阅读偏好持有；正文默认显示解析内容，图片／表格默认显示原图、不显示解析内容。原图失败应明确说明并允许重试，不能静默替换成解析内容；解析显示不得受额外流程图总开关阻断。
- 片段右键的显示设置优先于同类型偏好，仅覆盖用户明确调整的字段，可恢复跟随组件。鼠标或键盘确认显示层、对照方式或恢复跟随后立即关闭右键菜单；上方组件配置面板仍允许连续调整。设置按工作区、条目及逻辑片段隔离，生命周期长于虚拟行；整段／逐句共用已保存片段译文，切换不提交翻译；旧独立逐句结果保留在存储中，但不覆盖当前整段译文。缺少译文时明确提供“翻译此段”，已有译文可在菜单选择“重新翻译此段”；只有失败的片段请求显示重试，不将旧逐句失败当作新错误。整篇缓存须匹配当前原文、片段和目标语言；本地配对不可靠时保留句组或整段。其他显示层及全局组件切换不隐式启动翻译。译文可整段显示或按句成对排列，均属于原有同一个片段。正文、菜单各自只保留一个滚动所有者，不新增拖动手势。

- 片段笔记是阅读位置的唯一持久化记录；正文和收藏标记分别更新，取消收藏不能删除正文。空正文的收藏仍是有效位置，旧笔记无需迁移即可定位。
- 笔记定位中的长预览按“笔记／对应原文”切换，不能将两份完整长文连续堆叠。浮层在条目上下避让视口，固定页码、内容切换和定位操作；外层不滚动，仅正文限高滚动，原文渲染器不再创建内部滚动区。悬停使用 HoverCard；明确的“预览”按钮或右方向键使用 Popover 持续查看，支持正文滚动、Tab 访问操作及 Escape 返回入口。空收藏直接展示原文，失效位置仍可预览笔记但禁用定位。列表、预览分别拥有自身滚动，不改变阅读器或笔记保存状态。
- 收藏写入由所在 EntryWorkspaceView 的 SegmentBookmarksProvider 持有，沿用记录刷新入口；失败保留已保存状态并提示重试，不以空数据覆盖失败结果。
- 每个 PDF／重排阅读面独立持有前进、返回历史；返回恢复页内或段内偏移。阅读内容继续使用原有 PDF 滚动区／重排虚拟列表，定位列表仅承担自身滚动。
- 右键菜单与片段笔记编辑器使用同一收藏状态；菜单中的收藏、翻译和普通动作复用 SegmentMenuButton 的字号、图标、间距、行高及键盘状态，不能混入工具栏的小号按钮。菜单继续持有焦点导航与滚动，编辑器保留紧凑按钮。工具栏提供笔记定位、搜索与收藏筛选。无原文的笔记保留内容并说明失效，隐藏目标不能静默跳到无关位置。
- PDF／重排左侧轨道统一使用横条，收藏、笔记和批注仅以语义颜色区别，不添加记录图标、胶囊底或行内数量；保留原有标题层级与悬停放大，类型和合并数量通过可访问名称及预览说明。键盘焦点沿用通用焦点圈，放大仅作用于横条视觉层，不扩大纵向命中区域。点击有标记的集合优先定位收藏，再定位其他记录，预览提供逐项定位；浮层事件不得触发轨道的空白点击或指针位置更新。
- 导航容量按可用高度、8px 最小间距及 160 条上限计算，标记与当前阅读变化不能降低容量或重新分组。仅折叠文档顺序上相邻的片段，优先保留独立标题；空间不足时标题也参与折叠，保留所有片段，不因页面坐标集中或大段空白浪费槽位。
- “只看标记”的筛选状态归各 SegmentRail，记录归原笔记与批注映射，数量按逻辑片段去重；筛选不触发正文跳转，不改变详细目录、选中状态或保存数据，清除最后一条记录后保留返回全部的入口。原阅读容器继续拥有滚动，轨道自身不新增滚动或拖动，聚合预览由 HoverCardContent 独占滚动。复用 Toggle、Tooltip 与 HoverCard，不增加悬停等待。
- 图表、公式和参考文献预览复用 SourceSnapshotPreview、HoverCard、Popover 和 ViewportOverlay。鼠标悬停即时预览，单目标点击定位，多目标点击选择；键盘聚焦预览，向下键打开可操作面板，Enter 定位、Escape 关闭。Alt+左右键只在阅读面导航，不拦截编辑器输入。
- 图片详情使用有界居中的 Dialog，图片初始双向居中、完整适应画布。图片会话独占缩放和平移状态，不写入阅读偏好；画布无滚动条，滚轮围绕鼠标缩放且不滚动阅读器，左键捕获指针拖动放大后的图片，边缘限制避免丢失图像。方向键平移、加减缩放、0 复位，Escape 在拖动中回滚、其他情况下关闭并恢复入口焦点；失焦、取消和卸载清理手势。详情中的鼠标移动与右键不冒泡触发片段预览或菜单，表格详情保留自己的大小和滚动。
- PDF 原生内部链接优先；目的地失效时，按链接实际文字与解析索引回退，不让失效链接遮住已有参考文献。只覆盖数字的链接必须结合周围完整引用或明确标签识别，不能从内部目标名称猜编号、把章节／页码误认成文献，或请求模型。PDF 引用层拥有命中几何与异步解析状态，原阅读器仍负责滚动与返回历史。图表缺少独立图片时按需读取原 PDF 截图，失败可重试；后台页和拖动期间沿用现有可见性／交互约束。
- 保持 PDF.js 文字层可选、可复制；引用命中区域独立覆盖，不改写原文节点。引用操作不能冒泡触发段落笔记编辑。
- 双栏文内引用必须同时核对编号、页码及横纵位置，不能按纵向距离选择另一栏。参考文献列表使用条目编号匹配正文和 `list_item_regions`，不依赖数组顺序；缺少横向坐标的 PDF 目的地保留整条范围，只有明确编号才能消除栏间歧义。无法确认正文时保留 PDF 目标预览与定位，不展示猜测的另一篇文献。列表预览高亮同样按编号或唯一正文匹配区域，合并、缺失和冲突项不能借用相邻区域。
- 列表区域的悬停译文与替换译文同样按文献编号取值；缺少区域编号时，通过翻译缓存的原文唯一匹配找回编号。无编号列表仅在原文唯一匹配且译文项数一致时按原文顺序对应，禁止用区域数组下标切译文；编号缺失、重复或冲突时不显示猜测结果。兼容 Markdown 转义、加粗、列表符号和全角括号，不重新请求模型或改写翻译缓存。

## 12. 规范维护

实时任务使用右下角独立 Popover 浮窗，不为它插入底部整行、空白面板或压缩阅读区。Windows 原生网页仅对与任务浮窗相交的局部区域裁剪绘制及命中，收起后恢复完整窗口区域；原网页 bounds、滚动、可见性及导航身份不变。浮窗几何使用与网页相同的主视图坐标及像素比例，监听、观察器和原生区域资源随开关／卸载释放；不扩展为自动隐藏所有网页或所有浮层。任务正文仍独占限高滚动，键盘与焦点沿用共享 Popover，普通 PDF／笔记继续使用原 DOM 层级。

助手的外部网页、PDF、字幕与公开检索证据使用实际工具成功结果中的 URL 引用；本地片段才使用真实登记的 `[S#]` 标记。引用纠正须说明本次实际可用的类型，不能要求为外部材料编造本地编号，也不能将正文内任意链接当作已读取证据。引用无法核实时保留失败事实并说明原因，不伪装为用户取消或未知写入。普通只读失败提供安全、固定的下一步提示，由主助手决定后续处理，不展示原始异常。

右下角实时任务优先显示当前资料库的全部未完成任务，区分进行中、排队、暂停、等待用户确认和停止收尾；完成历史默认折叠并限制数量，不能截掉暂停／等待任务。助手运行及消息队列、公开论文／Sciverse 添加、全文／片段／选区翻译、PDF 解析队列、批量 PDF 拖入与检索索引共用此入口。面板仅投影原执行器的真实状态，不能注册第二份执行任务；助手内的论文导入不再重复显示成助手对话。没有可靠总量时仅展示阶段，不猜测百分比。条目任务显示条目名称，助手任务显示对话及当前请求；返回操作路由到所属条目／对话，停止只作用于对应助手运行。复用 Popover、Button、语义 token 和限高滚动，缩放／窄窗口保持操作可达，流式 token 不触发任务列表重绘。选择翻译工具条卸载不丢失任务，终态释放执行资源，仅保留有限历史；任务投影本身不新增轮询或拖动手势。

助手待发送队列按资料库／对话归属窗口级注册表，不归局部输入框；当前回答结束并保存成功后按 FIFO 逐条发送。用户可展开、重新编辑或取消尚未发送的消息，编辑锁只阻止对应队头启动，后续消息不得越过；编辑仅改变文字，保留提交时冻结的阅读范围、附件与模型配置。Ctrl/Cmd+Enter 保存编辑，Escape 放弃编辑，退出编辑或删除后恢复到队列入口焦点，不跳动正文。停止或失败后保留未发送消息并暂停，需明确点击继续；待确认提案保存后同步到队列上下文，不能覆盖正在写入的运行。待发送队列同样禁止删除所属历史，并参与刷新／退出保护；只在本次应用窗口内保留，不宣称应用重启后恢复未发送草稿。

公开论文确认添加后接入现有右下角 JobStatusDock，与翻译、解析共用任务列表，不新增浮动任务窗。后端任务管理器持有排队、当前下载、已处理／入库／已有／失败计数及终态；只有消耗有效确认后才创建任务。超时、取消、部分失败及调用中断必须结束任务并保留已处理数量，不把进度计数称为成功数量、不虚构下载百分比。Sciverse 沿用原本地任务状态，已存在也必须结束任务。任务面板正文独占有界滚动，长错误完整换行，键盘和缩放沿用共享 Popover；运行任务不被历史数量上限截掉，资料库之间不混用状态，晚到初始快照不得覆盖新事件，卸载释放监听。此任务显示不授权自动重试、解析或修改论文。

全文翻译任务的暂停、继续、取消使用不同语义：运行时显示“暂停／取消”，暂停后原位提供“继续翻译／取消”。暂停保留本次任务身份、选择范围与剩余片段，但不占用请求连接或后台轮询；继续只恢复该任务，暂停期间不可改范围或开启覆盖任务。取消结束任务、清除待执行范围，保留已完成译文并回到明确创建新任务的入口，不再提供继续旧任务。Task 与 Workspace 持有真实状态及持久化快照，阅读器共享同一个 hook；任务面板保留唯一片段列表滚动区、原生 Button 键盘操作及既有拖动契约。处理中禁用重复动作，原文或模型配置失效时保留暂停任务并明确提示。全局任务栏区分暂停和取消，暂停不显示运行动画或完成提示。

PDF 解析的“未解析”与“排队中”必须来自不同的真实状态，不显示猜测百分比。条目库解析分组内复用紧凑任务行，分别展示进行中、按执行顺序排列的等待项及默认折叠的失败项；标题可打开 PDF，等待项提供置顶／上移／下移／移出队列，使用共享 Button 与键盘焦点，不新增拖动手势。原解析 SidebarPanel 仍是唯一滚动所有者；任务及顺序由 Rust Workspace 持久化，App 负责当前资料库打开期间的调度唤醒，收起侧栏不暂停。已提交任务不能通过列表顺序强行插队或取消远端操作。未配置、读取失败、排队、上传、服务端等待、解析和失败分别表达，失败可明确重试；移出仅取消本地等待，保留 PDF。助手下载继续默认未解析，不隐含解析授权。

论文检索配置复用 SettingsGroup、SettingSwitch、Input 与 Button，组件拥有草稿和保存状态，设置页仍独占滚动；免费服务缺省启用，保留用户已保存的关闭选择，不以密钥作为基础网页工具的启用条件。Tavily 收进默认折叠的可选增强，需主动开启，保存密钥不等于授权使用；凭据草稿只保留在当前设置会话并接入关闭保护，成功保存后清空。折叠入口使用原生 details/summary，沿用 Tab、Enter/Space，不拦截键盘或增加拖动。论文下载确认复用 ToolApprovalPanel 的运行所有权与独立限高滚动，真实候选预览由后端返回，不采用模型自述作为确认依据。展开摘要、拒绝、确认均可键盘操作，无自动聚焦／回车提交或新拖动手势；窄侧栏标题、网址和按钮自然换行。确认与后台任务隔离，切换会话不自动批准，停止时迟到的批准结果不能继续执行。PDF 导入不自动解析，不改变笔记和标签；原内联溯源与提案审阅继续有效。

应用退出保护同时读取未保存编辑与窗口级全部助手运行记录，包括其他资料库、等待用户输入及停止后收尾中的任务。原生关闭请求说明原因并阻止意外退出，用户需先处理或停止任务、等待保存结束；浏览器刷新沿用 beforeunload 提醒。不得因关闭提醒直接取消任务，也不得将窗口内后台运行宣传为退出应用后继续运行；注册和异步注册后的监听器均须在卸载时释放。

阅读工具条显式提供文档内后退／前进，复用 ReadingNavigationScope 的历史与 Alt+左右键；PDF 恢复页内位置、横向滚动和缩放，重排恢复虚拟列表位置与横向滚动。不新增全局或跨文档历史。选区操作复用原 PDF 工具条，重排只接受同一正文片段内的选区，提问／解释附加确切文字和来源页码，不直接发消息或写文件；翻译沿用固定任务服务，失败原地重试。选区状态归各阅读器，正文滚动仍归原容器，浮层内部独占长译文滚动；滚动正文、失焦、Escape 或外部点击关闭重排选区工具条，拖选文字不触发正文定位。浮层需转换应用缩放后的几何坐标并约束于视口。

重新打开时按资料库恢复可重开的阅读标签、顺序、固定状态、分栏与当前标签；先等资料库目录就绪，再验证对象身份，不在加载中覆盖已保存会话。PDF／重排的页内位置、横向滚动、缩放及原文／译文模式按独立视图保存，分屏恢复不得互相覆盖；PDF 的预估高度变为真实高度后校正锚点，任何用户滚动或新跳转优先于旧位置恢复。记录不包含未提交表单、聊天回复副本或审阅决定，也不自动运行模型。正文继续由原容器滚动，不新增键盘或拖动行为。

助手记住最近一次手动选择的引擎，重开及新建对话沿用；历史对话的引擎只影响该对话。记住的本地 Agent 不可用时明确提示，禁止静默回退到普通模型；异步保存的旧选择不得覆盖较新的选择。保存失败保留本次选择并提示下次可能无法恢复，模型选择不改变既有发送、审阅和授权合同。

助手输入区显示阅读对象，允许搜索并固定论文／笔记，默认跟随阅读且已附选区优先；附加资料可预览正文与页码。草稿目标归 AssistantPanel，发送和排队时冻结到运行快照，切换页签不改变已提交任务；新建对话重置固定目标，对象失效时阻止发送而非静默改用当前页。对象选择复用 Popover、Input、Button 和语义 token；写入继续走既有提案确认，不由阅读对象选择授权。

草稿与已发送消息的引用共用紧凑引用标签，鼠标悬停／键盘聚焦通过共享 HoverCard 预览完整快照、资料名称及真实页码，点击标签直接定位原文；笔记引用打开对应笔记，标签范围仅预览。浮层沿用选字／拖动优先权、Esc 和外部滚动关闭契约，长正文只在浮层内滚动；原文滚动仍归阅读器。未发送引用右侧的移除按钮只在悬停／键盘聚焦时显示，触屏常显并预留宽度，长标签截断不能产生横向滚动或挤掉移除入口。编辑器引用移除为独立可撤销操作，保留问题正文；外部附加引用提供撤销提示，不能恢复到另一资料库。已发送引用及回答来源不提供删除，不修改历史快照。提交的 [C1] 引用恢复为可预览／定位标签，[S1] 保留原定位路径；代码、普通链接和未知编号保持原文，对应附件不能因编号出现在代码中而被隐藏。导航归 App 的既有工作区操作，保留关闭保护和不可用来源反馈，不新增拖动手势、持久化副本或依赖。

原文 PDF block 采用 Ctrl + 任意正文位置拖动加入聊天草稿，不再提供角落拖动柄。按下主指针时根据 Ctrl 与实际 block 几何确定手势并捕获，移动 6px 后才开始拖动；普通拖动仍归原生选字，中途按下／松开 Ctrl 不转换手势，Ctrl 单击不添加或选中块。链接、按钮、输入区和预览正文保留原交互，Alt 点击笔记及 Ctrl 滚轮缩放不变。页面提示快捷操作，Ctrl 悬停用淡色填充标记可抓取块；现有片段菜单与键盘入口继续支持添加上下文。手势由 PDF 页的 usePdfBlockDrag 持有，复用 usePointerItemDrag、PointerPreview 与可见落点检测；目标反馈只出现在可编辑且同资料库的聊天输入框，使用指针穿透的半透明遮罩及“松开鼠标，加入此片段”提示，不增加拖动描边，不改变目标尺寸。移出、放下、取消或目标禁用后移除遮罩。放下插入现有行内片段引用，保存完整原文、论文和真实页码，不替换问题、不自动发送、不重复插入同一片段；引用与撤销归编辑器，发送仍由原快照流程处理。取消、失焦、目标不可用和无效落点不添加。hover 浮层避开原文块，拖动期间关闭 hover 正文；自动滚动只作用于指针下的原滚动容器，完成／取消／切换／卸载释放指针和临时样式。

PDF 片段菜单的“附到助手对话”与输入框正文插入共用行内引用流程：在当前光标／选区末尾插入，不覆盖已写问题或选中文字；保留完整原文、论文及页码，同片段去重，内容更新替换该引用而非重复附加。引用转为行内后不再另列附件，移除后允许再次添加，撤销不清除原问题。只读期间保留待插入资料，可编辑后转换；隐藏面板不得抢夺导航或焦点。编辑器拥有草稿、选区和撤销记录，父层继续拥有上下文与提交快照，Tiptap 节点插入避开 React 提交阶段并清理迟到任务。

对话消息以左侧助手／右侧用户气泡、角色文字及小头像共同区分，不只依赖颜色。正文、来源及待确认修改继续复用原组件；执行中的紧凑详情行显示动态圆点，减少动态效果时保持静态，完成后移除动画。消息列表仍是主要滚动所有者，详情与后台任务长列表分别限高滚动；不新增拖动行为。窗口级 assistantBackgroundRuns 持有按任务身份及资料库／对话隔离的运行记录，AssistantPanel 只订阅当前选中对话；切换、新建、收起或卸载面板不取消任务，过期异步回调不能切换页面或覆盖新会话。同一对话只允许一个运行写入者，其他对话可以并行；排队请求归属原对话，在原任务成功后继续，停止或失败不自动执行后续请求。后台列表提供返回与独立停止，运行中的历史记录禁止删除、重命名和导出。执行仍受原权限、预算、持久化及审核约束；窗口关闭后不继续运行，重开沿用检查点恢复。新建／历史／停止及详情按钮保留键盘访问，停止不影响其他任务。

助手过程信息统一由每条消息的 ExecutionDetails 持有折叠状态，默认仅显示一行状态/总耗时入口。思考文本、规划、工具轨迹及记忆详情按需挂载，流式增量和结束状态不能自动展开；复用 Button、DisclosureIcon，支持 Enter/Space，关联 aria-expanded/aria-controls。展开内容是唯一限高内部滚动区，原 AssistantPanel 继续持有会话滚动，不增加拖动行为。回答正文、来源链接及待审核修改保持外露，执行失败保留简短可见提示；空正文不预留光标空行。显示收起不代表关闭模型推理或减少模型请求。

条目元数据提案按卡片实际宽度布局：内容宽度不足 480px 时修改前后上下排列，足够宽时等宽并列；不能使用整窗断点决定侧栏列数。条目名独立完整换行，长标识、链接与描述不得撑开网格；操作和状态可换行，不依赖横向滚动或裁切保持边界。提案状态仍归原消息／执行器，卡片无独立滚动，消息列表承载完整对比；确认、拒绝及来源沿用原生按钮键盘行为，提交中禁用重复决定，不自动写入或重试，无新拖动和依赖。

工具错误是主助手的执行观察，默认不把异常正文直接展示给用户。主助手负责说明实际影响、已完成和未完成内容；执行记录保留失败事实但使用固定简明提示，不将子工具失败等同于整个回答失败，结束后不继续显示“正在处理”。审核、论文添加、任务提示和历史错误沿用同一安全展示规则。诊断入口位于“工具与扩展 / 诊断 / 助手调试信息”，默认关闭，开发环境也不自动开启；该本机偏好只控制诊断分类与状态码可见性，不能暴露密钥、私密路径或远程响应正文。复用共享 Switch 和设置搜索，消息、详情、任务列表和设置正文保留各自原滚动所有权，开关遵循现有键盘契约，不新增拖动行为或常驻错误弹窗。

助手输入区不提供普通执行／仅规划选择器，用户通过自然语言表达需求；自动分流由 harness 持有并冻结到任务检查点，不能由迟到分类或切换会话改变。语义候选当前仅观察，高把握的独立问候才进入无工具轻量路径；读取、修改与不确定需求仍交给主助手。诊断复用默认折叠的 ExecutionDetails / 工具事件列表，不新增常驻卡片或设置。旧历史请求的只读标记和恢复边界保留，但不要求用户切换模式。AssistantPanel 仍拥有草稿／排队入口和消息滚动，后台运行归原注册表，键盘发送、停止与拖动契约不变。计划正文不是修改确认；通用等待文案为“正在处理”，不能将整个任务时长标成模型思考时间。

助手消息正文默认使用 text-sm／leading-6，已完成回答的“展开阅读”在侧栏旁的阅读工作区新增独立只读页签，不再弹出 Dialog；再次打开同一消息复用原页签，正文使用 text-base／leading-7 并独占滚动，继续使用原 Markdown／溯源渲染器。App 的 surface layout 持有页签身份及关闭／分屏／拖动，左侧对话保持原会话和滚动；回复快照只随页签存活，不成为新的笔记或写入授权。确需澄清时主助手通过 ask_user 提供单选／多选、自由补充和可选的真实方案预览，不从旧消息字符串猜测执行按钮，不预选或自动提交。待答问题及草稿归资料库／对话所属运行，切换或卸载视图不取消；等待时显示静态“等待你的选择”，暂时隐藏普通输入区并保留草稿。问题正文独占限高滚动，标题与提交区固定，键盘遵循原生 radio、共享 Checkbox／Textarea／Dialog 契约，无新拖动行为。预览和提交意图均不授权写入，笔记及其他修改仍走原审核路径；取消明确停止所属任务。未提交草稿不跨进程保存，恢复未完成问题需重新回答，不能恢复为隐含同意。

所有模型的已完成回答共用右上角“展开阅读”图标与文字按钮，默认可见，消息悬停及键盘聚焦增强提示，不把整段正文变成点击区。空回答、用户消息和流式回答不显示此操作。完整回复中的本地证据按回复身份定位到另一分栏打开 PDF 并跳转片段／页码；切换证据后仍保留回答页签与原滚动位置，导航沿用原关闭保护。Sciverse 来源继续使用其来源展示能力，不把尚未导入的检索记录伪装成本地 PDF 跳转。无新增拖动手势或依赖。

Markdown 链接的组件身份在父级焦点刷新期间必须稳定，不能在 pointer-down 与 click 之间重建证据按钮；来源与回调读取当前数据。验证证据交互需覆盖完整指针序列，不能仅调用 click。跳转请求按稳定 surface 身份投递，阅读器准备就绪并执行定位之后才能标记完成；取消及被未保存保护阻止的导航不得消费请求。

阅读对象支持默认跟随、固定对象和显式不关联三种状态。固定对象按标签、条目、PDF、笔记分类搜索；固定标签作为包含子标签的检索范围，不能误当作当前论文。对象旁取消入口及菜单中的“不关联内容”均取消隐式条目／笔记／选区绑定，清除发送快照里的对象标识，不因切换标签页自动恢复。取消后焦点回到选择入口，可随时恢复跟随；手动附加资料和已有对话继续保留，界面须明确说明，不把取消对象宣传为清空上下文或禁止资料库工具。状态归 AssistantPanel，排队与运行中的任务冻结各自的对象和范围快照，候选列表滚动与原键盘契约不变。

助手回答以 Agent 汇总正文为主体，Sciverse／网页等检索结果不是第二份答案。论文推荐作为正文中的结构化列表展示，模型仅按工具返回的 paper_ref 选择、排序、分类并给出理由，标题和动作来自真实记录；宿主校验后在每篇论文旁显示查看、添加和内联状态，不按标题或自由文本猜测导入对象。未推荐候选默认折叠，来源详情保持原定位；不另加默认展开的底部添加清单。流式未完成块不暴露内部 JSON 或提前创建操作，旧 Markdown 保留原文。Sciverse 沿用现有本地导入服务并明确 PDF／远程全文／元数据降级；search_papers 添加先取后端真实预览，再逐次确认，缓存过期、无 PDF、失败和已存在分别提示。普通论文导入不自动解析、加标签或写笔记。状态归资料库级 ResearchPaperActionsProvider，对话和阅读页共享，关闭局部视图不重置添加中／完成状态；公开论文下载复用后台任务注册、取消和退出保护，完成释放运行记录。反馈采用内联 status／alert 与现有 Toast，失败可重新预览后确认重试，不弹成功 Dialog。来源区独占限高滚动，开关使用 Button 的 aria-expanded／aria-controls；记录数不称为去重论文数，不展示原始片段、内部编号或猜测页码，完整证据继续通过来源详情查看。无额外模型请求或新拖动手势。

设置界面遵循以下共享约束：

- 打开模型配置弹窗时焦点落在对话框容器，不自动聚焦输入框或展开候选；主动点击、Tab 进入或输入后才展开。提供商和模型候选列表最大高度为 32rem，并受弹窗可用高度约束；列表仍独占滚动，PageUp/PageDown 按实际可视行数移动，不扩大单项高度。
- 提供商与模型共用 CatalogCombobox：原字段直接输入，聚焦／输入展开下方候选，不在菜单内再放搜索框。原 Input 始终持有焦点，Enter 选择、方向键／翻页键导航，Ctrl+Home/End 到首尾，普通 Home/End 保留文本编辑，IME 确认不触发选择；Escape 仅关闭候选，Tab 前往下一字段。提供商查询未经选择不改连接；模型输入直接更新自定义 ID 草稿，但只有选择候选才回填规格。两种候选都虚拟化且不截断数量。非模态 Popover 的 Portal 位于所属 Dialog 内，沿用其滚动锁并按容器避让，不截获原输入框；外层对话框滚动、保存／取消不变。
- “模型与助手”和“工具与扩展”共用 SettingsPage / SettingsGroup 的标题、分隔线、720px 居中表单及按钮规格。模型页先显示默认对话模型与翻译设置入口，再显示连接列表；参数仍在连接编辑器内始终展开，搜索参数定位到连接编辑入口。工具页将基础检索与可选服务分组，Tavily / Sciverse 共用 SettingsServiceSection：配置与状态始终平铺，搜索直接定位控件，正文沿用页面唯一滚动区。Sciverse 的凭据反馈就地呈现，不重复 Toast；未保存草稿接入关闭保护，切换分类保留草稿但隐藏明文，关闭／卸载释放注册与过期明文回调。没有新增拖动或 UI 依赖。
- 提供商列表使用现有 TanStack Virtual、Input 和 Button 组成可访问的虚拟列表，不截断候选数量，不显示匹配总数／前 N 项及重复凭据说明。搜索与活动项归选择器，listbox 独占滚动；方向键、Home/End、PageUp/PageDown 在完整数据上导航，Enter 确认，Escape 由 Popover 关闭并归还焦点。活动项保留挂载以维持 aria-activedescendant，关闭释放虚拟化观察器。不能直接使用仅导航已挂载子项的 cmdk 选择逻辑。
- 顶层按用户任务分类；同一设置只有一个主位置，相关页面提供跳转，避免重复维护。
- `SettingsPrimitives` 组合已有 Switch、Checkbox、Select 和 Label。开关表示独立启停，互斥方式用选择框，内容范围和授权集合用复选框；依赖项禁用时保留原值并解释原因。
- `settingsCatalog.ts` 是设置页、全局搜索和侧栏搜索共用的静态目录；新增可搜索设置必须有唯一 `data-setting-id`、可见名称、同义词及所在分类，不索引用户值或凭据。
- 跳转先激活分类，再在 `.settings-viewport` 内滚动、聚焦和短暂高亮；重复请求使用新的 nonce。分类保留草稿和各自滚动位置。
- 设置定位高亮采用目标外扩的轻底色及细边框，上下 8px、左右 12px 留白，不动态添加内边距或挤动表单。定位在唯一设置滚动区为高亮预留 24px 顶部距离，并按实际 CSS 缩放换算；伪元素不接收指针，输入、键盘焦点及三秒高亮清理仍归原导航控制器。
- 设置内容只有 `.settings-viewport` 承担滚动；分类列表独立滚动，窄面板使用分类选择框。表单列数按容器宽度决定，不依据整窗宽度。
- 设置画布铺满可用宽度，模型列表随其 720px 表单居中，操作保持自然宽度。普通设置组及“说明＋控件”行左对齐，最大宽度 720px；说明列最多 420px，与控件间隔 16px，避免开关被推到页面远端。选择框宽 280px，内容容器窄于 480px 时放到说明下方并占满行宽；开关保持与说明同行。复选框组最大宽度 480px，按容器宽度自动换列。网格子项允许收缩，避免最小内容宽度将控件推出边界。
- 普通设置页通过 `.settings-form` 统一限制标题、表单和说明的内容宽度，并在右侧可用内容区整体水平居中，内部文字及控件保持左对齐；导入解析、资料库与 Sciverse 同样适用，模型页任务选择及高级区域也遵循 720px 上限并居中。搜索结果与表单使用相同内容宽度并居中；窄屏保留正常内边距、填满可用空间。资料库操作允许自然换行，Sciverse 凭据输入与操作按自身容器宽度重排，不使用整窗断点决定分屏布局。
- 自动保存由设置控制器持有，串行写入并保留失败草稿；使用现有关闭注册表完成保存保护。模型连接编辑采用明确的保存/取消，保存失败保留弹窗。
- 模型连接使用紧凑分隔列表，信息、能力与操作随列表容器宽度从三列收敛为两列或单列。长名称与地址截断并保留完整提示，操作不拉满整行；模型编辑复用独立共享 Dialog，正文独占滚动、底部保存／取消固定，字段按可用宽度换行。设置页眉与分类复用侧栏材质，正文沿用主题语义底色；不新增拖动行为，键盘、草稿和保存仍归原控制器。
- 模型目录复用 CatalogCombobox 与 Popover，只列出上方所选提供商的公开型号、内置预设及当前接口返回的模型，不再提供重复的提供商／全部模型范围切换。搜索和开关由选择器持有，列表独占限高滚动；键盘沿用方向键／Enter 选择及 Escape 关闭，不增加拖动。没有候选时仍可自定义模型 ID。连接草稿归 SettingsPanel，选择模型才回填规格；后台更新、失败与取消不得覆盖手动值。高级参数在编辑表单内始终展开，不保留折叠按钮，仍由原正文滚动区承载，保存／取消固定。公开参考与当前填写分开显示，未知值不猜测，加载和失败可见，禁用期间关闭浮层并阻止选择。
- 模型 ID 使用单一“可编辑输入＋下拉候选”控件，直接输入与候选确认共用原草稿；原字段输入直接更新自定义 ID 草稿，选择候选才回填规格，Escape 只收起菜单。提供商选择复用 CatalogCombobox，中文别名、大小写、标点与子序列匹配在本地计算，未知 ID／规格不按相似名称自动推断。提供商候选独占限高滚动，缺少地址或协议时仍可选，明确提示“选择后补充连接参数”，不得把整行禁用。编辑器保留所选提供商身份用于模型筛选，未知协议需显式选择后才能自动请求及保存，不猜测专有协议的兼容性。切换提供商清空旧凭据，保留正在编辑的配置身份；普通模型选择不改变提供商。地址和接口类型的标签／控件分别同排对齐，解释文案放在整行下方，不由一侧说明拉伸另一侧。移除原提供商按钮墙及展开状态，不新增拖动或 UI 依赖。
- 模型候选浮层以完整输入行作为 PopoverAnchor，左对齐且限制触发器／视口宽高，不以箭头按钮定位；采用 Dialog 内非模态 Portal 沿用外层滚动锁，列表有可见滚动条，原输入框固定；没有重复搜索框或计数说明。重复 ID 不再占第二行，当前模型显示勾选。接口列表由打开的编辑器在地址、协议或密钥变化后防抖 800ms 自动同步，云端等待密钥、本机允许空值，关闭／变更／超时取消并拒绝旧结果；仅失败时显示就地重试，不循环重试、不弹 Toast、不覆盖模型和参数草稿。自动同步不是保存配置或调用对话；更改地址清空旧凭据。公开目录状态和说明平铺展示，支持手动更新。

AppearanceIcon 复用已有导航物体资源，小型动作保留明确的线条符号并使用主题金属底和浮起／按下状态；补齐每日看板、设置、导入、创建和边界手柄的拟物外观。边界手柄复用同一金属面、细边与按下阴影，展开时显示原点状 GripVertical，折叠时只显示向右 ChevronRight，不增加叠套图标底座。拖动手柄和展开箭头在普通、悬停、按下与聚焦状态下均使用完全不透明的实体底色；玻璃主题也不透出正文或使用背景模糊。共享导航滑块采用拟物主题的黄铜边和按下阴影，标准与玻璃主题继续使用自己的语义样式，无新增依赖。

### 拟物书脊与立体书页

拟物条目库独有书脊、封面、列表三种展示，AppearanceProvider 持有本机展示偏好，默认书脊，尊重已有选择。书脊和封面共用原筛选、选择、右键操作、拖动和唯一书架滚动区；方向键按实际列数移动，Home/End 和虚拟化焦点契约保持一致。窄列标题省略并通过原生悬停提示展示全文，状态或解析操作从封面/列表或原右键入口访问。标准、玻璃风格保持列表。强调色选择仅适用于标准风格，其他主题使用预设语义色，保留原标准强调色。

书页模式的封面开合由阅读面板持有，阅读位置和翻页继续由 usePdfBookNavigation 持有，PdfBookModel 只负责展示。封面复用论文已有封面生成器及配色；点击或键盘激活打开，合上保留位置，搜索/定位自动打开。PDF 正文、选字、批注和缩放仍使用原页面及同一滚动区。相邻页翻动使用连续曲面网格与现有 PDF 快照，不新增 PDF 渲染管线；缓存尚未就绪、方向不一致或减少动画时直接定位，WebGL 不可用回退到原 CSS 翻页。隐藏标签、离开书页、失去图形上下文和卸载释放图形资源，动画完成后不保留渲染循环。每日看板和设置的拟物 PNG 使用透明背景，但按钮表面继续保持既定不透明材质。

书架取书过渡由根级 BookOpeningProvider 持有，先从实际书脊/封面位置取出并转正，再打开前封面，最后调用原 Tab 打开动作；重复点击不重复提交，Escape/取消/窗口变化在提交前不导航。根级覆盖层复用 Dialog 焦点契约，无第二滚动区，取消恢复书架焦点，完成后向可见阅读区移交。所有封面使用共享 BookVolume 的实时 DOM 文字、布纹和六个三维面，不再将标题烘焙为图片。短时内存交接标记避免阅读 Tab 再展示一次封面，不写入资料库。减少动态效果直接打开。

正文翻页以右下角（反向为左下角）为起点，斜向圆柱折线逐步向书脊移动，保留未掀起区域，末帧平铺到另一侧。使用双向细分网格而非整页旋转；翻页触发区在纸面下角，保留 PageUp/PageDown 和原拖动手势。原生窗口截图工具超时时，必须明确未完成视觉验收，不以几何或交互单测代替手感验收。

### 每日推荐中的生活组件

每日看板左侧的显示偏好由 useDailySidebarPreferences 持有并保存在本机独立键中，不改动资料库阅读/待办/笔记数据。日期保持在顶部，黄历、吃饭老虎机、星座运势和阅读建议可以显隐并用上下按钮排序；全部隐藏仍保留设置入口。侧栏正文拥有唯一纵向滚动，显示设置 Popover 只管理显隐和排序；菜单编辑使用独立有界 Dialog，正文独占滚动，页头和保存操作固定。切换侧栏关闭浮层和弹窗。复用 Checkbox、Select、Button、Input、Dialog 与语义颜色，无新增拖动操作和依赖。

MealSlotWidget 持有短暂的滚动动画，在完成后才提交选择；同日结果保存、可重抽，多选项时避免立即重复。自定义菜单去重并限制数量/长度，空菜单明确引导编辑；按钮使用原生键盘激活契约，滚动文本不反复播报，只有结果区播报状态。离开侧栏、切换日期、改菜单和卸载取消动画，迟到结果不保存；减少动画时直接给出结果。星座在“外观与界面 → 每日推荐”中保存为本机偏好，侧栏按星座与本地日期请求爱云 API 的中文今日运势，显示来源及娱乐提示。成功、失败和中断状态按日期缓存在本机，同日重进不重复请求，用户显式刷新或重试才再次请求；日期或星座变化后重新获取。接口失败显示错误，不将旧本地生成文案伪装为联网结果。切换侧栏取消请求并忽略迟到结果；不显示健康或财务建议。两者可在未打开资料库时使用。偏好写入失败保留本次选择并显示错误；隐藏阅读建议时停止其模型请求。

吃喝抽取区最大宽度 320px、水平居中，窄侧栏随可用宽度收缩；结果行突出显示，按钮按内容宽度居中。菜单按正餐、小吃、大餐及统一的“喝点什么”分组，复用 Select 分类选择；不再提供“怎么吃”或菜单搜索。编辑弹窗支持逐项添加/修改/删除、撤销最近一次删除及恢复分类默认项；关闭放弃草稿，保存一次提交所有分类的草稿，并显示当前分类用于抽取。旧三类饮品菜单一次性去重合并，旧饮品选择迁移到新分类，已删项目不会重新加入；旧“怎么吃”自定义内容只在本机偏好中保留，不再出现在抽取界面。候选饮品为可修改的本地示例，不表示附近门店实时供应。旧自定义正餐菜单保留，主动清空不恢复默认。切换分类取消未完成抽取且不重新挂载选择器，保留键盘焦点。持久状态仍归 useDailySidebarPreferences，原滚动和键盘契约不变，无新依赖。

翻译行为使用一个“默认翻译来源”下拉选择专用服务或已保存的大模型连接；五类行为提供“跟随默认来源”与显式覆盖。变更默认不覆盖显式来源，旧设置沿用原有来源。草稿由 TranslationSourcesSettings 持有，滚动由设置页持有，键盘选择沿用 SettingSelect；不另设仅支持大模型的默认选择器。

条目库表头点击按升序、降序、默认三态循环，新列首次点击统一升序。默认恢复当前视图原排序（普通条目为创建时间倒序，最近阅读为访问顺序）；状态仍归 EntryLibraryView，Table 保持滚动和列宽拖动契约，按钮的提示及 aria-sort 与当前／下一状态一致。

选区翻译在发出请求前仅规范请求副本中的 PDF 换行：英文间补空格，中日韩文字间连写，处理软连字符；原文选区和批注定位不变。专用服务的 HTML、公式等格式标记留在本地，不要求服务复述占位符；普通无格式段落仍整段请求。单项调用失败写入对应段落并继续，任务结束汇总未完成项；只有配置初始化或持久化等无法继续执行的问题中断任务，已完成项保留。

PDF 悬停配置仅保留一个主开关，在“解析后原文”和“译文”的可见开关下分别设置整段／逐句，不再提供独立逐句开关。两种粒度共用一个片段预览，逐句原文定位失败或译文无法可靠对齐时，分别回退整段并解释；整段也无译文时明确显示暂无译文。控件复用 Select，状态归阅读偏好；预览布局、滚动、Escape 与拖动关闭规则沿用现有组件，不触发翻译调用。

### PDF 悬停句子与选字翻译

开启逐句悬停时，可定位真实文字范围的句子在右上方显示“选中此句”图标按钮，位于整句最右边界旁并限制在页面内。按钮直接复用全局选区浮窗和自动翻译设置，不再接管正文单击或要求修饰键；普通片段操作、双击选词、拖动选字、Alt 笔记、Ctrl 拖拽和图片双击保持原有契约。跨越文字到按钮的空隙时延迟关闭，移入按钮取消关闭；按钮按下不得触发全局悬停清理或清除现有选区。

选句后仅淡化本片段其他文字，仍允许悬停另一句并显示高亮和选句按钮；再次选择替换全局选区并遵循已有自动翻译设置，不重复打开笔记。现有选区浮窗优先，暂停竞争的悬停预览。状态归原选字 hook 和页面，滚动归原阅读容器，Escape、切页、失焦沿用清理契约，无新增依赖。

PDF 显示状态的 Context 单独放在 readingViewContext.ts，组件、翻译控制器和导航均直接引用，避免开发热更新更换组件模块后消费者仍持有旧 Context。顶部原文／译文按钮使用普通 button，不提交外层表单；切换只显示已有译文，不触发翻译请求。

### 重排组件配置与单段对照

组件浮层采用紧凑设置表：固定说明头部与恢复默认底部，中间独立滚动；顶部单列全局正文对照方式，下方按类型列出显示、大小与可多选的内容层，并解释原图、解析后内容、翻译的含义。复用 Popover、Select、Switch、Toggle，不新增依赖。全局设置归原阅读偏好，单段设置归 ReflowSegmentPreferencesProvider，按资料库和条目保存，虚拟列表卸载不丢失。

正文信息栏在悬停或键盘聚焦时显示“跟随／整段／逐句”，使用与详略同高的 ToggleGroup，预留空间避免跳动，窄宽度沿信息栏横向滚动。切换仅修改本段对照方式，不启动重译、不覆盖内容层显示。恢复跟随只清除本段对照覆盖。单段逐句只暂停本段详略，其他段落不变，恢复整段或跟随后沿用已有详略设置。右键菜单同样不再改变全局详略；标题、图表、公式等不显示逐句入口。方向键和 Enter／Space 沿用 ToggleGroup，Escape 返回片段，不冒泡触发导航、预览和拖动，正文滚动仍归原虚拟列表。

组件浮层宽度收敛为 22rem，使用当前阅读面作为碰撞边界，并按可用宽高收缩；从阅读工具溢出菜单打开时也由阅读面提供同一边界。每类内容先显示类型、总开关和大小，下一行放原图、解析后内容、翻译三个独立 Switch，开启项使用主题边框与浅底色。全局逐句对照使用 Switch，关闭即整段；单段跟随／整段／逐句继续保留三态选择。

内容层开关收为单行紧凑标签与小 Switch，不再纵向堆叠。文字和图像大小沿用原生 range（与重排外观一致），50%–200%、1% 步长实时预览，显示当前百分比，支持键盘方向键/Home/End。阅读偏好保存实际比例并兼容旧档位；图像尺寸及虚拟高度估算同步支持数值。隐藏组件时禁用滑杆，恢复默认沿用原入口。

### 公共控件辨识度

Button 的 outline／secondary 与 Select 触发器统一使用 control-surface、control-border、control-hover、control-active 语义色，从当前主题派生底色和清晰边界。展开项加强主题边框，Select 已选项同时有底色和勾选标记；ghost 保持轻量但增强悬停边界。禁用态和键盘焦点沿用原组件契约；玻璃、拟物外观保留材质并加强普通控件轮廓。状态、滚动、键盘和拖动所有权均不改变。

组件总显示保留 Switch；下级原图、解析后内容、翻译改为紧凑 Checkbox，使用缩进与轻分隔线明确从属关系，避免四个同形开关混淆。百分比为可聚焦按钮，点击或 Enter/Space 只将当前组件大小恢复 100%，禁用状态跟随组件总开关。公共按钮与 Select 使用更柔和的中性底色、边框和低饱和悬停色，不改变事件和滚动契约。

公共 Button／Select 默认外观采用 macOS 风格的轻量中性控件：普通状态无可见描边，统一淡主题色填充；使用当前 primary 与 card 按 sRGB 混合，默认 12%、悬停 20%、展开 28%，不再混入前景灰色。主题切换后控件同步变色，以同一主题色加深表达状态；主要操作保留主题色。轮廓通过轻微阴影而非高对比边框建立，键盘焦点环和错误提示仍保留，禁用态沿用透明度。自选玻璃与拟物主题恢复各自材质，不再额外强化描边。

阅读组件浮层保持 22rem 宽度与阅读区边界，组件行增加到上下各 20px 留白，两行控件间隔 16px；分隔线降低对比。头尾分别增加留白，内容层说明改为默认收起的原生 details，按需展开，主设置列表仍独占滚动，不改变任何选项或保存行为。

PDF 悬停原文和译文使用同一个 HoverContentSwitch：上层 Switch 控制显示，开启后展开缩进的“逐句显示”Switch，关闭子开关即整段。关闭父级保留粒度，主悬停关闭时所有子项禁用；原文和译文的显示与粒度独立，回退整段时继续提示原因。重排沿用现有整段悬停，不提供尚未接通的逐句开关。Button outline／secondary 与 Select 恢复淡主题色细描边，与主题色底面共同表达可点击性。

HoverContentSwitch 改为单个复合开关外观：同一圆角轨道内左侧嵌入整段／逐句滑动选择，右侧为显示开关。两者是同一非交互容器内的独立 switch，不将按钮嵌套在按钮中。下方实时显示显示整段原文／显示逐句译文／已关闭／悬停已暂停；关闭显示时内部粒度仍可见但禁用，重启保留选择。原文与译文复用同一组件且不串改设置，键盘 Tab 和 Space／Enter 可分别操作。


译文页的句子按钮和原生拖动选字均读取可见译文 DOM 的 Range，使用同一选区浮窗直接查看对应原文，不调用翻译 API。准确对齐时显示所选译文所在句的原文，多句按顺序合并；不能准确对齐则明确回退整段原文。浮窗沿用复制、提问、固定及关闭能力；译文重排坐标不写入 PDF 原图批注，避免高亮落在错误位置。状态仍归页面选区 hook，正文滚动不变，原生双击选词与 Escape 关闭保持一致。

选区浮窗顶部拖动手柄在未固定时也显示。useSelectionToolbarPosition 分别持有手动位置和固定状态：拖动不自动固定，当前选区内保留位置，换选区后未固定浮窗恢复跟随选区；固定后才跨选区保留位置和内容。4px 拖动阈值、指针捕获、视口边界、方向键移动及 Escape／取消／失焦回退沿用现有契约，正文与浮窗滚动所有者不变。

选区浮窗左下、右下提供独立缩放手柄，固定与未固定均可调整宽高。尺寸与位置同归 useSelectionToolbarPosition，使用真实视口坐标处理拖动、按 CSS 缩放转换尺寸，左下缩放保持右边界、右下保持左边界，最小 280×160 CSS 像素并让位于更小的可用视口。手柄固定在底边，内容在内部滚动，放大后译文区同步扩展。方向键微调、Shift 加速，Escape、失焦和取消恢复手势前大小与位置；缩放不触发翻译或固定，关闭浮窗重置尺寸。

条目库选择模式不新增表格上方独立批量操作行：仅在表格最左侧显示选择列，并在原工具栏“选择模式”位置显示已选数量、全选／取消全选、清空、批量操作和退出选择。选择状态仍归 useLibrarySelection，批量确认与执行仍归 LibrarySelectionActions，筛选、虚拟滚动、Shift 范围选择、Escape 退出和列宽拖动契约不变。

选择模式操作统一放在原工具栏的同一个语义 group 内，已选数量、全选、批量动作和退出按钮共用主题色细边框与浅底色；窄宽度沿工具栏横向滚动，不新增表格独立操作行。仅调整视觉容器，选择和批量任务状态所有者不变，保留原键盘与滚动契约。

左侧条目详情标题右侧使用共享 TooltipIconButton 提供编辑入口，只在存在当前条目时显示，资料加载中禁用。点击通过原工作区导航打开／复用条目概览并传递一次编辑请求，直接进入原 EntryEditPage，保留原保存、草稿恢复及关闭保护。侧栏和编辑页面滚动所有者不变，不新建第二套编辑状态。
