# 私人书房：拟物风格提案与独立 Demo

用户已确认材质方向。本文说明正式应用的可选外观扩展及保留的独立 Demo；验证与待办状态以开发计划为准。

## 风格方向

把 NeuInk 变成一间安静的私人书房。参考早期 Smartisan 的实体控件感与细致光影，使用原创书封和图标构成，不复制品牌图标。工作区仍然由导航、资料、详情组成，拟物层负责表现材质，资料的关系和操作语义保持清晰。

| 部位 | 材质与表现 | 使用边界 |
| --- | --- | --- |
| 顶部工具栏 | 暖灰金属、柔和高光、浅色搜索框、实体按钮 | 保留原版材质，只减轻搜索框过深的凹陷 |
| 左侧导航 | 浅色亚麻、暖色选中底纹、透明物件图标 | 保留织物与光影，文字仍是主要识别方式 |
| 论文书架 | 胡桃木层板、布面精装封皮、书脊、纸页与书签 | 正式应用沿用单击/Enter 打开详情，单独提供分屏按钮 |
| 列表 | 浅纸色、细分隔线、小封面、黄铜色进度条 | 提供高密度浏览，不强迫用户始终使用书架 |
| 详情 | 米白纸面、完整标题、阅读进度、相关笔记 | 不为每条元数据叠加卡片 |
| 阅读预览 | 纸张边缘与柔和投影，清晰正文 | 实际 PDF 的内容将保持原样；当前为示例排版 |
| 标签笔记 | 牛皮纸装订本、横线纸、来源条 | 装饰不能影响编辑、选择和引用 |

底色为暖灰与米白；主操作为深红，进度和书签使用黄铜色。光源统一来自左上方。按钮按下轻微下沉，书本悬停轻微抬起；遵循系统减少动态效果的设置。

正式应用的控件进一步收敛为方正平面：按钮、选择框和搜索框使用 2px 小圆角、平面底色及 1px 内侧白色细边，取消外投影和形成圆弧凸起的渐变；开关使用矩形轨道和方形滑块。概览卡片与条目行共用主题小圆角，侧栏分组标题为直角透明底和底部细线。参考 Smartisan 设置界面的浅色表面与细致边缘，具体尺寸按 NeuInk 的桌面密度确定。[Smartisan T2 界面评测](https://www.cnbeta.com.tw/articles/tech/461737.htm)。该调整保留左右工作区布局、书本与浮层投影及书架、纸张、亚麻材质，不影响普通主题。

`library-showcase.html` 的“控件检查”使用正式共享组件集中展示按钮、开关、复选框、输入框、页签及菜单，支持键盘、禁用、只读和错误状态检查；入口仅存在于开发预览，不进入产品菜单。

## 物件图标与光影秩序

锤子 UI 设计总监方迟曾说明，拟物向熟悉的物理物件学习，同时需要重视排版和信息布局。这里借鉴的是这种结合方式，而不是复制整套手机桌面。[设计团队访谈，2014 年](https://www.pingwest.com/a/41713)

这一版采用以下规则：

- **物件层**：书籍、笔记本、放大镜、标签有可辨认的结构、真实材质和透明轮廓。取消给所有图标套一个圆角底板。
- **控件层**：保留金属工具栏、织物导航、实体按钮和视图切换的高光与按下反馈。搜索框采用浅凹面与微弱内阴影，避免整个顶部变成深槽；不将整套控件改为扁平风格。
- **光源**：图标统一使用左上方约 10 点钟方向的柔光；高光只出现在受光边缘，接触处有短阴影。不能给同一个物件同时叠加互相矛盾的 CSS 阴影。
- **材质**：金属靠窄高光体现曲面，布面以漫反射和织纹表现质感，纸页以层叠与边缘体现厚度，玻璃保留部分透明与反射。
- **尺度**：导航中的物件图标显示为 40px；信息、全屏、清除等小型操作继续使用现有线性图标，保证小尺寸可读性。

四枚图标由内置 `image_gen` 生成，每枚单独生成；第一枚书籍图标作为后三枚的材质与光源参考。生成结果为 1254 × 1254 的 RGBA PNG，已检查实际 Alpha 通道存在完全透明、部分透明和不透明像素。放大镜镜片在深色背景下也可透出底色。

## 隐藏入口

1. 打开顶部搜索，或按 `Ctrl/Cmd + K`。
2. 输入完整 `theme`（忽略首尾空格和大小写），出现“打开私人书房”。普通关键词、不完整命令不会显示此入口。正式应用同一命令显示三种风格，也可以从“设置 → 外观与界面”切换。
3. 按 Enter 或点击命令后才切换；输入本身不会自动切换。
4. 进入后可通过底部“退出书房”，或再次输入暗号返回标准样稿。

正式应用默认不启用。通过暗号明确开启后，`neuink.appearance.v1` 记住材质选择；书架/列表偏好单独保存。普通搜索与设置不展示开启入口，状态栏仅在已开启时提供“退出书房”。退出移除材质层并恢复现有 `neuink.themePreset` 的配色，不修改条目、标签、笔记、列偏好或打开的编辑会话。浏览器存储不可用时仍可在当前页面切换，并提示未能记住选择。

独立 Demo 使用另一个 `neuink:atelier-demo:appearance` 键，和正式应用不互相迁移；Demo 状态栏中的暗号提示仅供评审。

## 如何体验

本地开发服务启动后，访问：

<http://127.0.0.1:1420/atelier-showcase.html>

预览面板较窄时，可点击右上角“全屏预览”，查看完整桌面布局；再次点击“退出全屏”即可返回。

- 书架和列表共用同一份示例资料、筛选条件与当前选择。
- 可选择主题、筛选标题、仅看正在阅读的论文。
- 单击论文更新右侧详情；双击、键盘 Enter 或详情中的阅读按钮打开阅读样稿。
- 点击“标签笔记”可翻开三本笔记，查看示例来源并试写、保存。
- 笔记保存仅在本次页面会话中有效；刷新恢复初始示例。

封面、题名简写、元数据、进度和笔记均为演示资料，不代表实际论文出版信息。当前不会读取真实资料库，不会写入真实笔记，也不是实际 PDF 阅读器。

## 实现与隔离

- 独立 HTML 入口位于 `apps/desktop/atelier-showcase.html`，组件和材质样式位于 `src/dev/atelier/`；正式 `App` 没有引用它。
- 复用现有 Button、Input、Textarea、Table、Tooltip、Dialog 和 ScrollArea；没有增加依赖。
- 材质变量只定义在 Demo 的主题根节点和弹窗根节点，不修改 `theme.css` 或已有主题配置。
- 导航使用透明 PNG，书架使用 CSS 渐变、阴影和 3D transform，因此没有引入 WebGL 场景、额外渲染循环或 3D 库。
- `useDemoAppearance` 拥有风格状态，仅在执行暗号命令或退出时更新 Demo 专用的 `neuink:atelier-demo:appearance` 浏览器存储键，不修改正式应用设置。
- 页面组件拥有选择、筛选和示例编辑状态；示例内容不持久化，没有业务 IPC 或数据请求。
- 主内容、详情和阅读内容各由自己的 ScrollArea 管理纵向滚动；表格横向滚动由共享 Table 的容器负责；笔记正文由 Textarea 管理滚动。
- 对话框沿用共享组件的焦点约束、Tab 导航与 Escape 关闭；书本和列表支持键盘 Enter 翻阅。此阶段不提供拖动重排。

## 正式应用接入

正式应用在 `main.tsx` 挂载 `AppearanceProvider`，共享语义变量位于 `theme.css`，材质规则全部限定于 `html[data-appearance="atelier"]`。全局搜索和左侧搜索共用同一个隐藏命令组件。书架通过 `LibraryPapers` 接入条目库，沿用真实条目、标签筛选、阅读状态、分屏和回收站回调。右键菜单收敛为 `LibraryPaperContextMenu`，拖动仍由原条目库 hook 管理。

当前书封根据真实标题与首个标签排版，颜色按条目 ID 稳定生成，不伪造作者、年份、出版社或原 PDF 封面。长标题提供完整悬停提示和详情入口。书架与列表共用集合与排序；原表格保持挂载以保留列宽和滚动，超过 120 篇时书架按行虚拟化。方向键、Home/End 可访问远处论文；单击或 Enter 打开详情，分屏按钮独立处理事件，右键提供重新解析和移入回收站。

笔记列表增加装订边与物件图标，编辑正文采用浅纸面，标签采用纸签材质，进度使用黄铜色。PDF 画布、文字命中、引用、保存及权限逻辑沿用现有实现。未来如需要真实 PDF 首页面封面，应单独接入现有 PDF 渲染与缓存能力；本次不读取或生成封面文件。

## 机械材质与动效

正式主题的控件规则统一位于 `styles/atelier-controls.css`，覆盖 Button 各变体、选择、输入、开关、复选、页签、切换组与菜单浮层。静止时显示左上细高光，悬停时加强白色边缘，按下时切换压入细边；选中保持压入状态。2px 方角和纯色面不变，只有浮层与书本物件保留外投影。

侧栏、标签导航、快速选择与标签编辑共用 DisclosureIcon 的方形框和旋转箭头；折叠标题与旁边动作独立响应。论文／标签／笔记列表增加纸面边与窄黄铜索引线；笔记正文、概览及对话输入区加入低对比纸边。正文没有额外纹理，PDF 画布及文字层不受影响。

悬停、按下、展开分别使用 140/70/180ms 过渡，无回弹。侧栏展开仅淡入内容，不动画面板高度或改变滚动位置；调整高度时停止材质动效，结束或取消后清理状态。减少动态效果的系统偏好关闭这些过渡及按钮／书本位移。组件继续持有原状态、键盘与拖动契约，没有增加依赖。
## 正式主题的三维书本与阅读材质扩展（2026-09-16）

此扩展落在正式 BookCover 与 EntryOverview，不修改上方独立样稿的数据。概览将完整标题、描述与打开入口合并，数量收成紧凑行，属性和文件采用细分隔线；书房显示小书封，宽度小于 480px 时自动收起。玻璃模式沿用同一信息结构但不显示或加载三维书封。

Three.js 0.186.0（MIT）按需加载，开发类型为 @types/three 同版本。现有 CSS 封面继续作为静态回退；Three.js 补充真实纸页厚度、书脊、封板及统一方向光照，不替代 Radix 控件或 PDF.js。模型与封面纹理均由本地代码生成，使用真实标题／标签，不读取 PDF 图像、不请求外部模型、不伪造作者或出版社。构建独立延迟模块约 522 kB，gzip 131 kB；现有 CSS 无法可靠表达模型遮挡和随角度改变的材质照明，因此此次新增依赖限定于该视觉模块。

概览仅在可见时创建场景，每窗口最多三个 WebGL 场景。纹理为 512×768，DPR 最大 2，模型由低复杂度几何组成，静止后不继续渲染。离开视区、拖动、失焦、关闭和退出主题释放资源；回到窗口恢复可见概览。WebGL2 不可用或上下文丢失时显示 CSS 封面，减少动态效果和高对比度偏好跳过三维。

书架悬停不再从 CSS 封面切换为 WebGL 纹理，避免两套字体排版、色彩和比例造成突变。书架始终使用同一 DOM 正面，增加封底、书脊、纸页及上下边缘形成 22px 厚的连续六面体。进入或聚焦默认横向 −22°、纵向 6°；指针驱动横向 −36° 至 −8°、纵向 −2° 至 14° 的可见透视，边缘反光和接触阴影同步变化。使用 260ms 平滑过渡，没有缩放和上浮，移出后复位。概览真实模型同步扩大转角，最大约 41°，保留原纹理和零抬升。书架仍按行虚拟化，打开、分屏、选择、键盘和拖动仍归原条目库。

PDF 选中文字操作复用共享 Button，浮层通过 reader-popover 接入书房纸面／金属细边与玻璃透光。笔记格式工具条统一 editor-toolbar 材质，选中保留 aria-pressed；来源快照和笔记表面采用极淡纸感，PDF 画布与文字选区不变。普通主题无材质覆盖。

机械材质本轮通过 42 项相关测试与前端构建。浏览器检查涵盖轻量按钮完整悬停、选中与焦点环、开关、折叠和独立动作、窄栏／缩放／拖动、加载／错误／空状态及恢复普通主题。原生桌面视觉和系统减少动态效果的实机验证仍未完成。

`entry-sidebar-showcase.html` 复用真实条目详情侧栏与条目概览，提供搜索暗号入口、退出书房和共享控件检查。可在同一组示例资料上比较两种外观，检查分组折叠、窄侧栏和缩放；示例 IPC 只修改内存中的演示数据。

第一版已验证独立样稿的键盘、筛选、空结果、阅读、笔记保存、滚动、全屏和退出流程，类型检查、正式前端构建及现有 789 项前端测试通过。

透明图标已完成 RGBA 透明度检查、图标加载检查和浅／深底视觉检查。

正式扩展的类型检查、前端构建与 804 项前端测试通过。浏览器在复用真实组件的条目库检查页验证材质、切换、窄栏/125% 缩放、筛选空结果及 600 篇论文的虚拟滚动与首尾键盘定位。原生 Tauri 窗口的视觉验证尚未完成。现有测试中仍有 PopoverTrigger 的 ref 提示，构建仍提示较大的前端包；本次没有新增依赖。
