# 校园旅行 · 图片与素材清单

优先提供本人拍摄或已取得使用授权的照片。网上图片可以用于核对建筑，不默认有权打包进应用；来源、摄影者和授权需一起记录。当前不联网自动抓图，游戏也不发送资料库内容。

## 第一批：三个目的地（每处先给 2–3 张即可）

| 地点 / 稳定 ID | 必需参考 | 可选补充 | 用途 |
| --- | --- | --- | --- |
| 信息学馆 / informatics | 正面全景、约 45° 侧前方，能看清楼体轮廓及入口 | 门牌近照、广场或道路、夜景 | 地点明信片、海豹观察／拍照场景 |
| 小南湖 / lake | 湖岸广角、你最熟悉的一个观景点 | 树木和步道、长椅、不同季节 | 湖边休息、画水纹、散步场景 |
| 一号教学楼 / teaching | 正面全景、入口或侧立面 | 楼名标识、公共走廊（避开个人信息） | 求知主题明信片、提问卡场景 |

请确认“一号教学楼”指你地图上的哪一栋，最好在原图圈出来，避免把公共教学楼混淆。照片附拍摄方位和大致季节即可，不需要定位元数据。横向照片优先，长边建议至少 1600 px，建筑不要被裁掉；不需要一开始就准备全部。

## 第二批：增强校园生活（不阻塞当前路线）

- 常去食堂：外景、招牌、2–3 道你想保留的食物；确认食堂名称。
- 社团：愿意加入的社团名字、代表活动和可使用的标识；不直接使用成员肖像。
- 宿舍：上床下桌布局、窗边、喜欢的小物件；避开门牌、姓名和屏幕隐私。
- 海豹动作：之后从已确认的角色图制作眨眼、挥鳍、背包出发、归来 4 组透明素材，无需你另找角色。

## 当前预留与制作规格

- `destinations.ts` 以稳定 ID 管理路线、来信及纪念物；每地点预留 3 个故事，可逐一替换画面而不清空旅行记录。
- 真实地点现在使用明确标注的文字明信片，不拿体验路线插画冒充建筑实景。
- 最终明信片建议 1600×1280（5:4），主体及建筑保留安全边距；文字、地点、日期由程序绘制，不烘焙进图片。
- 宿舍背景沿用已确认美术；海豹、背景、按钮分层。新增图统一使用同一暖色拟物插画风，不混入像素画和旅游海报。
- 收图后顺序：核对地点 → 单张场景稿 → 用户确认建筑与风格 → 接入对应地点 → 再做其他动作／季节。不会再一次性生成不准确的整个校园。
- 第一轮最有帮助的是**信息学馆全景＋侧前方各一张**。
