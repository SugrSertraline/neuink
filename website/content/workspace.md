工作台由左侧工具、内容标签页、可选的右侧分屏与实时任务组成。侧栏负责查找和管理对象，正文区域负责阅读与编辑；切换侧栏不必关闭正在阅读的论文。


## 对照完整工作台

![Neuink 完整实机窗口：左侧条目详情、中间 PDF、右侧演示笔记](../public/screenshots/pdf-note-workspace.png)

左侧找到论文，中间核对 PDF，右侧整理笔记并检查保存状态。点击图片可查看原尺寸；服务地址已遮挡。每个操作的独立步骤图见[截图导航](screenshots.md)，可继续进入导入、翻译、来源追溯和导出教程。

## 五个侧栏入口

| 入口 | 适合做什么 |
| --- | --- |
| 条目库 | 浏览论文、标签、属性与标签笔记，创建或整理条目。 |
| 条目详情 | 查看当前论文或笔记的归属、内容、文档笔记、标签笔记与回收站入口。 |
| 搜索 | 在当前资料库检索条目、笔记、页面和片段。 |
| 助手 | 围绕选定阅读对象提问、检索或审阅修改。 |
| 标签阅读 | 保持一个主题范围，连续阅读该范围中的论文和综合笔记。 |

设置是独立入口。关系图从条目库页眉打开，不是第六个固定侧栏工具。

## 标签页与左右分屏

PDF、重排、条目概览、笔记、网页及完整助手回复可在标签页中打开。标签可以排序、固定、关闭，或通过相应菜单移动到另一侧。左右分屏可以交换，分隔条可以调整宽度。

**常见组合**：PDF + 文档笔记、论文 A + 论文 B、原文 + 重排、网页 + 整理笔记。每一侧保留自己的滚动与当前内容，不按页码或阅读百分比强行同步。

同一对象可能复用已有标签，而不是每次都新建一个副本。使用“复制”类操作时，阅读位置可以分开，但笔记不是另一份文件；编辑权与保存仍受同一份文档保护。

## 当前焦点为什么重要

点击左侧或右侧正文后，该区域成为当前阅读面。助手可以跟随当前对象，但你仍应在发送前检查阅读对象选择器；显式选择材料或“不关联内容”会改变本次范围。

打开网页并不意味着旁边的 PDF 会一起发送。网页读取绑定所选网页的导航状态，详情见[网页阅读](browser.md)。

## 保存与关闭保护

文档笔记、片段笔记、批注和条目编辑各自有保存状态。关闭标签、关闭分屏或切换资料库时，应用会检查未保存内容。保存失败时应留在原编辑页处理，不将对话框消失当作保存成功。

有未保存内容时，跨分屏移动可能被阻止，以避免重新挂载丢失草稿。同一分屏内排序不等于修改文件。崩溃、断电后的所有草稿恢复并不在当前保证范围内。

## 实时任务面板

右下角任务入口集中显示解析、翻译、论文添加、助手运行、待发消息及索引状态。进行中、待确认、排队和暂停分别呈现，完成历史默认收起。

处理时先看任务类型：全文翻译可暂停并继续；取消则结束这一轮但保留已有译文。论文下载取消不撤销已经完成的入库。助手停止也不等于回滚此前已确认的写入。

## 窄窗口与侧栏调整

可折叠侧栏中的分组、改变侧栏宽度或收起不需要的工具。标签阅读中的标签选择、论文与笔记分组各自滚动；PDF 与编辑器正文也各自滚动。遇到长表格时使用表格内部横向滚动，不必把整个页面放大。

当前分屏发生在同一个原生窗口内；把标签拖出为另一个独立桌面窗口不是已完成能力。
