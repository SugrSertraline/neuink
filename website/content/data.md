Windows 0.1.3 默认把数据放在程序旁的 `data` 文件夹。无需指定路径，也没有手动迁移入口。以下便携规则针对 Windows；macOS 使用其平台数据目录，仍以对应发行说明为准。

## 程序与数据放在一起

完整解压便携包后运行 `Neuink.exe`。公开包的 `data` 里只有使用说明；首次启动会在其中建立资料库和设置。程序所在文件夹需要可写；建议放在自己的文件夹或 U 盘，不要直接在压缩包内运行。

| 位置 | 内容 |
| --- | --- |
| `data/library` | 论文、PDF、解析、图片、笔记、批注、译文与聊天记录。 |
| `data/settings.json` | 应用和模型配置，可能包含你填写的密钥。 |
| `data/webview` | 界面偏好、标签页及支持恢复的阅读状态。 |

设置中的“资料库与数据”显示当前位置，可打开对应文件夹。保存和备份时保留整个 `data`，不要只复制 PDF 或 Markdown。

## 使用 U 盘在另一台电脑继续

1. 保存笔记，等待解析、下载与写入完成，正常退出 Neuink。
2. 复制整个程序文件夹，保留 `Neuink.exe`、`data`、`embedding-models`、`resources` 和其他随包文件。
3. 在另一台 Windows 电脑运行同一文件夹中的 `Neuink.exe`。换盘符后仍使用包内数据。
4. 使用后退出 Neuink，再安全弹出移动盘。不要让两台电脑同时写入同一数据副本。

Claude Code 等工具及登录需在每台电脑分别配置；Agent 自己管理的底层会话不保证随包续接。模型设置可能保留，但系统凭据及依赖仍受另一台电脑环境影响。

## 更新版本时保留 data

关闭应用，先把整个 `data` 备份到另一个位置。将新版程序文件与原 `data` 放在一起，保持资源目录完整；公开下载包中的 `data` 只有说明文件，不要用它覆盖个人数据。

程序升级不会替你恢复已被外部文件操作覆盖的数据。确认论文、图片、聊天和设置正常后，再自行整理备份。

## 旧 neuink_data 自动整理

启动时只检查程序目录旁和程序所在磁盘根目录的 `neuink_data`，不会扫描整台电脑。例如程序在 `D:/Neuink-USB`，会检查 `D:/Neuink-USB/neuink_data` 和 `D:/neuink_data`。

缺少的文件补入当前数据，冲突保留当前已有文件。复制与校验成功后，旧目录放入 Windows 回收站；失败或回收站不可用时保留旧目录。冲突内容仍可从回收站里的旧目录恢复。

其他磁盘或任意位置的旧库不会自动导入。处理旧库前先关闭旧版应用并独立备份，不要在运行中改动它。

## 备份与恢复

保存并退出后复制整个 `data`，保留全部子目录和隐藏文件。恢复时退出 Neuink，在副本上核对内容后再使用。断电、外部覆盖和多端同时编辑不属于自动恢复保证。

应用中的条目、笔记和归档标签有相应恢复入口；来源快照仍可读不代表原 PDF 已恢复。缓存可重建，用户文件不能依赖缓存恢复。

## 共享边界与联网范围

目前没有内置局域网共享或多端冲突合并服务。轮流使用同一 U 盘前必须退出应用。公开 GitHub Release 和七牛 CDN 仅分发程序，不能上传包含个人论文、聊天和密钥的 `data`。

本地 PDF 阅读、已保存内容、笔记、关键词检索和导出在本机完成；语义搜索使用随包的本地模型。远程解析会把 PDF 交给配置的解析服务，AI 与翻译会把相应上下文交给所选模型，在线研究会访问对应服务。本地优先不代表所有 AI 操作离线。
